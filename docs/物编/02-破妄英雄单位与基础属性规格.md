## 文档状态

- 版本：`v0.1` 白盒施工基线。
- 建立日期：`2026-07-11`。

- 上位职业基线：[破妄法门资源循环与完整技能组](../归档/职业设计/02-破妄法门资源循环与完整技能组.md)。

## 一、基础定位

| 维度 | 破妄指数 | 四职业中预期位置 |
|---|---:|---|
| 裸装生命 | `95` | 中等偏下，不能靠面板硬吃机制 |
| 物理攻击 | `110` | 四职业中高位 |
| 物理防御 | `100` | 中等 |
| 法术防御 | `85` | 偏低，保留贴身对法系目标的风险 |
| 普攻速度 | `105` | 中等偏快，用于维持三段生势 |
| 基础移动 | `110` | 较高，但仍低于技能位移带来的瞬时机动 |
| 自我恢复 | `70` | 主要依靠守意归元和外部成长，不做高额常驻吸血 |
| 控制/破韧 | `105` | 依赖照真分支，不是无条件常驻优势 |

指数以未来四职业平均值 `100` 为基准，只用于后续横向校准，不直接写入 Y3。

## 二、等级成长公式

首发等级范围为 `Lv1-60`。裸装基础属性统一按角色等级计算：

```text
最大生命 = round(620 + 68 × (等级 - 1))
物理攻击 = round(48 + 5.7 × (等级 - 1))
物理防御 = round(22 + 1.9 × (等级 - 1))
法术防御 = round(16 + 1.5 × (等级 - 1))
```

取整规则：先计算完整定点数，最终显示和写入战斗属性时四舍五入到整数。等级不得低于 1 或高于当前版本上限。

### 2.1 关键等级裸装属性

| 等级 | 最大生命 | 物理攻击 | 物理防御 | 法术防御 | 内容阶段 |
|---:|---:|---:|---:|---:|---|
| `Lv1` | `620` | `48` | `22` | `16` | 花果山启程 |
| `Lv10` | `1232` | `99` | `39` | `30` | 花果山前中段 |
| `Lv20` | `1912` | `156` | `58` | `45` | 花果山篇完成 |
| `Lv30` | `2592` | `213` | `77` | `60` | 地府篇中段 |
| `Lv40` | `3272` | `270` | `96` | `75` | 地府篇完成 |
| `Lv50` | `3952` | `327` | `115` | `90` | 天庭篇中段 |
| `Lv55` | `4292` | `356` | `125` | `97` | 通天塔开放 |
| `Lv60` | `4632` | `384` | `134` | `105` | 首发等级上限 |

### 2.2 成长职责

- `Lv1-20`：基础属性足以承受普通怪连续攻击，但精英和 BOSS 重击必须躲避。
- `Lv21-40`：裸装成长维持基础可玩性，装备强化和进阶开始成为主要战力差异。
- `Lv41-60`：裸装成长不替代装备、法宝和收集系统；首发毕业强度主要由局外长期成长提供。
- 通天塔在 `Lv55` 开放，裸装角色只满足进入资格，不保证能稳定推进高层。

## 三、固定战斗属性

| 属性 | 基础值 | 规则 |
|---|---:|---|
| 最大魔法 | `0` | 破妄不使用蓝条 |
| 魔法成长 | `0` | 所有技能蓝耗为 0 |
| 魔法攻击 | `0` | 首发破妄技能全部按物理攻击结算 |
| 基础暴击率 | `5%` | 装备和收集在此基础上叠加，最终上限后续统一 |
| 基础暴击伤害 | `150%` | 回响和裂痕默认不能独立暴击 |
| 基础命中率 | `100%` | 不包含目标闪避修正 |
| 基础闪避率 | `0%` | 生存依靠操作、减伤和通用闪避，不给常驻随机闪避 |
| 基础冷却缩减 | `0%` | 装备词条上限待定 |
| 基础物理穿透 | `0` | 由装备、法宝或效果提供 |
| 基础法术穿透 | `0` | 破妄默认不需要 |
| 战势 | `0/100` | 出生、入本加锁、死亡后均为 0 |
| 绝技值 | `0/100` | 出生、入本加锁、死亡后均为 0 |
| 普攻三段窗口 | `1.4秒` | 由同步 Lua 记录 |

## 四、移动与普攻标尺

| 项目 | 设计值 | 物编处理 |
|---|---:|---|
| 基础移动速度 | `3.8` 引擎单位/秒 | `ori_speed = 3.8` |
| 基础攻击速度 | `100` | `attack_speed = 100`，需回读项目模板确认基准含义 |
| 基础攻击间隔 | `1.05秒` | `attack_interval = 1.05` |
| 转身速度 | 待回读 | 不猜测 `turn_speed` 尺度 |
| 视野 | `1200` 候选 | 接入地图后结合镜头和公共野外密度验证 |
| 普攻射程 | `2.0` 设计身位 | 换算后写入 `common_atk_range`，不能直接把身位写入物编 |
| 碰撞直径 | `1.0` 设计身位 | 作为全职业白盒基准，实际碰撞字段待项目模板确认 |

普攻类型必须从真实近战英雄模板回读 `common_atk_type`，不得直接猜枚举。普通攻击三段动画、每段生势和连段重置由同步 Lua 与动作资源共同实现。

## 六、出生、升级与重连规则

1. 创建或读取角色时，以存档等级重新计算裸装基础属性。
2. 再叠加装备、强化、进阶、法宝、宠物、收集和临时状态。
3. 属性应用顺序必须幂等；同一角色重复初始化不能再次增加成长值。
4. 升级只改变等级并触发一次全量重算，不直接执行 `旧防御 + 成长值`。
5. 死亡不改变等级和长期属性，只清空战势、绝技值和临时状态。
6. 断线重连恢复长期属性和技能构筑，不恢复战势、绝技值、普攻段数或短时效果。
7. 单人本和团队本加锁时清空临时资源，但不清空生命和装备；是否回满生命由副本入口全局规则确定。

## 七、属性施工验收

| 验收项 | 通过标准 |
|---|---|
| Lv1 创建 | 裸装生命 620、物攻 48、物防 22、法防 16、魔法 0 |
| 等级重算 | Lv20/Lv40/Lv60 与关键等级表一致，误差不超过取整规则 |
| 幂等初始化 | 连续执行初始化 10 次，最终属性与执行 1 次完全相同 |
| 重连 | 长期属性和技能等级恢复，战势与绝技值为 0 |
| 同职业隔离 | 4 名破妄不同等级同时存在时，属性和资源互不串值 |
| 普攻循环 | 无攻速加成时可稳定完成三段，完整三段产生 15 战势 |
| 五槽 | 英雄可学习 8 个主动，但同时只能装配 5 个 |
| 无蓝职业 | 所有破妄技能不扣魔法，单位魔法始终为 0 |
| 模板安全 | `common_atk_type`、转身、普攻射程均来自真实项目回读，不使用猜测值 |

## 八、当前施工结论

- 英雄裸装属性和成长公式已经确定，可进入离线配置与等级重算逻辑施工。
- 真实单位创建仍受 Y3 数值 ID、模型、头像、近战普攻模板和地图工程缺失阻挡。
- 当前不能执行 `y3_obj_edit.py -create`、热更或编辑器回读；这些状态不得标记为 implemented/verified。
