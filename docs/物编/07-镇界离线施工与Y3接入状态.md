## 运行时契约

- 所有效果命令必须显式携带 `self`、`primary`、`selected`、`team` 或 `explicit` 的 `target_scope`；`team` 自动排除施法者。`C02_M07_JIEDING_MARK` 按“目标 ID + 施法者 ID”隔离，`C02_M10_TONGSHOU` 只呈现一个最高来源并在其过期后回退。
- 守势只来自有效职业命中、一次成功格挡或一次有效护守；界势在 Lv15 后才生效，`6` 秒脱战清空，死亡、挑战清理、跨层、销毁和重连清空短时状态。
- `C02_A04` 只接受项目分类器确认的敌方非周期可格挡直击；`C02_A07` 只有分类器确认实际减免或吸收伤害时才确认有效护守。分类器缺失时，两者都不产生资源。
- `C02_A05/C02_A08` 需要项目注入的权威施法点；缺失时返回 `cast-point-required`，不以施法者位置替代。A08 对普通/精英使用控制；对 BOSS 只调用项目的破韧钩子。控制状态由按“稳定单位 ID + 控制类型”计数的租约管理。
- 格挡、个人、团队减伤按类别取高值后乘算，最终上限 75%。
- 桥接控制器按 `actor_id + lifecycle_id` 管理循环计时器、延迟效果和全部 Unit Trigger；移除角色后先注销旧 Trigger，旧回调、旧延迟伤害和旧命中确认不能影响同 ID 的新角色。
