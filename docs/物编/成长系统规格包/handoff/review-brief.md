# 成长系统复审简报

## 复审目标

确认成长规格在数值、公平、存档、公共 BOSS 与 Y3 可实施性上没有把待决项误写为已完成，也没有把 economy-v2 的运行时关闭设计表误写为已实施。

## 必查问题

1. 60 点技能数学是否在所有职业与自动授予路径中守恒。
2. 四职业裸装曲线、装备成长与塔门槛是否形成可调的非碾压节奏。
3. economy-v2 的 XP、掉落/保底、P1 和塔首轮奖励在精确编译后，是否仍保留合理的零付费 30/60/90 分钟路径。
4. `progression_participation`、参与箱、稀有资格、保底和荣誉是否完全分离且可审计。
5. 经验、强化、合成、孵化、存档迁移和重连是否都有幂等与反重复领取边界，且每笔经济收据是否由 `(actor_id, lifecycle_id, authority_proof_ref)` 解析 stable owner_id。
6. “长期存档 ORPG”是否被拆成可在 Y3 2.5D 地图中执行的权威子会话，而非隐含无限 MMO 服务依赖。

## 当前阻塞

装备和宠物数据、地府/天庭 source_profile、真实经济运行时、Y3 工程与实机验证尚未具备；economy-v2 已冻结的数值与合同也不得以文字完善程度替代实际编译和运行证据。
