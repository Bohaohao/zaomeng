# UI 交接简报

## 面板范围

- 等级/经验与章节进度。
- 技能树、剩余技能点、绝技试炼提示与三套构筑预设。
- 背包、装备、强化、进阶、法宝、宠物和材料。
- 主城收集、龙宫版本选择、通天塔逐人门槛与塔层记录。
- 公共 BOSS 的个人进度证据、非稀有参与反馈与资格拒绝原因。

## 权威边界

UI 只能显示状态、发起选择和展示权威反馈。升级、技能加点、构筑锁定、传送、挑战开启、奖励、掉落、保底与存档写入必须由同步玩法逻辑确认。不得用本地 UI 将“有效参与”“参与箱”或“稀有资格”互相推导。

构筑面板必须把 5 主动、装备、法宝和宠物配置作为一个预设整体展示和请求切换；客户端不能局部替换被挑战锁锁定的任何一项，也不能复制物品实例状态。

C04 的龙宫提示和入口反馈必须只读取当前 `actor_id` 的路线通过键；路线选择键、队友旁观、公共事件或他人通过都不能显示为本人已解锁完整交互。

其他职业也必须展示并校验自己的 Lv8 核心路线完成状态：C01/C02/C03 分别只读取当前 `actor_id` 的 `C01_ROUTE_LV8_core`、`C02_ROUTE_LV8_core`、`C03_ROUTE_LV8_core`；任何职业都不能只凭发现入口、等级或队伍成员的完成状态绕过完整龙宫交互门禁。失败/超时后 UI 只允许重新发起路线 attempt，不得本地写入完成态。

## 待决后才能出图的面板

- 经验曲线与升级预览。
- 装备部位、词条、强化/进阶数值。
- 法宝/宠物槽位、配方与成长。
- 货币余额、兑换和掉落保底。
- 通天塔奖励、赛季与单人/团队记录。
