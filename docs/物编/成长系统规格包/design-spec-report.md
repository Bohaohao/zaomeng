# 成长系统规格包报告

## 结果

本规格包将现有三篇 Lv60 成长设计整理为一个可校验的 Y3 规划层交接包。它明确了等级、技能点、绝技、基础属性、公共奖励资格、装备/法宝/宠物字段边界、首轮验证切片与下游责任。

`design-spec.json` 已通过结构验证，完整性评分为 `100/100 (ready)`；其中保留 9 项待决。项目级目标会话时长尚未给定，结构校验会保留一条时长缺失警告；评分不代表经验、物品、掉落或 Y3 实机已经实现。

详细契约以 [18-成长系统进度、掉落与长期目标契约](../18-成长系统进度、掉落与长期目标契约.md) 和 [19-装备、法宝、宠物与材料物编规格](../19-装备、法宝、宠物与材料物编规格.md) 为准；本目录的 JSON 和 handoff 文件用于机器读取与后续技能交接。

## Y3 适配判断

项目以 Y3 2.5D 俯视角、1-4 人公共地图为载体，成长主体是可存档的长期进度，具体的野外、单人本、团队本与通天塔是可重复的权威子会话。该形态可适配 Y3，但不能将“长期 ORPG”误解为无限持久的 MMO 服务器：奖励、资格、掉落和存档变更都必须落到同步玩法事务。

## 已结构化内容

- `Lv1-60` 三篇成长主线、`Lv55` 通天塔逐人硬门槛与后续每篇 `+10` 级原则。
- 四职业的 60 点技能预算、5 主动槽、3 预设、绝技三阶试炼与四套裸装属性公式。
- 长期状态、临时战斗态、DPS 荣誉、个人有效参与、参与箱和稀有资格的字段分层。
- 五品质装备、强化/进阶、法宝合成/洗炼/追加、宠物、材料、货币、掉落 profile 的 A/B 层边界。
- 花果山、龙宫、牛魔旧战场、通天塔和主城收集的奖励方向及不可擅自补全的数值缺口。
- 公共 BOSS 奖励、零付费商业边界、存档迁移、Y3 物编/运行时/UI/地形的下游交接。

## 首轮建议

先做成长系统的花果山闭环：Lv1-20 门槛、技能点幂等、四职业属性重算、三套构筑、龙宫旧潮门槛、花果山收集结构和奖励资格日志。它是规格/验证切片，不缩减产品 v1.0 仍需覆盖的三城 Lv60 内容。
