## 2. 全篇生态原则

天庭的敌人生态不是“把天兵全部清空”，而是让玩家分辨被裂律操控的秩序执行者、可纠正的错误命令与不可伪造的首领压力。每一种生态对象都必须服务下列循环：

`读出错误规则或关系 → 选择遮蔽、校验、转向、分流、净化或保留通路 → 让错误压力可见地失效/转化 → 理解下一次如何避免同类失败`

共同约束：

1. **双通道预警**：关键压力至少具备形状、方向、轨迹、轮廓或场地变化之一，并另有声音、文字、状态符号或 UI 之一；颜色不能是唯一信息。
2. **非输出优先**：允许攻击成为压力处理的一环，但不能让持续输出跳过校验、净化、转向、分流或通路维护。
3. **可见结果**：处理成功必须让命令静止、阵眼断链、机关停摆、路线打开、回响改道、援护显现或可净化对象脱离错误控制等结果可见。
4. **可复盘失败**：失败应能归因于误读预警、错误目标、漏掉节点、错误顺序、封死退路或未完成反制；不以无提示秒杀、隐藏规则或纯数值碾压表达。
5. **无新增运行时事实**：生态对象不能写进度、签发资格、决定轮换、改变成员快照、完成清理、发放奖励或生成经济收据。

## 4. 各生态对象的战斗合同

### 4.1 受控天兵：被救回的秩序执行者

| 项目 | 规格 |
|---|---|
| 职责 | 让玩家先读出“压力来自错误阵眼/命令”，再选择拆阵与净化；受控天兵不是天然敌对的刷怪对象。 |
| 预警 | 错误命令来源、与阵眼的关系线、被召回/被强制参战的状态须先于攻击压力可读；须有非颜色辅助。 |
| 玩家反制 | 校验真阵眼、切断错误关系、在可见窗口执行净化/救援，并利用脱控后的结果证明阵势已被纠正。 |
| 失败结果 | 只清理受控天兵而不处理阵眼，会使错误秩序继续召回或阻断路线；失败信息必须明确指向遗漏的阵眼或关系。 |
| 可使用交互 | 观察关系、绕行、校验、净化、短暂分流、将压力引向可验证的正确节点。 |
| 禁止交互 | 把击杀受控天兵当成唯一通关条件；把其作为经验、掉落、货币、材料、资格或收据来源；以隐藏阵眼强迫背板。 |
| 1–4 人适配 | 单人可按“识别→拆阵→救援”顺序完成；多人可以并行观察与保护路线，但任何一名成员都不应永久锁死为纯救援职责。 |
| 首领关系 | 仅服务巨灵神守阵的既有叙事和锁链可读性；不复制巨灵神的动作、仇恨、阶段或胜负条件。 |
| 场地职责 | 至少提供阵眼关系阅读面、可回退观察位、净化/救援可达区与不把撤离路线封死的连通空间。 |

### 4.2 四方门卫机关：相互否定命令的精英机关

| 项目 | 规格 |
|---|---|
| 职责 | 将“四方守备信号同时互相否定”变成可观察的方向、开闭、相位与路径压力，预演后续四方机制语法。 |
| 预警 | 每次状态切换先展示来源朝向、当前门态、受影响路线及冲突关系；方向形态与第二通道提示均须存在。 |
| 玩家反制 | 选择开关顺序、保留一条安全通路、分流观察或等待正确门态；正确处理应令至少一条冲突回响静止或转为可通过状态。 |
| 失败结果 | 误把四处机关当成互不相关的独立目标，会使路线互相封锁；复盘应显示哪一道命令与哪一道门态相冲突。 |
| 可使用交互 | 读取朝向、观察状态、按顺序切换、利用已打开的通路回撤、在多人时分工交叉确认。 |
| 禁止交互 | 同时要求多处长期占据；将门态只写在聊天或只用颜色；把相位门变成无提示传送、实际地图门或会话入口。 |
| 1–4 人适配 | 单人拥有先后处理和可重复验证路线；两至四人可以并行读图与接力，但不需要第五人或固定职业。 |
| 首领关系 | 是四象轮值失衡的预演，不是四圣兽或方位星官的替身，也不决定星宿轮换。 |
| 场地职责 | 同屏/可往返地读取多方状态，保留至少一条回退路；机关状态与背景装饰不得混淆。 |

### 4.3 失控云兽：路线扰动而非追杀填充物

| 项目 | 规格 |
|---|---|
| 职责 | 在天王殿外缘制造可预判的机动压力，迫使玩家保留路线、选择分流与处理相位门影响。 |
| 预警 | 移动意图、扑向/驱离方向、即将影响的路径或安全区要在动作发生前有轮廓、轨迹或场地提示，并配独立辅助。 |
| 玩家反制 | 用可见路径引导其经过空区、借门态错开、短暂控制其占用路线，或让其移动暴露错误守备信号。 |
| 失败结果 | 未提前保留路径或将其引向队友/关键交互，会令回撤空间被压缩；失败不应表现为无预兆追尾。 |
| 可使用交互 | 预判、引导、绕行、以队伍接应分摊路线压力、将其与机关状态分开处理。 |
| 禁止交互 | 把其做成不可躲避的高速点名、无边界追踪、掉落容器或四圣兽换皮。 |
| 1–4 人适配 | 单人可凭路线和时序完成；多人可由一人牵引、其余人处理机关，但牵引者始终留有可脱离和交接的路径。 |
| 首领关系 | 只连接“四门失衡”的公共教学，不携带任何青龙风潮、朱雀火场、白虎猎印或玄武壁障的首领结算语义。 |
| 场地职责 | 需要环绕、会合、观察与安全回退的连通结构；不以死角、不可抵达边缘或封闭小格制造压力。 |

### 4.4 泛称监星使：校验与短暂净化的精英观察者

| 项目 | 规格 |
|---|---|
| 职责 | 在周天观台让玩家学习观察星点变化、辨认真伪链路与完成短暂校准；其叙事功能是解释七星与二十八宿被卷入。 |
| 预警 | 观察对象、正在变化的链路、可校验/不可校验状态和校验结果必须有连续历史，不能只在交互瞬间显示。 |
| 玩家反制 | 先观察变化，再校验或净化；错误星图被保留时，应让玩家能重新读到差异与修正方向。 |
| 失败结果 | 过早处理错误链路会保留错误星轨或错失短暂净化机会；失败说明应指向“未观察/误判”，而非随机失败。 |
| 可使用交互 | 观察、验证、标记变化、短暂净化、在多人时交叉确认；在单人时可以重复验证。 |
| 禁止交互 | 与天玑·匿曜监星使共用首领身份、把真伪仅以颜色区分、自动替玩家判定正确星图。 |
| 1–4 人适配 | 单人可按顺序验证；多人可交叉确认并共享可见结果，不能让某一人独占隐藏信息。 |
| 首领关系 | 只是泛称观察编制；不复用天玑首领的真伪星标反照动作、首领轮廓或通关条件。 |
| 场地职责 | 提供短暂观察位、可见的星图变化方向和不被装饰遮蔽的校验面。 |

### 4.6 七星校星规则回响：只帮助首领机制被读懂

七星不得被额外小怪潮挤占为群战。下列回响是首领场地中的非人格规则表达，只在已有“空间规则 → 首领身份动作 → 反转收束”骨架内使用：

| 试炼 | 可出现的规则回响 | 可读与反制 | 禁止越界 |
|---|---|---|---|
| 天枢 | 中轴、稳定锚、方向翻转与回归路径。 | 读中轴后借稳定锚校回方位；反制结果让中心/外圈关系更清楚。 | 不新增第二首领、不可读强制位移或数值型站桩。 |
| 天璇 | 内外双轨、旧轨来源、下一落点与可穿越回环。 | 区分旧轨复制与新轨，选择切换或诱导回环。 | 不让两轨仅靠颜色区分，不造额外追兵。 |
| 天玑 | 真伪星标、观察位与反照关系。 | 先验证真星，再让假象反照首领。 | 不把泛称监星使或假星标变成有姓名的额外 Boss。 |
| 天权 | 双侧承压、裁决条与归位提示。 | 用顺序与正确打断回正失衡。 | 不要求单人同时长期占据两侧。 |
| 玉衡 | 两类安全位、灵息回流和护持转化。 | 交替利用安全位，使过量回流转为护持。 | 不以资源数值、职业专属或隐形安全位强迫猜测。 |

它们全部遵守单人规则：可顺序处理、可重复确认、可自我制造反制窗口；无队友点击、承伤、打断或长期站位前提。检查点、复活、挑战次数、材料、称号、法宝、掉落和结算仍为 `null/deferred`。

### 4.7 星宿方位回响与噩梦支援状态：不覆盖星官身份

| 场景 | 可复用的非人格回响 | 玩家必须读出的关系 | 正确处理的可见结果 | 禁止越界 |
|---|---|---|---|---|
| 青龙普通 | 连线、延迟龙影、真阵眼、风潮推拉、路线改道。 | 星链方向、延迟与推拉如何共同改变路线。 | 错误龙脉被切断，连线转为可通过/导流路线。 | 不把星链回响命名或表现为某一星官本体，不隐形连线。 |
| 朱雀普通 | 火种、回响次序、余烬、水脉、火环缺口。 | 火场状态、可穿越缺口与净化出口。 | 复燃停止，余烬转为可用的安全/净化条件。 | 不用同一火效混淆伤害、交互与安全区，不让离群点名无人可救。 |
| 白虎普通 | 猎印、拦截线、明暗、破网双端、连锁顺序。 | 点名归属、可接应区与轮换路径。 | 猎印被卸除/反向成破绽，围猎路线打开。 | 不将同步处理锁定给固定职业，不以无路可走点名惩罚。 |
| 玄武普通 | 镇桩、回声、虚穴、甲壁开口、反射角度。 | 两侧压力与剩余通路。 | 甲壁出现稳定开口，反射转为可利用机关角度。 | 不使用隐藏出口、无预警封场或必须同时守两点。 |
| 四圣噩梦 | 贡辉链、净宿状态、圣兽庇护、导流/庇护/反猎/破壁窗口。 | 当前激活链、对应星官关系、净宿援护具体改变了什么。 | 贡辉转净宿、圣兽庇护减弱、核心出现可读缺口。 | 不新增第九敌人，不把状态图标当作唯一交互，不重算方位、不签发资格或奖励。 |

普通模式仍按既有“前阵双宿 → 中阵双宿 → 后阵双宿 → 守位单宿”推进。回响只强化该方位共同语法，不能把七名星官改为可被小怪替代的血量目标。噩梦中，贡辉、净宿与圣兽庇护只是关系状态；它们不读取客户端时钟、不改变已冻结的方位，也不改变断线成员 `left`、禁止重连和不可领取当前实例结果的既有边界。

## 7. 施工前场地与表现输入
