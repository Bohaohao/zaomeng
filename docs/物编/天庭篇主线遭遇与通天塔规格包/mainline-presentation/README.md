- 不使用原作正文或外部文学资料；只保留原创概述。
- 不写入 Y3、Lua、地图、UI、对象、资源、镜头轨迹、音频或特效文件。
- 不填生命、攻击、防御、攻速、移速、伤害、施放或持续字段。
- 不创建掉落、奖励、材料、货币、经验、资格、收据、经济结算或进度写入。
- 不改变既有权威合同中的成员、会话、失败、清理、重入、幂等或完成判定。

所有实际绑定保持 `null/deferred`。真实施工仍受 P0 绝对标定、真实 Y3 工程与 P1 主线纵切门禁约束，详见上级[施工就绪台账](../construction-readiness-ledger.md)。
