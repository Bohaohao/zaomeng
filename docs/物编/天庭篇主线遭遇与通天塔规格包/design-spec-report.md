# Y3 设计规格报告

## 一句话定位

天庭篇以“被污染的天律能否被校正”为主线冲突：凌霄外庭完成常规收束，七星承担七种单人机制与长期收藏，二十八星宿按时辰轮换提供主线后最高端团队本，噩梦四圣兽回收七宿机制。

## 已完成的内容设计

| 模块 | 当前规格结论 |
|---|---|
| 主线 | 临时天庭 → 南天门 → 天宫道 → 天王殿 → 周天观台 → 凌霄外庭。 |
| 单人 | 天枢、天璇、天玑、天权、玉衡、开阳、瑶光固定七本，各有空间规则、首领方向、残片、称号标签和展示。 |
| 七星长期目标 | 同种残片十枚合成对应星君称号；七称号自动解锁名称待定的七曜集合称号，效果集合不重复叠加。 |
| 团队 | 二十八星宿为主线后高端轨道；普通采用双宿/双宿/双宿/单宿，噩梦由四圣兽与七宿双向共鸣组成终局。 |
| 时辰 | 子/辰/申青龙，丑/巳/酉朱雀，寅/午/戌白虎，卯/未/亥玄武；入场锁定权威 rotation_snapshot。 |
| 四圣 | 青龙、朱雀、白虎、玄武分别回收行云、火候、围猎、封镇语法；必须逐链净宿后才打开终局。 |

## 适配与边界

- 目标为最多四人，所有团队机制都以四人上限为设计约束。
- 入章、成员资格、实例状态、失败/清理、严格不重连与 Asia/Shanghai 轮换快照的离线权威语义已冻结；真实权威服务、存储和 Y3 接入仍未实现。
- 天庭仍不得默认读写 DF_PROGRESS_YANLUO_HALL_CLEARED。
- 天庭仍只外部引用 runtime-closed economy-v2；没有新增运行时材料、钥匙、物品、货币、塔模式或奖励值。
- “十枚同星残片”是用户明确的离线配方倍率，不是掉落或资源吞吐数值。

## 结构化工件

- 机器内容合同：tianting-content-expansion-contract.json。
- 进度与会话权威合同：authority/tianting-progression-and-instance-authority-contract.json。
- 主线与副本关系：mainline-route.md。
- 单人和团队的完整机制：instances 目录。
- 公共遭遇、奖励候选、通天塔复用、文学灵感：encounters、economy-candidates、tower、references 目录。
- 下游对象、地形、Lua、UI 与复审边界：handoff 目录。

## 必须保持未决

1. 逻辑进度、实例会话和 rotation_snapshot 的真实运行时键、可信提供方、存储、网络协议、迁移与异常恢复。
2. 地图、对象、技能、数值、AI、检查点、同步、断线与 Y3 持久化施工。
3. 所有候选材料、钥匙、称号、法宝的资源表绑定、掉率、数量、保底、收据、属性和名称。
4. 通天塔的全局 run、三或五层选择、十层大 Boss、层位、抽取、掉落、词缀和赛季。

这份报告只描述离线规格的成熟度，不能被理解为可直接生成 Y3 内容。
