# 天庭奖励候选登记

> 这是奖励类别和长期目标的设计登记，不是经济表、掉落表、物品表或结算实现。除“同一种七星残片十枚合成对应星君称号”外，本文不冻结数量、概率、保底、货币、属性或运行时资源键。

## 不可越过的边界

- 只能外部引用 runtime-closed 的 economy-v2；不得把候选材料伪装为既有 MAT_ 或 CUR_ 键。
- 不得写入 XP、金币、掉率、保底、材料掉落数量、装备属性、法宝数值或塔奖励。
- 实际发放需要未来的资格快照、所有者、遭遇实例、事件、幂等收据、奖励槽位和权威证明；本页没有实现这些字段。
- 普通难度的夜巡钥是“开启噩梦的设计语义”，不决定它是可交易物品、账号资格、队长资格还是一次性凭证。

## 奖励类别

| 来源 | 候选类别 | 叙事/玩法用途 | 经济与实现状态 |
|---|---|---|---|
| 七星单人本 | 天枢残片至瑶光残片 | 分别对应七星收藏与毕业法宝的“七种均齐备”条件。 | 展示名已定；物品键、产出、数量、掉率、保底、绑定均 deferred。 |
| 七星残片收集 | 天枢星君至瑶光星君 | 同种残片累计十枚合成对应称号；七称号齐备解锁名称待定的集合称号。 | 十枚是用户固定的离线配方倍率，不是掉落数；称号属性/持久化 deferred。 |
| 七星全收集 | 周天校律盘（天庭阶段毕业法宝） | 七种残片均齐备，加上天律校印的基础路径主题；四圣铸核只可支撑四象覆环等可选至臻展示。 | 实际配方、数量、来源强制关系、属性、制造与收据 deferred。 |
| 二十八星宿普通 | 方位宿印 | 对应方位的铸造、收藏和噩梦资格候选。 | 仅材料族概念。 |
| 二十八星宿普通/噩梦 | 星官遗契 | 天庭装备词条、法宝胚子、外观收藏的候选材料族。 | 不创建装备、词条或属性。 |
| 二十八星宿普通完成 | 方位夜巡钥 | 请求同方位噩梦准入的钥匙/凭证候选。 | 归属、数量、消耗、有效期、重复发放和收据 deferred。 |
| 四圣兽噩梦 | 四圣铸核 | 天庭毕业法宝的珍贵材料候选。 | 不默认把它设为单人毕业的强制门票。 |
| 四圣兽噩梦 | 圣兽遗珍 | 高阶装备胚子、外观与四圣称号收集的候选。 | 不创建实际奖励或数值。 |
| 四圣成就 | 四方圣兽称号 / 四象镇天 | 对应方位完成与七链净宿的长期目标。 | 仅无数值效果标签和展示方向。 |
| 通天塔天庭主题 | 暂不登记材料 | 七星与二十八星宿只注册为未来小 Boss 池。 | 本轮明确不设计塔掉落。 |

## 称号效果的防叠加语义

| 集合 | 单称号 | 集合称号 | 生效规则 |
|---|---|---|---|
| 七星 | 七个星君称号 | 名称待定的七曜集合称号 | 集合称号作为唯一生效的七曜效果集合，不能和单称号重复计入。 |
| 四圣 | 青龙巡天、朱雀焚曜、白虎执锐、玄武镇界 | 四象镇天 | 集合称号作为唯一生效的四圣效果集合，不能和单称号重复计入。 |

这条规则只防止“同一收藏效果翻倍”。它不规定标签是否在全局、天庭、星宿副本或通天塔生效；数值与可交互性必须等待战斗与称号系统合同。

## 进入经济裁决前必须补齐

1. 每一奖励类别的资源表绑定与版本。
2. 资格快照、所有者范围、多人参与箱、断线与重复结算语义。
3. 获得周期、掉落/保底、来源上限、代币/货币与沉没成本。
4. 夜巡钥的形态、可交易性、过期、消耗、补发和幂等收据。
5. 称号与法宝的实际持久化、展示位、效果作用域和战斗数值。
