# 天庭内容深化复审简报

## 本轮已完成的离线裁决

1. 七星取代旧“蟠桃园 / 御马监二选一”，成为固定七个单人试炼。
2. 天庭常规主线在凌霄外庭收束；二十八星宿是主线后最高端团队循环。
3. 十二时辰轮换固定为：子/辰/申青龙，丑/巳/酉朱雀，寅/午/戌白虎，卯/未/亥玄武。
4. 普通七宿通关通向方位夜巡钥候选；噩梦中七宿以宿曜贡辉强化四圣，四圣以圣兽庇护反哺七宿。
5. 七星同种残片十枚合成星君称号；七称号集合与四圣集合均采取“集合替代单称号效果集合”的防翻倍语义。
6. 七星/星宿只注册为未来全局通天塔 Boss 池；每三或五层未选，每十层大 Boss 仅留接口。

## 复审重点

| 主题 | 必查问题 |
|---|---|
| 叙事 | 主线是否解释了星宿失序，并把“净化而非滥杀”作为可玩行动？ |
| 七星 | 七个机制、称号标签、展示方向是否重复？十枚规则是否被误写为掉落数量？ |
| 星宿 | 是否准确保留二十八全名、四象各七、四段普通结构和最多四人可解？ |
| 时间 | 是否只由权威 rotation_snapshot 选择方位，且重连不重算？ |
| 噩梦 | 是否真实保留七宿→四圣与四圣→七宿的双向关系，并要求逐链净宿？ |
| 经济 | 是否没有出现资源键、掉率、保底、数量、属性、钥匙消耗或发奖实现？ |
| 通天塔 | 是否只写内容池，不绑定五节拍、不建第二塔、不提前设计塔掉落？ |

## 仍不可放行

- 天庭入章/完成、实例、时间、失败、清理、重连与资格的**运行时服务、存储、网络协议和 Y3 接入**；离线语义合同已冻结，见 `../authority/tianting-progression-and-instance-authority-contract.json`。
- 所有对象、技能、数值、AI、地图、UI 资产。
- 所有材料、钥匙、称号、法宝的资源表、收据、掉率、保底、属性与兑换。
- 通天塔 run、三或五层选择、十层大 Boss 名单、掉落和赛季。

在这些前置合同完成前，复审通过只表示策划设计可交接，不表示能够进入 Y3 施工。
