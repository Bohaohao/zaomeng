# 天庭篇与通天塔首轮决策登记

## 已冻结

| ID | 决策 | 状态 | 影响 |
|---|---|---|---|
| TT-FIX-001 | 天庭等级段为 Lv41-60，首发等级上限为 Lv60。 | fixed | 只定义章节定位，不推导经验表或时长。 |
| TT-FIX-002 | 通天塔入口要求单人或每一名团队成员均达到 Lv55。 | fixed | 不使用队伍平均等级或成员替代。 |
| TT-FIX-003 | 通天塔每 5 层设置构筑休整节点。 | fixed | 休整节点允许已保存预设按既有构筑规则切换；不定义楼层总数。 |
| TT-FIX-004 | 玲珑塔主题并入全局通天塔，不能作为第二套长期爬塔系统。 | fixed | 天庭包只能提供主题和内容接口，不能创建独立塔记录或奖励账本。 |
| TT-FIX-005 | 首发支持最多 4 人公共地图、单人本与团队本；共享状态变更走权威玩法逻辑。 | fixed | 天庭副本未来必须复用既有会话、成员锁、失败和清理边界。 |
| TT-FIX-006 | DF_PROGRESS_YANLUO_HALL_CLEARED 不是天庭默认门槛或消费者。 | fixed | 当前只允许龙宫逆潮消费该键；天庭入章需要独立的新决策。 |
| TT-FIX-007 | 成长、货币、掉落、保底和塔奖励必须由版本化资源表和幂等收据结算。 | fixed | `economy-v2` 已采纳为运行时关闭的设计表；天庭只外部引用它的塔首轮奖励与收据边界，`implementation/growth/` 仍为禁止消费的离线候选。 |

## 本轮离线设计结论

| ID | 结论 | 状态 | 约束 |
|---|---|---|---|
| TT-DESIGN-001 | 以天门倾覆、临时天庭主城、神将失控与天律裂缝作为天庭篇世界观锚点。 | offline_design | 仅继承世界观方向，不把高层叙述扩写为已批准的章节台词、Boss 或关卡顺序。 |
| TT-DESIGN-002 | 以主城安全区、天宫道/南天门/天王殿外缘、单人内容候选、团队内容候选和全局塔主题五类逻辑角色组织范围。 | offline_design | 所有角色使用 spec_id；不新增地图、对象、遇敌、奖励或运行时键。 |
| TT-DESIGN-003 | 主线、单人、团队与通天塔使用彼此可见的内容职责，但具体入口、前置、完成关系和时间顺序由后续合同裁决。 | offline_design | 不默认把团队本写成常规完成者，也不把单人本或塔写成章节门票。 |
| TT-DESIGN-004 | 天庭公共/单人/团队/塔只登记奖励来源类别和所需资格快照。 | offline_design | 天庭具体资源不得从花果山白盒字段或旧建议推导；塔首轮只外部引用 `economy-v2`，不内嵌值。 |
| TT-DESIGN-005 | 通天塔首轮循环只固定准入、休整和全局唯一性；运行、记录、奖励和赛季作为显式空合同字段保留。 | offline_design | 不提前写入楼层数、层主题、词缀、奖励数量或赛季规则。 |
| TT-DESIGN-006 | 通天塔首轮子循环以“准入 → 五个抽象节拍 → 第五节拍休整 → 结算/失败/退出/下一循环交接”的状态与时序合同表达。 | offline_design | 五节拍只定义子循环宽度，不代表总层数；所有状态均为 `TT_SPEC_`，不创建运行时键或实现。 |

## 明确延期

| ID | 未决项 | 阻塞原因 |
|---|---|---|
| TT-DEFER-001 | 地府至天庭的入章条件、进度键、唯一写入者和受信任消费者。 | 当前跨篇接口只定义阎罗完成键至龙宫逆潮的消费。 |
| TT-DEFER-002 | 天庭公共路线的实际顺序、地图拓扑、出生点、入口、出口、区域等级、对象和资源。 | 工作区没有天庭地图工程、编辑器回读或天庭地形包。 |
| TT-DEFER-003 | 蟠桃园或御马监的首发单人本选择、入口、时长、状态机、Boss、奖励和失败回退。 | 世界观仅给出二选一方向。 |
| TT-DEFER-004 | 凌霄宝殿、杨戬线、常规篇章完成者和团队本的具体关系。 | 当前范围只确认天庭团队内容方向，未定义完成语义或运行时合同。 |
| TT-DEFER-005 | 通天塔全局 run 模型、单人/团队记录、持久化、后续循环、楼层计划、词缀、首通/复刷、最终层数和赛季。 | 首轮五节拍只补齐离线状态边界；它不提供全局运行、记录或经济合同。 |
| TT-DEFER-006 | 天庭 XP source_profile、装备、法宝、宠物、材料、掉率、保底、资格和资源吞吐的章节分配与运行时接入。 | `economy-v2` 已冻结全局曲线/塔首轮奖励/收据，但尚未分配天庭来源，且权威账本和证明解析未施工。 |
| TT-DEFER-007 | 天庭真实对象、Y3 ID、地图根、Lua、UI、持久化和多人实机。 | 需要真实工程、资源台账、同步设计和后续专项流程。 |
