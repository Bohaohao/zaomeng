## 轮换边界

二十八星宿的方位在入场前冻结为 rotation_snapshot。实例内的方位、难度、七宿名单、四圣兽和奖励资格不得由本地 UI 或客户端时间自行改变。

| 层级 | 允许决定 | 禁止决定 |
|---|---|---|
| 内容规格 | 十二时辰映射、每方七宿、普通/噩梦关系、机制语法。 | 时区、服务端时钟实现、快照 ID 格式、钥匙消耗。 |
| 离线权威实例合同 | 入场时快照、成员锁、断线离场、失败、清理与幂等；见 `authority/tianting-progression-and-instance-authority-contract.json`。 | 用客户端时钟或 UI 覆盖快照，或把离线语义误作已接入的运行时服务。 |
| 经济合同 | 奖励资格、所有者、收据、掉率、数量与保底。 | 从本白盒推导材料或货币数值。 |

## 不变约束

1. 天庭 Lv41–60；首发上限 Lv60。
2. 通天塔 Lv55 逐人准入，每五层休整，且只能是唯一全局塔。
3. 二十八星宿是主线后团队内容，不替代凌霄外庭的常规章节收束。
4. 天庭不得默认消费或写入 DF_PROGRESS_YANLUO_HALL_CLEARED。
5. 运行时键、物品键、地图键、能力键和资源表绑定均保持空值。
