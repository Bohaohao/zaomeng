## 逻辑角色表

| 逻辑角色 | 本包可确认的职责 | 本包禁止确认的内容 |
|---|---|---|
| 临时天庭主城 | 天庭篇文明、安全、功能与传送锚点。 | 真实地图根、NPC、坐标、资源、传送点和 UI。 |
| 公共路线群 | 天宫道、南天门、天王殿外缘的范围方向。 | 物理邻接、遭遇次序、怪物、Boss、刷新、掉落和等级带。 |
| 单人内容候选 | 在蟠桃园与御马监中保留一次明确选择。 | 选择结果、入口、区域数量、时长、状态机、目标和奖励。 |
| 常规完成角色 | 为未来角色级章节收束预留唯一职责。 | 是否存在、其副本类型、进度键、写入者、Boss 和完成流程。 |
| 团队内容方向 | 凌霄宝殿/杨戬线的团队内容方向。 | 常规完成关系、入口、成员条件、地图、战斗和奖励。 |
| 全局通天塔 | Lv55 逐人准入、每 5 层休整、天庭玲珑主题。 | 楼层、词缀、记录、奖励、赛季、独立第二塔。 |

## 白盒验收边界

- 所有天庭角色是 TT_SPEC_ 规格局部标识，不可转写为 runtime key。
- 天庭入章不从 DF_PROGRESS_YANLUO_HALL_CLEARED 建立边；该键的既有消费者边界保持不变。
- 主线、单人、团队和塔之间的虚线都不代表入口、前置、地图连接、奖励资格或完成键消费。
- 天庭主题塔层只属于全局通天塔，不能出现并列的玲珑塔存档、奖励账本或赛季。
- 所有奖励节点只可外部引用 runtime-closed economy-v2，不能生成经验、货币、物品、掉率或保底字段；implementation/growth/ 候选不得消费。
