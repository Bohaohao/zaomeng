# 二十八星宿团队本规格

## 定位

二十八星宿是天庭常规主线收束后开放的版本最高端团队副本。它支持既有的最多四人团队边界，且所有共享状态、轮换判断、成员资格、失败、清理、奖励和重连必须由未来权威玩法逻辑裁决。

- 普通：挑战当前方位的七宿，学习本象机制，并取得对应噩梦挑战钥匙候选。
- 噩梦：同样按方位轮换；四圣兽与七宿同时在场，七宿强化圣兽，圣兽庇护七宿。
- 它不写入天庭常规主线完成，不与凌霄主线高潮争夺章节终局。

## 十二时辰轮换

每四个连续时辰完成一轮，十二时辰共三轮：

| 时辰 | 当期方位 | 当期七宿 |
|---|---|---|
| 子、辰、申 | 东方青龙 | 角、亢、氐、房、心、尾、箕 |
| 丑、巳、酉 | 南方朱雀 | 井、鬼、柳、星、张、翼、轸 |
| 寅、午、戌 | 西方白虎 | 奎、娄、胃、昴、毕、觜、参 |
| 卯、未、亥 | 北方玄武 | 斗、牛、女、虚、危、室、壁 |

入场前必须由未来权威时间源生成 rotation_snapshot，锁定方位、难度与本次实例。副本进行中跨时辰、客户端改钟或本地时间不一致都不能改变当前副本。时区、换日时刻、时辰边界、快照恢复和维护回退仍需独立合同。

普通到噩梦还必须满足同方位匹配：普通完成快照的方位 = 夜巡钥/资格的方位 = 噩梦入场快照的方位。钥匙归属范围、重复普通完成、消耗、收据和断线补发均仍由未来权威实例与经济合同决定。

## 普通难度结构

每个方位的七宿按“前阵双宿 → 中阵双宿 → 后阵双宿 → 守位单宿”四段联动登场。每个星官都有独特的招牌动作，但同一方位共享一套空间语法；这使普通模式既能教会二十八个动作，又不会变成七个冗长大 Boss 的串行复刻。

| 方位 | 共享机制语法 | 团队协作压力 | 典型失败方式 |
|---|---|---|---|
| 青龙 | 连线、腾挪、风潮、路线重排。 | 维持队形并切断错误龙脉。 | 各自跑位导致星链互相覆盖。 |
| 朱雀 | 火种、传导、过热、灰烬复燃。 | 传递/净化火种并轮换安全区。 | 只追输出导致火场无可用区域。 |
| 白虎 | 猎印、围猎、反击、爆发窗口。 | 被点名者引导，队友援护并反制。 | 让猎印无处理地叠到同一目标。 |
| 玄武 | 封镇、壁障、潮汐、护甲拆解。 | 分工开墙、守点并保留通路。 | 只攻一侧，场地被甲壁完全切开。 |

## 噩梦：四圣兽与七宿双向共鸣

普通难度通关后，产出对应方位的“夜巡钥”候选，用于请求该方位噩梦准入。钥匙的真实物品 ID、归属范围、数量、消耗、过期、掉落和重复发放仍未决定。

| 阶段 | 场上关系 | 玩家解决的事 |
|---|---|---|
| 开场 | 对应四圣兽 + 七名同方位星官全部在场。 | 识别当前激活的一至两条星链，不能把战斗当成八单位血量竞赛。 |
| 星链处理 | 七宿各向圣兽提供宿曜贡辉；圣兽各向七宿提供圣兽庇护。 | 完成该星官的签名反制，把一条共鸣链转成净宿状态。 |
| 净宿窗口 | 已净宿星官停止为圣兽供能，并提供短暂的场地/路线帮助。 | 用净宿窗口削弱四圣专属机制，逐步创造核心暴露。 |
| 终局 | 七条链均处理后，圣兽核心进入可结算窗口。 | 完成最终净化；全程仍沿用实例快照所锁定的方位。 |

| 四圣兽 | 噩梦专属语法 | 玩家反制窗口 | 视觉与读条方向 |
|---|---|---|---|
| 青龙 | 巡天龙轨、风潮推拉、星链改道。 | 把净宿星链改为导流路径，让龙轨穿过空区。 | 云海盘龙、木青鳞光、长距离轨迹预警。 |
| 朱雀 | 火种过热、余烬复燃、火场重置。 | 把净宿余烬转为短暂庇护区。 | 赤羽、火环、由暗到亮的复燃读条。 |
| 白虎 | 猎印叠加、狩猎冲刺、反击撕裂。 | 让净宿轨迹反转为破甲窗口。 | 金白爪痕、低伏蓄力、明确点名标识。 |
| 玄武 | 甲壁封场、冥水切割、护壳轮换。 | 用净宿打开共守窗口，选择正确的破壁点。 | 厚甲、水幕、慢而清晰的墙体推进。 |

## 施工前门禁

- 每次入场必须冻结权威轮换快照；不能用客户端时钟、UI 展示或缓存时间决定方位。
- 机制必须可由最多四人完成；不假设第五人以上的职业或分工。
- 每个星官的技能、预警、反制需先经过对象、地图、战斗、同步与可读性专项评审，才可转为实际资产。
- 任何奖励要走版本化资源表、资格快照、幂等收据与持久化；本文不提供掉率、数量、保底或发奖实现。
