# 七星单人本规格

## 定位

七星是天庭阶段固定的七个可重复单人副本：天枢、天璇、天玑、天权、玉衡、开阳、瑶光。它们在朝会殿·周天观台开启，承担三件事：

1. 让玩家逐个理解“校星”而非“杀星”的核心动作；
2. 提供七种独立残片与星君称号的长期收藏目标；
3. 为二十八星宿的星链、方位和净宿语法做低压预习。

这取代了此前“蟠桃园 / 御马监二选一单人本”的旧假设；两地可作为主线场景或支线环境，但不再占用首发单人本名额。

## 统一关卡骨架

每一星都遵循“空间规则 → 星官身份动作 → 反转收束”的三段结构，而不是七次换皮单挑：

| 段落 | 玩家任务 | 失败含义 |
|---|---|---|
| 校星 | 观察该星的空间规则，激活正确锚点。 | 本段重置；实际检查点和复活方式由权威副本合同决定。 |
| 试炼 | 应对首领的招牌动作，制造净化窗口。 | 不能以纯输出跳过机制。 |
| 回正 | 将被污染的星轨反转为可利用路线，完成校正。 | 只结算权威清除结果，不在本文定义奖励发放。 |

真实地图、对象、技能 ID、施法时长、伤害、Boss 血量、检查点、掉落数量、资格和次数均未定义。

所有称号效果都是“效果方向”，不是数值 Buff。七星来自单人本，任何称号方向都必须有单人完整效用；组队语义最多扩展展示或可选协同，不能反向成为称号价值或获取后的多人硬依赖。冷却、范围、是否全局生效、PvP/PvE 边界、持久化和真实技能实现必须由战斗与权威结算合同另行裁决。

## 残片、称号与毕业法宝

### 七星残片

- 每一星只对应一种展示名残片：天枢残片至瑶光残片。
- 具体掉落次数、掉率、保底、资格、背包上限和实际物品键均为空。
- 残片在这里是离线材料类别，不可冒充 economy-v2 已存在的材料键。
- 十枚称号配方与“七种均齐备”的毕业法宝配方如何消耗、计数或共存，明确延期到经济合同；同一份残片不能在未裁决的情况下被两条配方隐式重复花费。

### 星君称号

- 用户指定规则：同一种残片累计十枚，可合成该星对应星君称号。
- 七个称号都带独立的非数值增益标签与展示方向。
- 集齐七个称号自动解锁“七曜集合称号”；最终名称仍待定。
- 集合称号汇集七个标签并展示完整七星图，作为唯一生效的七曜效果集合，不能与七个单称号重复叠加。

### 天庭毕业法宝

- 毕业法宝名称待定。
- 概念配方要求“七种残片均齐备 + 珍贵材料候选”。
- 四圣噩梦和天律线可以成为珍贵材料候选来源，但不得在本轮把单人毕业目标强制锁死为团队噩梦门票。
- 实际配方数量、材料名称、稀有度、属性、是否绑定、制造与收据均 deferred。

## 与主线和团本的学习闭环

| 七星学习 | 在二十八星宿中的回收 |
|---|---|
| 天枢的定轴与位移修正 | 青龙星链、玄武镇桩。 |
| 天璇的轨道预判 | 青龙行云与朱雀火环。 |
| 天玑的真假辨认 | 心月狐、女土蝠与白虎猎印。 |
| 天权、玉衡的平衡与调和 | 朱雀火候、玄武护壁的分工。 |
| 开阳、瑶光的开窗与收束 | 解除星链后对四圣兽的短暂反制窗口。 |

七星首通可承担“校星”叙事，但十枚残片的称号收集不是主线门票。

## 施工前门禁

- 新建七个副本前，先补齐单人会话创建、失败、清理、退出、重连和幂等语义。
- 新建材料/称号前，先为它们建立版本化资源表绑定、所有权、收据、重复处理与背包规则。
- 任何实际技能、特效、对象、Boss、地图、数值或 UI 均需走对应专项流程；本页不生成它们。
