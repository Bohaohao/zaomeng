# 天庭篇主线、遭遇与通天塔首轮路径

## 口径优先级

等级、成长、塔门槛和经济边界以全局设计基线、18-20 与成长数值和经济裁决登记册为准。世界观文件提供天门倾覆的高层因果和天庭内容方向；它不能替代尚未建立的天庭章节、进度、遭遇或副本合同。

## 已有世界观方向

第三劫的方向是：邪力沿命册与天门进入天庭，神将受控、玉帝被囚；承命者进入天庭调查危机，世界观将南天门至凌霄相关内容及玲珑塔主题作为范围锚点。该方向回答“为何天庭值得成为第三篇”，但还没有回答“哪个角色级事件开放天庭”“何处完成常规主线”或“团队内容与常规完成的关系”。

## 四层路径

| 层级 | 内容 | 当前约束 |
|---|---|---|
| 世界观方向 | 临时天庭主城、天宫道/南天门/天王殿外缘、神将失控、天律裂缝。 | 这是内容来源，不是物理地图或固定节点顺序。 |
| 章节主线角色 | 城市锚点 → 公共路线群 → 调查/升级节点 → 常规完成角色。 | 除城市与公共路线的方向外，节点、入口、前置、完成者与新进度键均 deferred。 |
| 可选单人内容 | 蟠桃园或御马监中的一项。 | 未选择，不可创建入口、对象、奖励或 runtime key。 |
| 团队与长期内容 | 凌霄宝殿方向的团队内容；玲珑塔主题并入全局通天塔。 | 团队内容的完成关系、入口和 Boss 未定；塔仅固定 Lv55 逐人门槛与每 5 层休整。 |

## 因果与边界

1. 地府篇的世界观后果可以为天庭危机提供叙事背景，但这不自动形成进度门槛。
2. DF_PROGRESS_YANLUO_HALL_CLEARED 当前只能由阎罗殿写入并由龙宫逆潮消费；天庭不可把它当作默认入场条件、替代键或奖励资格。
3. 天庭主线应在后续合同中明确一个角色级、受信任的入章与完成边界；在此之前，所有天庭章节节点只可使用 TT_SPEC_ 标识。
4. 单人本、团队本和通天塔都不能在未裁决前被写成天庭常规完成的前置或替代。
5. 玲珑塔只能强化天庭主题记忆，不能分裂记录、奖励或赛季为第二座长期塔。

## 通天塔首轮循环的当前可表达内容

~~~text
达到 Lv55 的每名参与者
-> 权威准入
-> 首轮子循环的五个抽象节拍依次推进
-> 第五节拍权威完成后打开休整，可请求既有已保存构筑切换
-> 结算 / 失败 / 自愿退出 / 下一循环交接互斥收束；重复请求返回既有权威结论
-> 下一循环、楼层、词缀与记录仍依赖独立合同；首轮奖励外部引用 runtime-closed economy-v2，implementation/growth/ 候选不得消费
~~~

五个节拍只描述首轮子循环的顺序和第五节拍休整点，不宣告总层数、下一节拍、主题顺序、首通/复刷规则、赛季或奖励数值。详见 [tower-first-cycle-state-contract.json](tower-first-cycle-state-contract.json)。

## 明确不在本轮决定

- 天庭入章的完成键、写入者、消费者、事件幂等和断线/重连语义。
- 天宫道、南天门、天王殿外缘的物理连接、地图坐标、区域等级、怪物、公共 Boss 和刷新。
- 蟠桃园与御马监的选择及全部实例细节。
- 凌霄宝殿与杨戬线的最终关系、团队规模以外的成员条件、战斗阶段和章节完成语义。
- 通天塔的 run 状态、记录范围、楼层计划、词缀、兑换目录、赛季和迁移；economy-v2 仅冻结首轮奖励与收据语义。
- 天庭具体经验 source_profile、掉落、材料、装备、法宝、宠物、资格和保底分配，以及它们的运行时接入。
