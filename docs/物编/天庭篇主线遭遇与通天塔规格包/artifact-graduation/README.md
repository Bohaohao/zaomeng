# 天庭毕业法宝定位与谱系包

## 状态

`offline-design-spec / positioning-and-lineage-accepted / production-gate-closed`

本包以父合同为唯一定位来源，并由完整设计子包细化既有 `TT_SPEC_SEVEN_STAR_GRADUATION_ARTIFACT`／**周天校律盘**的同槽替换、玩法语义、七星材料关系、可读性、失败边界与未来结算前置。

它不创建 Y3 物品、能力、材料、掉落、配方、数值、货币、资格、收据、存档或运行时键。

## 已冻结的结论

- 天庭毕业法宝是 `high / endgame` 的**可选构筑收束件**，与花果山、地府法宝共用 v1 唯一活动槽；它不是天庭入章、主线、七星、星宿、通天塔或毕业的门票。
- 正式显示名冻结为**周天校律盘**；“七曜毕业法宝”保留为说明性称谓。二者都不等同于 `ART_TT_*` 或真实物品键。
- 它的玩法语义是“读星 → 正确反制 → 校律归位窗口”。未来可在构筑预设中选择定序、辨序或开序之一；三者分别只响应 `stabilize`、`discern`、`open`，错配即失效且不出回应卡，不并发、不自动完成机制，也不重叠七曜或四象称号的效果集合。
- 七星七种残片仍是概念配方的必要类别；十枚同星残片合成星君称号的规则保持不变。二者的实际扣除、计数、保留、收据与防双花账本必须由未来经济合同一次性裁决。
- 基础毕业路径必须保留单人完整可达的常规／天律催化剂路径；四圣噩梦只可对应四象覆环的可选展示／叙事印证，不能成为基础毕业材料、战斗强度来源或唯一必需团队门票。
- 旧法宝不会因天庭推进被自动消耗、降级、静默失效或以纯倍率宣告淘汰。未来迁移只能由独立谱系、经济和收据合同授权。
