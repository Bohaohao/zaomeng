# 周天校律盘｜完整离线设计包

本目录冻结天庭毕业法宝 **周天校律盘**（文档别名：七曜毕业法宝）的完整离线设计。唯一机器事实源为 [tianting-graduation-artifact-complete-design-contract.json](tianting-graduation-artifact-complete-design-contract.json)；本目录中的人类可读说明、决策登记与规格化摘要都不得与它冲突。

## 本包回答的问题

- 周天校律盘在天庭后段的定位、五段获得/理解路径与前序法宝的并存关系。
- 定序、辨序、开序三种互斥构筑形态分别帮助玩家读懂什么，且不会替玩家完成什么。
- 七星残片、天律校印、四圣铸核的设计级来源关系，以及四象覆环的可选展示定位。
- 称号收藏、四职业兼容、双通道可读性、失败/断线/清理优先级和未来施工数据面。

## 本包不做什么

这是纯离线设计，不创建或授权以下任何内容：

- Y3 物编、Lua、真实物品/能力/材料键、资源 ID、存档、进度键或会话字段；
- 攻击、防御、伤害、冷却、持续时间、距离、目标数、推荐装备等级或职业强度；
- 掉率、保底、材料数量、配方、消耗、资格、奖励、结算或经济收据；
- 对现有主线、七星、星宿、四圣、称号、清理、复活、断线和轮换权威合同的写入权限。

## 施工前门槛

周天校律盘可以作为后续施工输入，但还不能直接物化。以下门槛必须先被独立采纳：

1. P0 跨职业战斗绝对标定，才可讨论任何属性、强度、技能时间或最佳构筑。
2. 经济与权威收据合同，才可定义材料数量、配方、来源 profile、资格、消耗、掉落、保底与重放结算。
3. 既有天庭权威会话、遭遇反制、构筑预设和 UI 无障碍合同的真实运行时接入，才可让“校律回应窗口”成为玩家可见的行为。

在上述门槛完成以前，三形态只表达已验证信息的可读性，不承诺任何数值战斗收益。
