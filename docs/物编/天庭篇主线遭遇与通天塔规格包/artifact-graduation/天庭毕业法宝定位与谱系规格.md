# 天庭毕业法宝定位与谱系规格

## 一句话结论

天庭法宝是七星学习闭环的“高阶构筑收束”，不是把旧法宝数值清零的升级券，也不是星宿、四圣或主线的准入门票。

正式显示名冻结为**周天校律盘**；“七曜毕业法宝”仍是既有说明性称谓。它复用 `TT_SPEC_SEVEN_STAR_GRADUATION_ARTIFACT`，不创建 `ART_TT_*`、Y3 物品或资源 ID。完整的玩家行为、来源证据与失败边界见[完整设计子包](complete-design/README.md)。

## 1. 玩家为什么会想装备它

七星分别教会玩家稳定轴线、读回环、辨真伪、处理承压、调和资源、把握开门和完成收束。毕业法宝不再额外塞入第八套机制，而是把这七种学习压缩成一次可选择的“校律回应”：

1. 玩家先读到预警、自己完成正确反制。
2. 反制已经建立归位窗口后，法宝才可表达一次构筑偏好。
3. 该回应只能是预设中的一类：定序、辨序或开序。

它因此强化“判断后获得回报”的手感，而不是自动扫除复杂机制。

| 校律形态 | 承接的七星学习 | 适合的玩家偏好 | 明确不做 |
|---|---|---|---|
| 定序 | 天枢、天权、玉衡 | 稳定位置、承压和秩序回收 | 不提供复活、无敌或清理锁豁免 |
| 辨序 | 天璇、天玑 | 读星轨、辨识真伪、把结果看清 | 不自动找真身、显示一切预警或代做验证 |
| 开序 | 开阳、瑶光 | 把握开阙、追击和收束时机 | 不无条件造输出窗或跳过门阵、星链、净宿 |

具体技能、属性、伤害、冷却、持续时间、范围与特效都还没有数值或对象定义。

## 2. 与旧法宝如何共存

法宝槽只有一个。玩家始终可以在集结点等合法节点，于完整构筑预设中选择：

- 保留并使用花果山的 `ART_HG_TIDE_SEAL` 或 `ART_HG_FLAME_CORE`；
- 保留并使用未来地府的中期构筑法宝；
- 选择七曜毕业法宝的一个校律形态。

这不是强迫替换链。天庭推进、七星收集、主线完成或进入团队本都不会销毁、降级或自动换掉旧法宝。挑战、死亡、断线和清理锁期间也不能临时改选。

## 3. 材料、称号和四圣的关系

基础配方的概念仍是“七种残片均齐备 + 珍贵催化剂”。本轮只确定了关系，不虚构任何 `MAT_*` 键、数量或掉率：

- 七星残片：每个单人本只对应自己的一种残片类别；毕业法宝需要七类齐备这一事实。
- 星君称号：同星累计十枚残片的用户规则不变；七曜集合称号仍替代七个单称号，而不是叠加。
- 防双花：一枚残片到底是被毕业法宝消耗、被称号计数、被保留还是被转换，只能由后续单一经济账本裁决；当前不能同时假定两份配方都花掉它。
- 常规催化剂：基础毕业路径必须有不依赖团队噩梦的常规／天律来源。
- 四圣噩梦：只可对应四象覆环的可选展示／叙事印证；不能成为单人毕业法宝材料、战斗强度来源或唯一必需团本门票。

四圣和七曜称号的展示、效果标签与毕业法宝的校律形态必须各自结算，不能做成“称号越多、法宝被动越叠”的隐性数值层。

## 4. 推荐的成长位置

| 阶段 | 法宝关系 | 推荐理解 |
|---|---|---|
| 花果山 | 可选早期／稀有横向法宝 | 保留，不因后续篇章失效。 |
| 地府 Lv21–40 | 中期构筑转向 | 与旧法宝同槽竞争，提供局面处理差异。 |
| 天庭 Lv41–60、周天观台后 | 开始七星收集与学习闭环 | 不是立即必须装备，也不设未采纳的精确装备等级。 |
| 天庭常规后段 | 七曜毕业法宝的可选长期目标 | 基础路径必须单人完整可达；实际取得等级仍待来源和经济合同。 |
| 星宿／四圣长期循环 | 四象覆环的可选展示／叙事印证 | 不反向把团队噩梦变成基础毕业材料、战斗强度来源或主线门槛。 |

## 5. 未来施工顺序

1. 采纳天庭 source-profile、逐人资格和收据合同，先让七星／星宿的完成事实有合法的经济消费者。
2. 再裁决七类残片、催化剂、称号和毕业法宝之间的占用／消耗账本，防止双花和断线补领。
3. P0 外部实证七道门全部采纳后，才能填写四职业下的法宝绝对属性、伤害、冷却、时长和秒数。
4. 最后才进入物编、Lua、UI 和实际会话接入。
