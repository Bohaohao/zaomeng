## 2. 全篇表现语法

### 2.1 优先级

| 级别 | 必须保护的信息 | 允许承载方式 | 禁止被什么遮挡或替代 |
|---|---|---|---|
| P0：生存与反制 | 首领轮廓、前摇、目标归属、路径、可交互状态、反制结果。 | 清晰姿态、几何轮廓、轨迹、场地形态，加声音/文字/状态提示之一。 | 环境粒子、屏幕装饰、仅颜色差异、仅聊天文本。 |
| P1：阶段与协作 | 当前机制阶段、队友处理方向、净宿援护、可用退路。 | 场地变化、连线/缺口/开口、简明状态提示。 | 与 P0 同形同层、过量残影、不可交互背景。 |
| P2：氛围与收藏 | 云海、星图、天律残页、方位文化纹样、胜利余韵。 | 背景、远景、低对比环境层。 | 不得伪装为 P0/P1 提示，也不得掩盖行动区。 |

### 2.2 特效层级

1. **L0 轮廓层**：角色/机关/场地区域的稳定形态，用来回答“谁在行动、哪里可走”。
2. **L1 前摇层**：起手姿态、方向、轨迹起点或状态形变，用来回答“接下来会发生什么”。
3. **L2 关系层**：目标线、链路、区域边界、可用缺口或净化关系，用来回答“它指向谁、影响哪里”。
4. **L3 结果层**：净化、改道、开口、护持、破绽或失败结果，用来回答“处理是否生效”。
5. **L4 氛围层**：云、星尘、残页、余烬、水幕等低优先级陪衬；它必须让位给 L0–L3。

关键预警至少要有一个 L0–L3 的空间/形状信号，外加声音、文字、状态符号或场地变化中的一种独立辅助。颜色不能是唯一信息通道。

### 2.3 通用依赖

| 依赖 | 使用方式 | 本蓝图不负责的部分 |
|---|---|---|
| 权威阶段状态 | 只把已确认的阶段、目标归属、净宿和会话告知投射为表现。 | 不判定资格、进度、成员、时辰、成功或清理。 |
| 候选场地职责 | 为观察、决策、反制、退路和交互留出视觉职责。 | 不绑定地图、地形、坐标、碰撞或入口。 |
| UI/音频辅助 | 作为第二通道，补足俯视角、屏幕拥挤或听觉不可用时的信息。 | 不替代场上轮廓，也不产生本地权威状态。 |
| 后续物编 | 将本蓝图转化为资产清单前，必须另行裁决对象类型、ID、模板、属性和数值。 | 不生成插件、Y3 JSON 或任何对象。 |
