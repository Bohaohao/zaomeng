# 西游记与造梦视觉机制参考

## 使用边界

本页只记录创作参考：保留星官全名、提炼“天界星官仍有职责与个体动作”的叙事质感，并以造梦式的清晰轮廓、读条、机关预警作为视觉可读性目标。所有关卡、技能、数值、美术、音效、文本和资产均须原创，不复制外部游戏资产或原文长段落。

## 可采纳的文学灵感

- 《西游记》第九十二回出现角木蛟、斗木獬、奎木狼、井木犴等木部星官，并把井木犴写成近身擒猎、追拿型角色。这支持把井木犴设计为“飞扑、撕咬、拖拽”的朱雀七宿签名动作，而非泛化的远程法师。[《西游记》第九十二回](https://zh.wikisource.org/zh-hans/%E8%A5%BF%E9%81%8A%E8%A8%98/%E7%AC%AC092%E5%9B%9E)
- 《西游记》第三十一回把奎木狼放在天上星宿与下界失序之间，提供“星官可能偏离自身天职、但仍可回归星位”的叙事参照。它被转译为本包“净宿而非永久杀死星官”的处理方式。[《西游记》第三十一回](https://ctext.org/xiyouji/ch31/zhs)

## 项目内参考

项目既有资料曾把天宫道、南天门、天王殿、彩虹楼、朝会殿、凌霄作为造梦式天庭推进素材，并将星宿阵纳入后期内容库。它们在本包中被重新组织为“主线收束 → 七星成长 → 四象团队挑战 → 通天塔复用”，不把旧资料直接视作已实现关卡。[造梦西游 1–6 原作资料总表](../../../09-造梦西游1-6原作资料总表.md)

## 美术与可读性方向

| 类型 | 方向 | 避免项 |
|---|---|---|
| 星官 | 用动物、五行与方位做第一识别点，第二识别点是兵器或施法姿态。 | 二十八名只靠换色盔甲区分。 |
| 四圣兽 | 大轮廓优先于装饰细节；普通与噩梦用星链/庇护显式区分。 | 把双向加成藏在不可读的数值图标里。 |
| 场地 | 云海、金玉台、裂律符文与星盘结构形成方向感。 | 用密集粒子遮住星链、火环和安全缺口。 |
| 读条 | 起手、路径、落点、反制窗口均先给形状与颜色，再给文字。 | 仅靠伤害数字提示机制。 |
