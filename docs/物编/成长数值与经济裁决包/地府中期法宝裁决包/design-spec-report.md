# 地府中期法宝设计规格报告

## 一句话定位

把地府法宝固定为“中期局面处理构筑层”：玩家可在单槽中保留花果山法宝，或在镇魂引灯、勘命业镜之间作选择；回正是章节共享正确结果而不是第三件法宝。这不是强制合成链，也不是天庭门票。

## 已结构化内容

- 三篇阶段职责与地府 `medium` 定位；
- 单活动槽、构筑预设与挑战锁兼容；
- 常规路线确定性选择的最低可达性；
- 花果山法宝的保留、同槽选择和未来显式迁移；
- 对阎罗殿进度、天庭入章、死亡、断线和清理边界的禁止项；
- 镇魂引灯（镇魂／守序）与勘命业镜（勘命／破妄）两件 spec-local 身份、语义能力卡与三段成长路线；
- 回正／归律作为全篇共享正确结果，禁止被法宝独占、自动触发或解释成回滚；
- 对经济、配方、材料和收据的延迟决策。

## Y3 适配与范围

设计适合 Y3 的 2.5D、1–4 人会话与可读战斗空间：法宝只改变构筑选择与战斗语义，不能替代会话权威、死亡处理或地图交互。当前未创建 Y3 物品、单位、技能、Lua、UI 或地形。

## 最小施工建议

真正进入施工时，应先验证接引院后的镇魂引灯纵切与单槽预设切换，再验证判官殿后的勘命业镜纵切。白骨秘境和转轮殿只能承担横向机制验证，不能变成两件基础法宝的来源前置；可选变体、迁移和天庭继承都应排在两条纵切验证之后。

## 未决与前置

资产键、技能、数值、来源、掉落、材料、配方、收据与迁移均未采纳。下一步必须先完成跨职业绝对标定，并独立建立地府 `source_profile` 与权威收据输入，才能为任何具体法宝填值。
