# 地府双法宝详细设计

## 总结

地府中期只做两件法宝：**镇魂引灯**和**勘命业镜**。前者让玩家守住已经亲自核验的正确秩序，后者让玩家在伪证、改写和变形后继续追溯已经亲自核验的证据。

它们不代替地府的“命册证据 → 裁决 → 回正”循环：**回正是所有遭遇的共同正确结果，不是第三件法宝，也不是两件法宝自动附带的万能解法。**

## 1. 位置与换装

| 法宝 | 主轴 | 叙事锚点 | 建议开始理解的时序 | 不是 |
|---|---|---|---|---|
| 镇魂引灯 | 镇魂／守序 | 接引院的魂印识别 | 接引院后、阎罗殿前 | 减伤灯、免死灯、自动判定器 |
| 勘命业镜 | 勘命／破妄 | 判官殿的命册校勘 | 判官殿后、阎罗殿前 | 自动验真器、跳机制器、真相透视器 |

- 两件均是常规主线中的**语义锚点**，尚不是现有的奖励事件或物品授予。
- 角色未来可以同时拥有两件，但 v1 只有一个活动法宝槽；花果山两件法宝、两件地府法宝和天庭毕业法宝都争用这一槽。
- 只允许通过既有构筑预设整体切换。挑战、死亡、断线或清理锁期间不能局部切换。
- 不拥有、不领取或不装备任何地府法宝，仍能完成地府常规主线并进入天庭。

## 2. 镇魂引灯

### 定位

镇魂引灯解决的是“我已经读对了，但在压力、遮蔽或错误牵引中，怎样不丢掉这个正确关系”。它不是给玩家更高面板，也不是把不确定信息直接变成答案。

### 技能卡：守序引路

1. **前置**：玩家已亲自核验一条合法魂印、正确通路或待交接的证据关系。
2. **输入**：玩家指定该关系，建立引灯护持。
3. **正确响应**：压力或错误牵引出现时，已证实的关系仍显示形态、方向与交接提示；玩家仍需自行应对威胁、继续核验并手动回正。
4. **错误响应**：未证实或矛盾的关系只显示“未证实／矛盾”反馈，不会偷偷替换成正确目标。
5. **双通道**：灯焰形态、魂印轮廓或路线投影 + 独立铃音、语音或 UI 守序文字。

### 三段语义成长

| 阶段 | 玩家学会什么 | 材料主题（非物品键、非消耗） |
|---|---|---|
| 认印 | 只能护持自己已经读对的关系 | 魂印灯芯 |
| 定序 | 多目标压力中维持已证实关系的可读和可交接 | 魂印灯芯、引渡丝 |
| 明渡 | 正确处理后留下可复盘的交接痕迹 | 引渡丝 |

### 副本对应

- 无常巷：暂缓一侧时，保住另一条已核验魂印。
- 鬼门关：维持合法通行关系，避免把冲门误当唯一解。
- 接引院：保护已确认归属，为冲突记录留下校勘时间。
- 阎罗殿：使已保全的真证据在覆盖压力下不完全失读。
- 转轮殿：可辅助保留已互证的记忆交接，不能成为团队硬职责。

## 3. 勘命业镜

### 定位

勘命业镜解决的是“我已经找到了证据，但它被伪证、改写或形态变化覆盖后，怎样不丢掉上下文”。它保留的是可复核的来源关系，不是把所有隐藏答案直接照出来。

### 技能卡：回照留痕

1. **前置**：玩家已亲自完成一次魂印、命册条目、因果链或行为线索核验。
2. **输入**：玩家指定已证实关系，留下同源回照痕迹。
3. **正确响应**：同源目标变形、条目改写或伪证覆盖后，来源关系仍可追溯；玩家自己完成下一次核验、驳回与回正。
4. **错误响应**：没有首轮核验或证据矛盾时，只显示冲突摘要；不提前揭示全部真伪、不自动打断或提交。
5. **双通道**：镜面纹路、同源刻痕或因果连线 + 独立回音、判词语音或 UI 证据摘要。

### 三段语义成长

| 阶段 | 玩家学会什么 | 材料主题（非物品键、非消耗） |
|---|---|---|
| 留痕 | 保存已证实线索的来源 | 业镜纹 |
| 反证 | 伪证遮蔽时仍看清可继续阅读的矛盾关系 | 业镜纹、判词朱墨 |
| 正鉴 | 正确反制后保留手动回正所需的证据摘要与复盘线索 | 判词朱墨 |

### 副本对应

- 判官殿：保留被篡改条目与真实因果链之间的已证实关系。
- 白骨秘境：最适合的单人验证场；同源魂印跨形态持续，但必须玩家自己辨别遮蔽、诱导和暴露。
- 阎罗殿：命册再次改写时，保全过的证据仍可成为反证依据。
- 转轮殿：帮助成员显式交接已核验记忆链，不代替互证。

## 4. 材料与升级边界

“魂印灯芯、引渡丝、业镜纹、判词朱墨”仅是法宝成长的**叙事材料主题**。它们不是当前材料键、掉落、数量、消耗或配方；也不能挪用花果山的 `MAT_ARTIFACT_DUST` 或 `MAT_ADVANCE_HG`。

两件法宝的三段成长同样是语义成长，而不是已授权的升阶系统。未来若要给出材料来源、掉率、保底、消耗、属性、冷却、时长或数值，必须同时通过地府 source-profile、跨职业实证、经济收据和迁移合同。

## 5. 明确禁止

- 自动判真、自动选择目标、自动提交裁决、自动回正或跳过机制；
- 伤害、护盾、减伤、冷却、时长、范围、目标数或任何绝对战斗值；
- 额外复活、死亡撤销、会话回滚、清理锁绕过、完成键覆写；
- 以白骨秘境、转轮殿、稀有、重复挑战或通天塔作为基础取得或升级的唯一来源；
- 读取、写入或替代 `DF_PROGRESS_YANLUO_HALL_CLEARED`，或把法宝作为天庭交接证明；
- 自动消耗、删除、降级或折算花果山法宝。
