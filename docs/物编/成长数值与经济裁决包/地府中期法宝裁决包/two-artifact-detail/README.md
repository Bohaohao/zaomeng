# 地府双法宝详细设计包

## 状态

`offline-design-spec / accepted-design-detail / production-gate-closed`

本包把地府中期法宝从“方向性定位”细化为**恰好两件**可复审的规格身份：接引院后的**镇魂引灯**，以及判官殿后的**勘命业镜**。

它冻结展示名、主轴、叙事锚点、非数值技能步骤、语义成长、材料主题、遭遇适配、无障碍反馈和跨篇禁止项；它不创建真实物品、技能、材料、掉落、配方、数值、货币、资格、收据、Y3 对象或运行时键。

## 决定

- 地府只有两件中期法宝：`DF_SPEC_ARTIFACT_GUIDING_LANTERN`（镇魂／守序）与 `DF_SPEC_ARTIFACT_KARMIC_MIRROR`（勘命／破妄）。
- **回正／归律**改为全章节共享的正确结果，不再被任何法宝独占；两件法宝只能帮助玩家守住或读清已经亲自完成的判断，不能替玩家回正。
- 两件都以接引院、判官殿的常规主线节点作为**语义锚点**，而不是当前已经存在的奖励来源。真实事件、资格、来源档案和收据仍待权威经济合同。
- 白骨秘境是业镜的单人检验场，转轮殿是两件法宝的多人横向检验场；二者均不能成为基础取得、升级、主线或跨篇资格的唯一来源。
- 两件可同时拥有但只能启用一件；同花果山和未来天庭法宝共享 v1 唯一活动槽，挑战、死亡、断线或清理锁期间禁止局部换装。
