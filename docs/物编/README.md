5. 装备部位、品质、词条池、强化、进阶和职业限制。
6. 法宝本体、随机词条、洗炼、追加、合成与升阶。
7. 宠物本体、相性、成长、孵化和技能槽。
8. Y3 资源映射、批量生成和验收规则。
