## 必须按顺序解除的门禁

1. 连接真实 Y3 地图，查询现有单位、技能、效果与投射物 ID。
2. 查询并登记模型、头像、图标和特效资源；不得猜测资源 ID。
3. 将花果山公共白盒的逻辑资源写入地图，回读 `spawn_*`、`arena_*`、`area_hg_*` 与 `pt_hg_*`；再分别补齐龙宫四房与牛魔旧战场的内部资源契约。
4. 绑定可信角色进度验证器，并将已完成的离线权威遭遇 Lua 接入真实地图脚本根：补齐刷怪、仇恨、重置、伤害、破韧、参与、实例锁和清理确认的 Y3 回调。
5. 按依赖顺序创建投射物/效果 -> 能力 -> 单位，热更、等待、保存后回读关键字段。
6. 进行单人、四人、晚入场、断线、Boss 重置、龙宫四房与牛气冲天实机验证；其中须覆盖“死亡复活回当前篇章初始出生点、同一团队会话不可重入、匹配清理确认后才解锁”的真实地图回归。

## 通过标准

离线阶段只允许声明“规格与门禁通过”。只有完成真实对象创建、热更保存、回读和实机验证后，单个对象或遭遇才能标为 `implemented` 或 `verified`。
