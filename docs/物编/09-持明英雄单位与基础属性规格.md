## 一、横向定位

| 维度 | 定位 | 说明 |
|---|---:|---|
| 裸装生命 | 较低 | 远程站位与短窗自护交换承伤 |
| 法术攻击 | 较高 | 技能伤害以 `法术攻击` 为唯一职业主系数 |
| 双防 | 偏低 | 不能把护盾当作常驻坦度 |
| 移动 | `3.65` | 高于镇界，服务于净化后的脱离 |
| 攻速/间隔 | `96 / 1.10s` | 中距离法术普攻，不产生法印 |
| 团队保护 | 次级 | 短护幕与移速，不提供团队减伤主位 |

## 二、成长公式

```text
最大生命 = round(590 + 64 × (等级 - 1))
物理攻击 = round(24 + 2.2 × (等级 - 1))
法术攻击 = round(52 + 6.1 × (等级 - 1))
物理防御 = round(18 + 1.6 × (等级 - 1))
法术防御 = round(22 + 1.8 × (等级 - 1))
```

固定属性：最大魔法 `0`、暴击率 `5%`、暴击伤害 `150%`、命中 `100%`、闪避 `0%`、冷却缩减 `0%`、法印 `0-3`、绝技值 `0-100`。双防与法攻成长、法印和绝技值由 Lua 按完整等级幂等重算，不能逐级累加。

## 四、普攻与待验证项

普攻是中距离法术投射，不生成法印，不得作为 C03-BAL-001 的资源来源。普攻类型、射程、转身、碰撞、视野、模型、头像和技能列表均待真实项目回读；不得猜测枚举、资源 ID 或范围换算。

## 五、验收

- Lv1/Lv20/Lv40/Lv60 属性与表一致，多次初始化的结果相同。
- 远程普攻不生成法印；死亡、入本、失败、跨层、销毁和重连清理法印与绝技值。
- 四名持明不同等级同时存在时，属性、法印、明痕、律印、护盾和回调不串值。
- 创建真实单位后回读远程模板、普攻类型、射程、视野、转身和模型资源。
