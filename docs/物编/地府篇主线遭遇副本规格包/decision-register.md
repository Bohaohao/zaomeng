## 本轮离线设计结论

| ID | 结论 | 状态 | 约束 |
|---|---|---|---|
| DF-DESIGN-001 | 以十个 `spec_id` 保留鬼城至转轮殿的内容素材，并以独立 spec-local 角色登记白骨秘境。 | `offline_design` | 除阎罗/转轮两个既有 key 外不新增运行时 key。 |
| DF-DESIGN-002 | 参考顺序、常规完成会话、可选并行白骨单人本、固定团队终点和延期团队路线分层。 | `offline_design` | 参考顺序、白骨与转轮的叙事位置均不能被当成物理拓扑、内部前置或阎罗完成键消费。 |
| DF-DESIGN-007 | 接引院的异常档案与判官殿的审判揭示为转轮一系重置企图提供叙事承接。 | `offline_design` | 该承接是非物理、非门槛的叙事伏笔；不新增 key、入口、前置或运行时条件。 |
| DF-DESIGN-006 | `DF_CHAPTER_SPEC` 仅作为 `spec_chapter_id` 使用。 | `offline_design` | 显式标注为规格局部标识，绝不作为运行时章节 key。 |
| DF-DESIGN-003 | 鬼灯、无常、关隘、审判、魂河、桥面、梦境和轮回重置以主题标签表达。 | `offline_design` | 不创建单位、技能、波次、状态或伤害数据。 |
| DF-DESIGN-004 | 地府内容只登记奖励来源类别。 | `offline_design` | 所有结算细节继续指向成长数值与经济裁决包。 |
| DF-DESIGN-005 | `chapter_initial_spawn` 是逻辑角色而非资源键。 | `offline_design` | 必须由真实地图工程回读后才能绑定。 |
