# 地府篇主线与遭遇路径

## 口径优先级

副本分类、完成键与团队清理以全局设计基线、成长契约和地府篇前置接口包为准；本文件中的鬼城至转轮殿顺序只继承参考内容的叙事素材，不能覆盖已固定的“阎罗殿为常规最终、转轮殿为团队本”结论。

## 三层路径

| 层级 | 内容 | 约束 |
|---|---|---|
| 参考顺序 | 鬼城 → 无常巷 → 鬼门关 → 接引院 → 判官殿 → 阎罗殿 → 忘川河 → 奈何桥 → 望乡台 → 转轮殿 | 保留来源和主题，不代表已确定的地图邻接或入口条件。 |
| 常规完成路径 | 鬼城 → 无常巷 → 鬼门关 → 接引院 → 判官殿 → 阎罗殿 | 常规篇章在阎罗殿收束；只有其权威成功事件能写入 `DF_PROGRESS_YANLUO_HALL_CLEARED`。 |
| 团队内容路径 | 忘川河 / 奈何桥 / 望乡台 → 转轮殿 | `DF_E_ZHUANLUN_HALL` 是固定团队终点；前三节点、入口与物理拓扑仍为 `deferred`，不得默认消费阎罗完成键，亦不得成为其写入者。 |

## 因果检验

1. 鬼城的流转失灵导致无常巷与鬼门关的外部阻塞，而不是无关联的区域串联。
2. 外部阻塞迫使玩家进入接引院和判官殿，发现问题来自命册与审判体系本身。
3. 该发现因此将玩家导向阎罗殿；阎罗殿完成后，常规主线状态发生永久变化并写入唯一可信完成键。
4. 转轮殿作为固定团队终点保留“修复秩序是否等于重置众生”的更高层问题；忘川、奈何和望乡及通向转轮殿的实际路线仍不回写、替代或稀释常规完成结果。

## 明确不在本轮决定

- 转轮殿的地府内部入口条件、人数之外的组队规则、战斗阶段参数和实际路线。
- 白骨秘境的隐藏/非隐藏入口可见性、实际入口、时长、阶段、对象和奖励；它固定为规格局部的地府单人本职责，但不拥有运行时 key。
- 鬼城、忘川、奈何、望乡的物理连接、坐标、资源、地形和刷怪。
- 经验、掉落、货币、法宝、抗性装备、资格、保底与资源吞吐。
