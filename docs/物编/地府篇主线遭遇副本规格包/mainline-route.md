# 地府篇主线与遭遇路径

## 口径优先级

副本分类、完成键与团队清理以全局设计基线、成长契约和地府篇前置接口包为准；本文件中的鬼城至转轮殿顺序只继承参考内容的叙事素材，不能覆盖已固定的“阎罗殿为常规最终、转轮殿为团队本”结论。

地府入章采用同一角色的 `Lv20 +` 花果山常规收束证明，`Lv21-40` 只描述成长带；具体证明、幂等和拒绝边界见地府篇前置接口包。每个节点的战斗语法、预警、反制、失败复盘、1–4 人适配与无障碍双通道以 [combat/地府战斗机制与可读性规格](combat/地府战斗机制与可读性规格.md) 为唯一详细来源；本文件不复制其运行时或数值字段。

## 因果检验

1. 鬼城的流转失灵导致无常巷与鬼门关的外部阻塞，而不是无关联的区域串联。
2. 外部阻塞迫使玩家进入接引院和判官殿，发现问题来自命册与审判体系本身；异常档案与审判记录同时为转轮一系的重置企图留下非物理、非门槛的叙事伏笔。
3. 该发现因此将玩家导向阎罗殿；阎罗殿完成后，常规主线状态发生永久变化并写入唯一可信完成键。
4. 白骨秘境是可选、并行、非阻塞的独立单人本；它不在上述因果链中，不要求阎罗完成，也不成为阎罗常规完成路径的前置。
5. 转轮殿作为阎罗叙事收束后的独立团队内容保留“修复秩序是否等于重置众生”的更高层问题；忘川、奈何和望乡及通向转轮殿的实际路线仍不回写、替代或稀释常规完成结果，也不由阎罗完成键推导入口。
