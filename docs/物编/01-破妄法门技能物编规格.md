## 一、物编包范围

| 对象类型 | 数量 | 内容 |
|---|---:|---|
| 技能 `ability` | `18` | 8 个主动、8 个学习型被动、1 个固定职业被动、1 个三阶绝技 |
| 魔法效果 `modifier` | `12` | 洞明、显妄、真境、护盾、减伤、个人破隙及其他状态载体 |
| 投射物 `projectile` | `0` | 首发均为近战判定、延迟区域或回响，不建立飞行弹道 |
| 单位 `unit` | `0` | 破妄英雄单位和基础属性另立文档 |
| 物品 `item` | `0` | 武器、装备和法宝不在本文件范围内 |

首批物编包合计 `30` 个对象。技能对象先承载图标、等级、冷却、指示器和学习门槛；属性倍率、多段命中、战势、位移、破韧和状态覆盖统一交给同步 Lua。

## 二、统一记录头

除表内特别说明外，全部记录使用以下公共字段：

```yaml
status: reviewed
operation: create
y3_id: 待查询分配
chapter: 职业系统/破妄法门
source_doc: docs/归档/职业设计/02-破妄法门资源循环与完整技能组.md
icon_id: 待查询
model_id: 不适用
```

规则：

- `record_key` 是策划侧稳定键，不等于 Y3 数值 ID。
- 未查询真实项目现有 ID 前，所有 `y3_id` 保持“待查询分配”。
- 未查询官方和项目资源前，所有图标、动画、音效和特效保持待映射。
- `ability_cast_type` 采用 `y3-lualib main@fe2fb0e` 的 `y3.const.AbilityCastType`：主动与绝技为 `2`，固定被动和学习型被动为 `3`。
- 设计身位尚未换算为 Y3 引擎距离，几何字段在本稿中保留设计值和待映射字段。
- 物编 `ability_damage` 全部置零，防止与 Lua 属性倍率伤害重复结算。
- 破妄不使用普通蓝耗，`ability_cost` 和 `ability_hp_cost` 全部置零；战势由同步 Lua 扣除。

## 七、依赖与创建顺序

```text
第一批：12 个 modifier 基础对象
    ↓
第二批：C01_F01、C01_P01-P08 被动技能对象
    ↓
第三批：C01_A01-A08 主动技能对象
    ↓
第四批：C01_U01 绝技对象
    ↓
第五批：破妄英雄单位绑定、技能树数据和同步 Lua
```

- 首发不创建投射物。贯心风压、断岳二斩、定真裂痕和绝技回响使用定时区域判定与特效表现。
- 英雄单位的技能绑定列表必须等真实技能 ID 分配后再填写。
- `C01_A01-A08` 是技能树可学习对象，不等于玩家五槽中的固定 Q/W/E/R 键位；五槽由构筑预设动态绑定。

## 八、未解析字段与执行门槛

| 待解析项 | 原因 | 解决方式 |
|---|---|---|
| 30 个 Y3 数值 ID | 当前无真实项目 ID 台账 | 接入地图后查询现有技能、效果 ID，再分段分配 |
| 30 个图标 ID | 当前未查询官方和项目资源 | 使用资源查询后建立图标映射表 |
| 身位到引擎距离换算 | 尚无破妄英雄碰撞和镜头白盒 | 实机校准 1 身位后批量换算几何数组 |
| 动作、特效、音效 ID | 尚未选定资源 | 先做资源审查，再写表现依赖 |
| 被动技能底层模板 | 不确定项目是否已有稳定被动模板 | 查询并选择 `copyFrom`，不直接用主动模板猜测 |
| 动态护盾和属性修改 | 基础脚本字段不足 | 保留 modifier 外壳，由同步 Lua 计算 |
| 绝技槽绑定 | 属于英雄和 UI 系统 | 在英雄单位、技能栏与存档规格中统一处理 |

只有以上字段完成查询，并且所有对象进入 `id-assigned` 状态后，才能生成 `y3_obj_edit.py` 命令或 Y3-Helper 物编插件。

## 九、执行与验收

### 9.1 创建前检查

- 查询现有自定义技能和魔法效果，确认没有记录键对应对象。
- 建立 ID 台账并检查 `type:key` 唯一性。
- 回读同类技能确认被动模板和距离尺度；若真实项目内置库与固定 API 基线冲突，再复核 `ability_cast_type`。
- 所有五级数组长度必须恰好为 5，绝技数组长度必须恰好为 3。
- `ability_damage`、蓝耗和血耗保持零数组，避免基础物编抢先结算。

### 9.2 创建后验收

- 先创建 12 个效果，再创建 18 个技能；全批次只热更一次，等待 3 秒后保存。
- 回读 30 个对象的名称、最大等级、冷却、学习等级、指示器和效果分类。
- 确认 8 个主动均能被技能树学习，但技能栏最多装配 5 个。
- 确认被动、固定被动和绝技不会占用五个主动槽。
- 未接入 Lua 时，技能不得造成重复基础伤害或错误扣蓝。
- 接入 Lua 后执行职业基线中的完整白盒验证矩阵。
- 四名破妄同场时，资源、个人破隙、触发计时和冷却必须按角色隔离；显妄和明识只呈现单一最高来源并支持到期回退。
