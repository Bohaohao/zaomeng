## 六、B 层和验收门禁

- 所有效果命令必须显式声明 `self`、`primary`、`selected`、`team` 或 `explicit`；禁止从 `context.targets` 隐式回退。
- A01/A02 只生成 `earned` 法印并共享 `4.0 秒` 窗口；明界内为 `2.8 秒`。三来源法印按 `earned/refunded/external` FIFO 消耗，只有 `earned` 有效消费获得 `5` 绝技。P01 只改触发它的基础技能冷却，不改窗口。
- A04/A07 只接受项目确认的实际保护；A04/A07/A08 的净化只接收项目完成的确定性结果。
- A01/A03/A06 绑定主目标；A05/A08 脉冲必须重新取得 selected 快照。A05/A08 对 BOSS 只以显式 break scope 转破韧；unknown 不控制、不破韧，普通/精英控制由“稳定 Unit ID + root 类型 + 来源生命周期”租约重叠管理。
- 真实创建顺序：12 效果 -> 固定/学习被动 -> 8 主动 -> 绝技 -> 英雄绑定；创建后回读 31 个对象。
- 未填写生产 ID、图标、模型、普攻模板、距离尺度和项目钩子前，禁止生成生产 `y3_obj_edit.py` 命令。
