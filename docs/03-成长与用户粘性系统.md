# 成长与用户粘性系统

> 本文件保留成长方向与内容总纲。等级门槛、存档、奖励资格、长期目标和施工验收以 [成长系统进度、掉落与长期目标契约](物编/18-成长系统进度、掉落与长期目标契约.md) 为准；装备、法宝、宠物与材料字段以 [19-装备、法宝、宠物与材料物编规格](物编/19-装备、法宝、宠物与材料物编规格.md) 为准。

## 成长目标

v1.0 必须让玩家在首发内容完成后仍有继续游玩的理由。

核心长期目标：

- 提升角色等级。
- 刷装备并强化。
- 进阶装备阶级。
- 合成并培养法宝。
- 挑战更高通天塔层数。
- 收集称号、图鉴、时装和稀有外观。

## 职业等级与技能成长

首发等级上限为 `Lv60`：花果山篇 `Lv1-20`、地府篇 `Lv21-40`、天庭篇 `Lv41-60`。

每次升级获得 1 点自由技能点。技能点由可装配主动技能和不占槽被动技能共同消耗：

- 每职业 8 个主动技能，每个最高 5 级。
- 每职业 8 个学习型被动技能，每个最高 5 级。
- 固定职业被动不升级。
- 固定职业绝技为 3 阶，通过 `Lv15`、`Lv35`、`Lv55` 道统试炼强化，不消耗技能点。
- 玩家可以学习全部技能，但 Lv60 的 60 点总预算不足以升满整棵 80 点技能树。
- 详细规则见 [职业与技能树设计大纲](归档/职业设计/01-职业与技能树设计大纲.md)。

## 装备系统

装备应承担主要战力成长。

| 系统 | 设计方向 | 粘性来源 |
|---|---|---|
| 装备掉落 | 普通、精良、稀有、史诗、传说 | 刷怪、打本、追求稀有掉落 |
| 装备强化 | 使用金币和强化石提升基础属性 | 日常材料消耗 |
| 装备进阶 | 低阶装备加本城 BOSS 材料升级 | 老装备不废掉 |
| 套装效果 | 2 件、4 件触发效果 | 驱动反复刷套装 |
| 主城阶级 | 每个主城对应一段装备阶级 | 推进主城解锁更高成长 |

首发三城装备定位：

| 主城 | 装备定位 |
|---|---|
| 花果山 | 初阶基线装备、基础强化与可选团本套装种子 |
| 地府 | 中阶构筑、抗性方向与对花果山基线的非强制替换／进阶出口 |
| 天庭 | 高阶装备、套装、技能精通与毕业前的长期构筑选择 |

三篇装备、法宝、材料和替换关系的唯一详细来源为 [三篇成长谱系合同](物编/成长数值与经济裁决包/three-chapter-growth-lineage-contract.json)。本表不定义属性、部位、配方、消耗或资源 ID。

## 法宝系统

法宝提供中长期追求，吸收造梦西游中法宝合成和养成的粘性。

核心规则：

- 法宝作为贯穿游戏流程的重要组成部分，不是一次性技能道具。
- v1 先冻结一个活动法宝槽；拥有多件法宝不等于能同时启用多件主动效果，法宝主动不占五主动技能槽。
- `ART_HG_TIDE_SEAL` 是龙宫旧潮首通的可选早期法宝，`ART_HG_FLAME_CORE` 是牛魔旧战场的可选稀有横向法宝；隐藏本或团队本都不能成为主线强制门槛。
- 法宝的词条、洗炼、追加、升阶、配方、数值和具体主动效果仍待单独裁决；不得把旧“集齐五件装备”示例当作首法宝的当前必经路线。
- 后续替换或进阶必须保留来源、前序状态和消耗审计，不能无记录销毁玩家已投资的法宝。

首发阶段原则：

- 公共／主线可获得的基线装备保证角色不会因不刷隐藏本、稀有或团队本而卡住下一篇章。
- 龙宫、牛魔、白骨、七星和星宿提供横向选择、收藏或长线进阶机会；它们的材料不得隐式双花，也不得以随机掉落充当主线装备缺口。
- 地府与天庭的具体资产键、配方和消耗保持 `deferred`；在资产表采纳前，只能按谱系合同验证“保留、替换、进阶或回收”的逻辑出口。

词条池应按类型拆分：

- 攻击类：攻击、增伤、暴击、技能伤害。
- 生存类：生命、防御、减伤、抗性。
- 功能类：冷却、移速、资源回复、召唤物强化。
- 专属类：指定法宝主动技能增强，或指定 BOSS 虚影增强。

后续扩展：

- 法宝升星。
- 多法宝切换。
- 法宝套装或共鸣。
- 高阶主城专属法宝。

## 通天塔

通天塔是 v1.0 的长期天花板，不是附属玩法。

定位：

```text
主线 = 解锁世界
副本 = 获得材料
装备/法宝 = 提升战力
通天塔 = 检验战力并提供长期目标
```

当前已采纳规则：

- 角色达到 `Lv55` 后才能挑战通天塔。
- 团队挑战时逐人检查等级，任何成员低于 `Lv55` 都不能进入，不使用队伍平均等级。
- 支持单人和最多 4 人组队。
- 记录玩家最高通关层数。
- 每五层存在构筑休整节点；首轮奖励、团队资格和周额度以 `economy-v2` 已采纳经济合同为准。`economy-v3` 仅限未来花果山首通 XP 路线及桃林／蝙蝠窟必经公共主线语义覆盖，不承接通天塔奖励或资格。
- 总层数、章节层段、小／大 Boss 节奏、内容池、掉落、词缀、记录和赛季均未采纳；天庭四十层候选不能被视作全局塔既成事实。

## 外观与收集

外观与收集系统用于增加非战力目标。

v1.0 可预留并开放基础版本：

- 称号：击杀 BOSS、通关副本、达到塔层。
- 图鉴：怪物、BOSS、装备、法宝。
- 时装：稀有掉落、活动兑换、成就奖励。
- 隐藏饰品：隐藏副本或特殊挑战掉落。

原则：

- 时装优先作为外观和荣誉。
- 如附加属性，属性应轻量，避免强付费或强碾压。
- 称号和图鉴应提供长期收集目标，但不要让 UI 复杂度压过战斗。

## 主城收集机制

三个首发主城分别拥有独立的收集进度。花果山已有九项方向；地府与天庭只冻结“非主线、非极低概率强制”的结构，不预设相同数量。

规则：

- 玩家达成指定目标后，解锁对应收集项。
- 收集项可以提供长期目标或外观／荣誉；如进入属性，具体强度仍须通过跨职业数值与零付费门禁。
- 收集进度按角色存档保存。
- 每个主城独立设计目标，不共用同一套收集项。
- 目标可以是击杀、首通、材料提交、装备登记、隐藏发现、挑战成就。
- 收集奖励必须可长期追求，但不能让新玩家因为未收集而完全无法进入下一篇章。

收集项难度建议：

| 段位 | 数量 | 目标类型 | 奖励强度 |
|---|---:|---|---|
| 入门 | 发现区域、完成首个任务、理解一个核心机制 | 可读目标、轻量成长或外观方向 |
| 进阶 | 击杀精英、首通单人本、完成机制挑战 | 构筑补充、抗性或收藏方向 |
| 高阶 | 团队通关、隐藏登记、条件挑战 | 称号、展示或经数值门禁批准的长期方向 |

花果山已保留九项收集方向；地府和天庭的具体清单待对应玩法机制、资产和数值审阅后建立，不能为了凑数复用花果山的九项模板。
