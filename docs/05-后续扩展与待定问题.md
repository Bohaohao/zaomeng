# 后续扩展与待定问题

## 后续主城规划

v1.0 之后通过新主城扩展世界和成长上限。

候选主城：

| 主城 | 主题 | 扩展价值 |
|---|---|---|
| 东海主城 | 海岸、水府、漩涡 | 蛟魔王/鲨魔王二阶段、水系套装、装备进阶、宠物/灵兽支线 |
| 南瞻长安 | 人间城国、寺院、九黎前线 | 四洲主线与九黎主线的共同锚点 |
| 北俱妖城 | 寒域、蜃楼、异兽、时空 | 高难公共野外、异兽宠物与时空机制 |
| 瑶池/善见仙城 | 仙园、宫城、上层天界 | 瑶池、雷府、北极天宫和十洲三岛入口 |
| 星宫主城 | 星宿、星官、律令 | 星曜套装、塔层扩展、后期挑战 |
| 幽都 | 鬼帝、黄泉、血河 | 地府高阶内容与轮回规则扩展 |

火焰山当前保留为西牛贺洲“西行火域”和牛魔旧战场，不作为默认主城候选。只有在其具备稳定文明、两片以上公共野外、独立单人本和团队本后，才重新评估升格。

每个新增主城必须遵守：

- 有独立公共野外。
- 有独立单人本。
- 有独立团队本。
- 有独立材料和装备阶级。
- 通天塔追加对应主题楼层。

|---|---|---|

## 当前风险

1. v1.0 内容范围已经偏大，需要严格控制每个主城的副本数量。
2. 三主城都独立做副本，会增加地形、怪物和 BOSS 工作量。
3. 通天塔如果做 50 层，需要用规则模板降低制作成本，但奖励和体验不能完全重复。
4. 装备、法宝、强化、进阶、时装、称号同时存在，UI 和存档字段会比较多。
5. 公共野外奖励归属如果没有设计好，可能出现抢怪、抢 BOSS、低级玩家体验差。
6. 团队本状态锁和副本清理必须稳定，否则会造成卡副本、锁不释放、奖励重复等问题。

## 待定问题

- 装备部位数量是多少？
- 法宝同时可装备几个？
- 时装是否只做外观，还是提供轻量属性？
- 公共野外 BOSS 的个人掉落、队伍掉落和参与保底如何组合？击杀计数已确定按有效伤害贡献计算，同队成员占比严格大于 10% 时同步计入。
- 花果山地图分布定稿后，各区域怪群数量、刷新周期、材料产量和四人资源吞吐目标是多少？
- 团队本死亡后是倒地等待，还是死亡后在副本内观战？
- 通天塔是单人和团队共用层数记录，还是分开记录？
- 角色存档是否支持多存档槽？
- 首发是否做交易、摆摊或玩家间物品交换？

## 已解决问题

- v1.0 固定 4 个职业，允许同职业玩家同时出现。
- v1.0 不做正式转职，通过主动技能装配、被动投入、装备词条和套装形成流派。
- 首发等级上限为 Lv60；花果山、地府、天庭各承担约 20 级。
- 通天塔 Lv55 解锁，单人和团队均逐人检查等级，低等级玩家不可挑战。

## 后续交接建议

后续进入制作前，建议按顺序拆分：

1. 使用 `y3-terrain-layout` 做三主城、公共野外、副本区、通天塔和预留区的地图布局。
2. 使用 `y3-object-config` 整理职业、怪物、BOSS、装备、法宝、材料和掉落表。
3. 使用 `y3-lua-api` 设计副本状态锁、公共野外刷新、奖励归属、存档字段和通天塔规则。
4. 使用官方 UI 流程设计角色选择、背包装备、强化、法宝、副本入口、通天塔和结算界面。
5. 使用 `y3-review-panel` 对 v1.0 规格做技术、关卡、数值、新手和商业化评审。
