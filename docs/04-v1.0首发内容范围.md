# v1.0 首发内容范围

## v1.0 定义

v1.0 是可上架提供玩家游玩的版本，不是简单技术验证版。

首发版本必须让玩家感受到：

- 世界已经成立。
- 多主城推进已经成立。
- 单人玩家有内容。
- 组队玩家有内容。
- 通关主线后仍有长期目标。
- 装备和法宝养成能支撑重复游玩。

## 首发内容清单

| 模块 | v1.0 要求 |
|---|---|
| 玩家人数 | 最多 4 人同游 |
| 角色存档 | 选择角色存档进入地图 |
| 等级 | 首发上限 Lv60；花果山 Lv1-20、地府 Lv21-40、天庭 Lv41-60 |
| 主城 | 3 个主城 |
| 公共野外 | 每个主城 1 片公共野外 |
| 单人本 | 每个主城至少 1 个 |
| 团队本 | 每个主城至少 1 个 |
| 长期副本 | 唯一全局通天塔，Lv55 逐人硬门槛；总层数、篇章层段、词缀与赛季由上位全局塔合同另行采纳 |
| 职业 | 固定 4 个，允许同职业玩家同时出现 |
| 技能 | 每职业 8 主动、8 学习型被动、1 固定被动、1 独立绝技；主动最多装备 5 个 |
| 装备 | 掉落、强化、进阶、套装雏形 |
| 法宝 | 合成与升级 |
| UI | 角色选择、篇章三点传送、副本入口、背包/装备、强化/法宝、结算 |
| 粘性 | 最高塔层、称号、图鉴、稀有掉落、时装入口 |
| 扩展 | 预留后续主城地形空间 |

## 首发三主城内容

### 花果山主城

- 主城安全区：基础 NPC、强化 NPC、传送阵。
- 公共野外：山林、洞窟、瀑布、水帘入口、东海前缘、鲨之涡流。
- 怪物生态：猴妖、山怪、蝙蝠、初级妖兵、水族兵、鱼妖、鲨魔系妖兵。
- 单人本：龙宫，配置 4 份独立挑战区域，最多支持 4 名玩家同时分别挑战。
- 团队本：牛魔旧战场（经熔脉劫痕进入的梦墟旧战场），不是与花果山物理相邻的火焰山地图。
- 主要成长来源：花果山公共／龙宫／团队本的逻辑奖励键、首通资格、掉落与保底由 [economy-v2 基表及三篇成长谱系](物编/成长数值与经济裁决包/README.md) 唯一说明；`economy-v3` 只覆盖未来花果山首通 XP 路线及桃林／蝙蝠窟必经公共主线语义的限域修订，不在本范围文档重复编造掉落、配方或数值。

### 地府主城

- 主城安全区：鬼城 NPC、法宝合成 NPC、传送阵。
- 公共野外：鬼城及已裁定的公共路线。忘川、奈何与望乡的公共／团队前导身份和物理拓扑仍待地府专项裁定，不能由本范围文档提前写死。
- 怪物生态：鬼灯、僵尸、牛头、马面、花妖。
- 单人本：白骨秘境。
- 常规最终副本：阎罗殿；它不是团队本，权威通关后写入角色级 `DF_PROGRESS_YANLUO_HALL_CLEARED`。
- 团队本：转轮殿。
- 入章：同一角色持有花果山常规收束的受信任交接证明并达到 Lv20 后进入鬼城；地府 Lv21-40 是成长带，不能错误反推为 Lv21 入门硬门槛。
- 主要成长方向：中阶构筑、抗性与法宝成长。具体装备／法宝资产、地府 XP source profile、掉落与消耗仍由成长谱系和后续经济版本单点裁决。

### 天庭主城

- 主城安全区：天庭 NPC、装备进阶 NPC、传送阵。
- 公共野外：天宫道、南天门、天王殿外缘。
- 怪物生态：天兵、天将、云兽、机关神像。
- 常规主线：裂云南天门、断虹阵、四门失衡、周天观台至凌霄外庭·裂律观台；终局是私有 `1-4` 人常规收束。
- 单人本：七星试炼系列；蟠桃园／御马监仅为公共路线或未来支线场景素材。
- 团队本：二十八星宿普通与噩梦四圣，逐人要求天庭常规主线完成；它们不是凌霄主线终局的替代品。
- 长期支线：七星与星宿仅以内容池接口候选接入唯一全局通天塔，不能在天庭另设玲珑塔。
- 主要成长方向：高阶装备、套装、技能精通与长期称号。实际天庭 XP／掉落／材料／称号数值继续 deferred，不能由本范围文档代填。

## 首发玩家循环

```text
选择角色存档
-> 进入主城
-> 完成主线任务
-> 解锁公共野外
-> 刷怪/精英/BOSS
-> 进入单人本或团队本
-> 获得阶段装备、材料与可选法宝进度
-> 回城强化、进阶、合成法宝
-> 挑战通天塔
-> 为更高塔层继续成长
```

## 首发验收标准

- 4 名玩家可以同时进入并在不同公共野外区域行动。
- 公共野外怪物对所有玩家可见。
- 每个篇章的主城传送点、副本枢纽传送点、团本入口传送点都能正确往返，落点不进入怪物或 BOSS 战斗范围。
- 龙宫 4 份单人挑战区域能分别加锁、失败、清理和解锁，互不影响。
- 公共 BOSS 不按尾刀归属；同队成员有效伤害占比严格大于 10% 时能同步计入击杀。
- 团队本能正确纳入 NPC 周围玩家，最多 4 人。
- 团队本挑战中非成员不能进入或重复开启。
- 团队成员死亡后回当前篇章初始出生点，但本次死亡态和成员锁必须保留到匹配清理确认；团灭不得重复回传已死亡成员，超时只回传仍在战斗的成员。
- 团队本团灭或超时后能清除实例状态；只有匹配清理确认可解除成员锁。
- 每个主城拥有独立副本地形、怪物和掉落。
- 玩家能保存并读取等级、装备、材料、法宝、塔层记录。
- 通天塔能提供首发主线之后的长期挑战目标，但不得以本范围文档预设总层数、层段、掉落或赛季。
- 通天塔入口逐人校验 Lv55，任何低于 Lv55 的成员都不能进入挑战。
- 玩家升级时正确获得自由技能点；主动、被动、五槽和绝技阶级可以随角色存档保存与读取。
- 未开放主城区域在地图上有明确封锁和后续扩展提示。
