# v1.0 首发内容范围

## v1.0 定义

v1.0 是可上架提供玩家游玩的版本，不是简单技术验证版。

首发版本必须让玩家感受到：

- 世界已经成立。
- 多主城推进已经成立。
- 单人玩家有内容。
- 组队玩家有内容。
- 通关主线后仍有长期目标。
- 装备和法宝养成能支撑重复游玩。

## 首发内容清单

| 模块 | v1.0 要求 |
|---|---|
| 玩家人数 | 最多 4 人同游 |
| 角色存档 | 选择角色存档进入地图 |
| 等级 | 首发上限 Lv60；花果山 Lv1-20、地府 Lv21-40、天庭 Lv41-60 |
| 主城 | 3 个主城 |
| 公共野外 | 每个主城 1 片公共野外 |
| 单人本 | 每个主城至少 1 个 |
| 团队本 | 每个主城至少 1 个 |
| 长期副本 | 通天塔，Lv55 硬门槛，建议 50 层，至少 30 层 |
| 职业 | 固定 4 个，允许同职业玩家同时出现 |
| 技能 | 每职业 8 主动、8 学习型被动、1 固定被动、1 独立绝技；主动最多装备 5 个 |
| 装备 | 掉落、强化、进阶、套装雏形 |
| 法宝 | 合成与升级 |
| UI | 角色选择、篇章三点传送、副本入口、背包/装备、强化/法宝、结算 |
| 粘性 | 最高塔层、称号、图鉴、稀有掉落、时装入口 |
| 扩展 | 预留后续主城地形空间 |

## 首发三主城内容

### 花果山主城

- 主城安全区：基础 NPC、强化 NPC、传送阵。
- 公共野外：山林、洞窟、瀑布、水帘入口、东海前缘、鲨之涡流。
- 怪物生态：猴妖、山怪、蝙蝠、初级妖兵、水族兵、鱼妖、鲨魔系妖兵。
- 单人本：龙宫，配置 4 份独立挑战区域，最多支持 4 名玩家同时分别挑战。
- 团队本：火焰山/牛魔王。
- 主要产出：初阶装备、强化石、基础法宝碎片、龙王系法宝材料。

### 地府主城

- 主城安全区：鬼城 NPC、法宝合成 NPC、传送阵。
- 公共野外：鬼城街巷、奈何桥、冥河岸。
- 怪物生态：鬼灯、僵尸、牛头、马面、花妖。
- 单人本：白骨秘境。
- 常规最终副本：阎罗殿；它不是团队本，权威通关后写入角色级 `DF_PROGRESS_YANLUO_HALL_CLEARED`。
- 团队本：转轮殿。
- 主要产出：魂石、法宝合成材料、抗性装备。

### 天庭主城

- 主城安全区：天庭 NPC、装备进阶 NPC、传送阵。
- 公共野外：天宫道、南天门、天王殿外缘。
- 怪物生态：天兵、天将、云兽、机关神像。
- 单人本：蟠桃园或御马监。
- 团队本：凌霄宝殿。
- 长期支线：玲珑塔主题层，和全局通天塔形成首发爬塔记忆点。
- 主要产出：高阶装备材料、神将令、塔层挑战资源。

## 首发玩家循环

```text
选择角色存档
-> 进入主城
-> 完成主线任务
-> 解锁公共野外
-> 刷怪/精英/BOSS
-> 进入单人本或团队本
-> 获得装备与材料
-> 回城强化、进阶、合成法宝
-> 挑战通天塔
-> 为更高塔层继续成长
```

## 首发验收标准

- 4 名玩家可以同时进入并在不同公共野外区域行动。
- 公共野外怪物对所有玩家可见。
- 每个篇章的主城传送点、副本枢纽传送点、团本入口传送点都能正确往返，落点不进入怪物或 BOSS 战斗范围。
- 龙宫 4 份单人挑战区域能分别加锁、失败、清理和解锁，互不影响。
- 公共 BOSS 不按尾刀归属；同队成员有效伤害占比严格大于 10% 时能同步计入击杀。
- 团队本能正确纳入 NPC 周围玩家，最多 4 人。
- 团队本挑战中非成员不能进入或重复开启。
- 团队成员死亡后回当前篇章初始出生点，但本次死亡态和成员锁必须保留到匹配清理确认；团灭不得重复回传已死亡成员，超时只回传仍在战斗的成员。
- 团队本团灭或超时后能清除实例状态；只有匹配清理确认可解除成员锁。
- 每个主城拥有独立副本地形、怪物和掉落。
- 玩家能保存并读取等级、装备、材料、法宝、塔层记录。
- 通天塔能提供首发主线之后的长期挑战目标。
- 通天塔入口逐人校验 Lv55，任何低于 Lv55 的成员都不能进入挑战。
- 玩家升级时正确获得自由技能点；主动、被动、五槽和绝技阶级可以随角色存档保存与读取。
- 未开放主城区域在地图上有明确封锁和后续扩展提示。
