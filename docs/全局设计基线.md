# 全局设计基线

## 使用方式

本文件是造梦 ORPG 项目的全局引用入口。进行策划、世界观、地形、物编、Lua、UI、数值、经济、商业化或测试工作前，必须先读取本文件及对应下游文档。

当其他文档出现冲突时，优先级如下：

1. 用户最近明确采纳并已登记在本文件中的结论。
2. 本文件链接的当前有效基线。
3. 主策划目录中的系统文档。
4. 标记为历史稿、旧版或方案演变记录的归档文件。

当前有效结论：

- v1.0 固定 4 个职业，允许同职业玩家同时出现。
- 玩家共同身份为承命者，行者道统是共同体系，四种法门是职业。
- 首发等级上限 `Lv60`：花果山 `Lv1-20`、地府 `Lv21-40`、天庭 `Lv41-60`。
- 通天塔 `Lv55` 解锁，单人和团队均逐人校验，低等级玩家不可挑战。
- 每职业 8 个可学习主动、8 个可学习被动、1 个固定被动和 1 个三阶绝技。
- 主动和学习型被动最高 5 级，共享每级获得的自由技能点。
- 玩家最多装备 5 个主动技能；所有被动、绝技、闪避和法宝主动不占这 5 个槽位。
- 首发技能树容量 80 点，Lv60 总技能等级预算 60 点；自动授予、自动装配或初始化预分配的技能等级也必须计入该 60 点，并在职业构筑/技能树 UI 中明确其是否可由玩家手动分配。
- 主城永久免费洗点，每个角色免费拥有 3 套构筑预设。
- 破妄采用战势 `0-100` 的生势/耗势循环，80 点进入洞明；完整技能组已采纳为当前正式职业子基线。
- 破妄首批物编包确定为 18 个技能对象和 12 个魔法效果对象；真实 Y3 ID、图标和距离换算待接入地图后查询。
- 破妄英雄裸装成长采用生命 `620 + 68 × (Lv-1)`、物攻 `48 + 5.7 × (Lv-1)`、物防 `22 + 1.9 × (Lv-1)`、法防 `16 + 1.5 × (Lv-1)` 的当前白盒基线。
- 破妄离线施工包已覆盖英雄成长、8 主动、8 被动、三阶绝技和 12 个效果策略；v1.1 反查的四项桥接 P1 已完成离线修复，真实编辑器对象和 Y3 地图接入仍以施工状态文档为准。
- 用户于 `2026-07-11` 明确暂时跳过实际验证；破妄设计与离线施工阶段据此收口，真实编辑器接入、对象回读和实机测试延期，且不得标记为 `verified`。
- 破妄暂以 `y3-lualib main@fe2fb0e55a76f73490cdcbef8cbfe7a61d124d63` 为 Lua API 基线；英雄属性同步、踏虚双充能、耗势异步确认、回锋受击反击、显式效果目标范围、重叠控制租约、默认目标筛选和 Y3 事件桥接已补入离线施工包。
- 镇界采用守势 `0-100` 的生成/耗势循环，Lv15 后 `80` 守势进入界势；同条件 90 秒单体输出离线预算为破妄的 80%-87%，用格挡、反震、护盾和区域控制交换强度，不形成团队必带职业。
