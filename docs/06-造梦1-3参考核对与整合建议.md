# 造梦 1-3 参考核对与整合建议

> 文档状态：本文件只作为原作改编与早期方案的参考输入，不是当前首发内容的决策来源。造梦 1-6 的完整资料以 `09-造梦西游1-6原作资料总表.md` 为准；项目世界观以 `10-项目统一世界观总纲.md`、全局结论以 `全局设计基线.md`、地府／天庭的当前详细内容以各自物编规格包为准。本文中“蟠桃园／御马监单人本、凌霄／杨戬团队本、火焰山团本”等旧方案仅保留为参考素材，不能覆盖七星、二十八星宿或牛魔旧战场的现行口径。

## 本次口径

本次首发三主城从“花果山、地府、龙宫”调整为“花果山篇、地府篇、天庭篇”。其中：

- 花果山篇吸收《造梦西游 1：七魔王篇》的自然关卡推进、隐藏龙宫、多阶段牛魔王。
- 地府篇吸收《造梦西游 2：十殿阎罗篇》的鬼城到转轮殿主线、白骨秘境、十八层地狱、螺旋地狱。
- 天庭篇吸收《造梦西游 3：大闹天庭篇》的天宫主线、隐藏天宫副本、玲珑宝塔、兜率宫、后期天境内容。

这三代是三个不同游戏，不能直接拼接成一张超大复刻地图。我们的整合原则是：保留“关卡层层推进、隐藏入口、BOSS 阶段、装备/法宝掉落、爬塔长期目标”的结构，重做为 Y3 俯视角 ORPG 的三篇章主城。

## 造梦西游 1：七魔王篇

### 发展主线

主线是从花果山出发，经过水帘洞、桃花源、洞窟、东海水域，最终抵达火焰山挑战牛魔王。整体节奏很适合做首发新手篇：前半段是山林和洞窟，后半段切入水域与火焰山，颜色和场景变化明显。

### 主线关卡与 BOSS

| 顺序 | 原作关卡/区域 | BOSS | 整合用途 |
|---|---|---|---|
| 1 | 花果山 | 大猩猩 | 新手公共野外首领，教学走位和普攻节奏 |
| 2 | 水帘洞 | 猕猴王 | 花果山篇第一个副本或精英 BOSS |
| 3 | 桃花源 | 禺狨王 | 过渡到妖王体系，适合做精英巡逻怪 |
| 4 | 蝙蝠窟 | 蝙蝠石像 | 洞窟机制点，可做召唤小怪/机关石像 |
| 5 | 七星洞 | 狮驼王 | 中段强敌，适合公共野外 BOSS |
| 6 | 迦楼罗之穴 | 鹏魔王 | 飞行/冲刺型强敌，适合做高阶大精英或区域守门 |
| 7 | 东海龙宫前段/浅岸 | 龟丞相 | 水域支线 BOSS，适合龙宫入口守卫 |
| 8 | 东海龙宫 | 蛟魔王 | 花果山篇东海前缘区域 BOSS，一阶段首发；后续东海篇做二阶段 |
| 9 | 鲨之涡流 | 鲨魔王 | 花果山篇水域压轴区域 BOSS，一阶段首发；后续东海篇做二阶段 |
| 10 | 火焰山 | 牛魔王 | 花果山篇团队本终局，多阶段 BOSS |

### 美术风格

- 高饱和 Flash 横版美术，角色轮廓夸张，场景块面清晰。
- 花果山、水帘洞、桃花源偏绿色、岩壁、瀑布和植物。
- 蝙蝠窟、七星洞偏暗色洞窟，适合用狭窄路线、机关和小怪群制造压力。
- 东海段是蓝绿色水域，火焰山是红橙色终局场景，天然形成“新手自然区 -> 水域隐藏支线 -> 火焰终局”的视觉递进。

### 小怪生态

七魔王篇小怪资料在旧页面中较分散，首发设计不需要逐只复刻，建议按生态复用：

| 区域 | 小怪方向 | Y3 用途 |
|---|---|---|
| 花果山/桃花源 | 猴妖、山怪、树妖或花妖 | 新手近战、远程、治疗/增益教学 |
| 水帘洞/蝙蝠窟/七星洞 | 蝙蝠、洞窟小妖、石像机关 | 群怪、飞行扑击、召唤点 |
| 东海/龙宫 | 龟兵、鱼妖、水族兵 | 水域减速、护盾、远程水弹 |
| 火焰山 | 火妖、牛魔系妖兵 | 灼烧地面、冲锋、团队本前置小怪 |

### 隐藏副本与特殊机制

- 龙宫是七魔王篇最值得吸收的隐藏副本。原作入口在水帘洞水域附近，强调“隐藏通道”的记忆点。
- 龙宫根据角色等级出现一阶段/二阶段龙王，可转化为 Y3 的等级分流挑战。
- 牛魔王有多阶段战斗记忆点，适合成为花果山篇首个团队本终局。
- 洞窟石像、蝙蝠、小怪刷出点可以转化为“公共野外刷怪点 + 单人本机关房”。

### 花果山篇整合建议

首发不建议把东海、火焰山都做成独立主城。花果山篇应以花果山为主城，东海前缘作为本篇后段公共野外，火焰山作为团队本终局；后续东海篇再把蛟魔王、鲨魔王升级为二阶段或真身挑战。

| 模块 | 建议内容 |
|---|---|
| 主城 | 花果山安全区、水帘入口、基础强化 NPC |
| 公共野外 | 花果山、水帘洞外缘、桃花源、蝙蝠窟外层、七星洞、东海前缘、鲨之涡流 |
| 单人本 | 龙宫，强调隐藏入口、限时、死亡失败 |
| 团队本 | 火焰山/牛魔王，强调多阶段和团队站位 |
| 长期掉落 | 初阶装备、强化石、基础法宝碎片、龙宫隐藏材料 |

## 造梦西游 2：十殿阎罗篇

### 发展主线

二代的主线从鬼城进入冥界，逐步经过无常巷、鬼门关、接引院、判官殿、阎罗殿、忘川河、奈何桥、望乡台，最后挑战转轮殿。它的结构比一代更像“区域推进 + 地府官署层级”，非常适合做第二主城：每个区域天然对应 NPC、审判、魂石、法宝合成材料。

### 主线关卡与 BOSS

| 顺序 | 原作关卡/区域 | BOSS/状态 | 整合用途 |
|---|---|---|---|
| 1 | 鬼城 | 守夜人 | 地府篇入口首领，教学鬼灯/尸怪生态 |
| 2 | 无常巷 | 黑白无常 | 双 BOSS 结构，适合小型团队机制 |
| 3 | 鬼门关 | 秦广王傀儡 | 门关守卫，适合作为公共野外 BOSS |
| 4 | 接引院 | 秦广王 | 第一殿阎王节点 |
| 5 | 判官殿/判官府 | 判官 | 审判主题，适合负面状态/判定机制 |
| 6 | 阎罗殿 | 阎罗王 | 地府篇主线高潮之一 |
| 7 | 忘川河 | 常规关卡，无核心 BOSS | 路线过渡、毒水/减速/魂河机制 |
| 8 | 奈何桥 | 夜叉 | 桥面狭窄战斗，适合击退/冲锋机制 |
| 9 | 望乡台 | 孟婆 | 控制/遗忘/梦境机制，可做单人或小队挑战 |
| 10 | 转轮殿 | 转轮王 | 多血条/多阶段终局，可做地府篇团队本 |

本项目已固定：阎罗殿为地府篇的常规最终副本，通关后写入角色级 `DF_PROGRESS_YANLUO_HALL_CLEARED`；转轮殿为地府篇唯一的首发团队本。该分工只确定内容与跨篇接口，不预先确定任何掉落、经验、货币或对象 ID。

### 隐藏与扩展副本

| 副本/区域 | BOSS | 整合用途 |
|---|---|---|
| 白骨秘境 | 白骨精 | 地府篇首选单人本，三段血或多阶段形态很适合限时挑战 |
| 十八层地狱 | 刑天/战神刑天 | 高难隐藏本，可作为地府篇后期解锁 |
| 牛魔谷 | 红孩儿 | 可放到花果山/火焰山后续，而不是地府首发核心 |
| 活大地狱 | 楚江王 | 冥河/水域地狱分支，适合第二批地府副本 |
| 七夕台 | 宋帝王 | 活动型副本，首发不必纳入 |
| 螺旋地狱 | 五官王、卞城王、泰山王、都市王、平等王 | 地府篇长期挑战模板，可做轮换 BOSS 或通天塔地府层 |

### 美术风格

- 二代整体更阴暗，主色是灰、紫、蓝绿、暗红。
- 场景符号强：鬼城、灯笼、冥河、奈何桥、判官案台、阎罗殿、转轮殿。
- 比一代更适合做“功能型主城”：法宝合成、魂石兑换、抗性装备、诅咒/净化等系统都能放在地府篇。

### 小怪生态

| 区域 | 已核对小怪/常见敌人 | Y3 用途 |
|---|---|---|
| 鬼城/无常巷 | 引路灯、僵尸、守夜人系敌人 | 低阶亡灵、巡逻灯、夜巡精英 |
| 鬼门关/接引院/判官殿 | 牛头、马面、黑白无常系敌人 | 近战冲锋、拉扯、双目标组合 |
| 阎罗殿 | 鬼门、牛头、马面、无常系敌人 | 召唤门、持续刷怪、防线压力 |
| 忘川河/奈何桥/望乡台 | 蟾蜍精、曼珠、沙华、蛇妖 | 毒水、藤蔓、花妖控制、桥面压力 |
| 活大地狱 | 鱼妖、水蛭 | 冥河支线怪物，可后续扩展 |
| 转轮殿/螺旋地狱 | 轮回使者、五王系精英 | 长期挑战层的小首领和精英模板 |

### 特殊机制

- 黑白无常适合双目标、分摊、先后击杀机制。
- 判官和孟婆适合控制、审判、遗忘、减益层数机制。
- 白骨精、转轮王、牛魔王这类多形态 BOSS 是首发 BOSS 设计应重点继承的东西。
- 螺旋地狱的“多阎王轮转”很适合改造成长期周常/爬塔分支，不建议首发做成独立大地图。

### 地府篇整合建议

| 模块 | 建议内容 |
|---|---|
| 主城 | 鬼城安全区、法宝合成 NPC、魂石商人 |
| 公共野外 | 鬼城、无常巷、鬼门关、奈何桥外缘 |
| 单人本 | 白骨秘境，限时三阶段白骨精 |
| 常规最终副本 | 阎罗殿；其权威通关写入角色级 `DF_PROGRESS_YANLUO_HALL_CLEARED` |
| 团队本 | 转轮殿；转轮王作为首发团队终局多阶段 BOSS |
| 长期支线 | 螺旋地狱五王轮换，后续接入通天塔地府主题层 |

## 造梦西游 3：大闹天庭篇

### 发展主线

三代的主线是进入天庭，沿天宫道、南天门、各天王殿、彩虹楼、朝会殿推进到凌霄宝殿，目标是挑战天庭神将体系。相比一、二代，三代内容扩展量最大，包含大量隐藏副本、塔、神兽森林、兜率宫、截教天境、碧游宫、星宿、八仙、流沙河和节日活动。首发应只吸收“天庭主线 + 隐藏入口 + 玲珑宝塔/通天塔”的核心，不应一次性吞下所有后期内容。

### 天庭主线关卡与 BOSS

| 顺序 | 原作关卡/区域 | BOSS | 整合用途 |
|---|---|---|---|
| 0 | 新手引导/九重天 | 哮天犬等教学节点 | 可作为天庭篇前置剧情，不必独立成主城区域 |
| 1 | 天宫道 | 千里眼、顺风耳 | 天庭公共野外第一组双首领 |
| 2 | 南天门 | 巨灵神 | 天庭入口守门 BOSS |
| 3 | 南天王殿 | 增长天王 | 四天王系列第一节点 |
| 4 | 西天王殿 | 广目天王 | 四天王系列第二节点 |
| 5 | 北天王殿 | 多闻天王 | 四天王系列第三节点 |
| 6 | 东天王殿 | 持国天王 | 原作隐藏进入，适合做天庭隐藏本 |
| 7 | 彩虹楼 | 朱子真 | 机关/彩虹桥过渡 BOSS |
| 8 | 朝会殿 | 袁洪 | 终局前精英 BOSS |
| 9 | 凌霄宝殿 | 杨戬 | 天庭篇团队本终局，可加入哮天犬协战记忆点 |

### 隐藏副本与进入机制

| 隐藏/支线 | 原作机制记忆点 | 整合用途 |
|---|---|---|
| 蟠桃园 | 天宫道云团/隐藏入口 | 天庭篇单人材料本，产出恢复、炼丹、宠物/坐骑材料 |
| 御马监 | 北天王殿墙门触发 | 天庭篇单人本或支线，适合坐骑/速度类奖励 |
| 东天王殿 | 彩虹楼灯/机关进入 | 四天王隐藏补完，适合隐藏 BOSS 持国天王 |
| 水下迷宫 | 神兽森林水域下潜、珍珠/漩涡路线 | 机制很好，但更适合后续东海或神兽森林扩展 |
| 火龙岛隐藏 | 柱顶宝石变色 | 可转化为机关解谜型副本 |
| 尾妖林隐藏 | 点亮鬼火/攻击心脏 | 可作为后续截教天境高难隐藏本 |

| 二十八星宿阵 | 多个星宿 BOSS | 后续星宫主城和通天塔高层的内容库 |

### 活动型 BOSS

三代有大量节日或活动 BOSS，例如年兽、大年兽、雪人、圣诞老人、南瓜怪、糖果皇帝、月老、清明白骨精、邪生肖等。它们适合作为上线后的节日活动模板，不应计入首发三主城必须施工范围。

### 美术风格

- 三代比一、二代更明亮，天宫区域使用云海、金色宫殿、彩虹桥、玉石台阶、神将盔甲。
- 隐藏副本强调机关感：云团、灯、墙门、漩涡、柱顶宝石。
- 玲珑宝塔和兜率宫适合承载“爬塔、炼丹、法宝进阶”的长期成长视觉。

### 小怪生态

| 区域 | 小怪方向 | Y3 用途 |
|---|---|---|
| 天宫道/南天门 | 天兵、天将、弓兵、云兽 | 天庭公共野外基础生态 |
| 天王殿 | 持盾神将、机关神像、元素护卫 | 四天王前置怪、护盾/光环/元素抗性 |
| 彩虹楼/朝会殿 | 机关守卫、宫殿妖将 | 机关路线、精英巡逻、终局前压力 |

## 三代内容糅合规则

### 不能照搬的地方

- 不能把三代所有关卡一字排开做成超大线性地图，Y3 俯视 ORPG 会变成赶路和空场景堆积。
- 不能让三个主城共享同一副本地形，用户已经明确每个主城都要有独立副本区域。
- 不能把三代后期活动、节日 BOSS、隐藏副本全部塞进 v1.0，否则首发范围会失控。
- 不能按原横版跳跃机关原样移植，Y3 需要转化成俯视角的区域触发、机关交互、站位和阶段技能。

### 必须继承的地方

- 关卡推进：每篇都有“主城 -> 公共野外 -> 副本入口 -> BOSS -> 更高阶挑战”。
- 隐藏入口：水帘洞龙宫、天宫道云团、御马监墙门、彩虹楼灯机关，都可以转化为 Y3 的隐藏交互点。
- 多阶段 BOSS：牛魔王、白骨精、转轮王、杨戬/神将都应有阶段变化。
- 装备粘性：每篇产出不同材料和装备阶级，避免玩家只刷最高收益单点。
- 长期挑战：玲珑宝塔、螺旋地狱、通天塔应合并为首发长期上升空间。

## Y3 落地注意

- 三主城应放在同一张 Y3 地图中，用传送阵/UI 移动到不同区域，避免多地图异步问题。
- 公共野外可以共享玩家视野和怪物资源，但副本必须用状态锁、参与者名单、倒计时、死亡/团灭失败清理。
- 首发每篇只做 1 个单人本、1 个团队本、1 条公共野外路线，再用通天塔补长期目标。
- 天庭篇的玲珑宝塔不应再单独做一个超大副本区，而应和全局通天塔统一，避免“天庭有塔、中心也有塔”的重复感。
- 东海水域一阶段内容保留在花果山篇，蛟魔王、鲨魔王先作为首发水域区域 BOSS；后续东海主城再引入二阶段、深海形态、水下迷宫和更完整的海域玩法。
