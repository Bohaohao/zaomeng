# 花果山篇野外怪物与 BOSS 设计

## 核心结论

花果山篇不应该把原作所有 BOSS 都做成完整 BOSS 战。

首发版本只有花果山、地府、天庭三个篇章，第一篇章需要承担新手引导、成长起步、隐藏副本、首个团本和长期刷取入口。如果把《七魔王篇》的每个 BOSS 都做成完整机制战，会出现三个问题：

- 第一篇章节奏过重，后续地府和天庭缺少递进空间。
- 制作成本过高，首发三篇章都会被花果山消耗掉。
- 玩家刚进游戏就连续打 BOSS，普通刷怪、收集、装备成长、隐藏探索的节奏会被压扁。

因此采用三层处理：

| 层级 | 用途 | 数量建议 | 设计强度 |
|---|---|---:|---|
| 野外大精英 | 承接原作低中阶 BOSS 的形象记忆 | 4-5 个 | 1-2 个核心技能，短战斗 |
| 野外区域 BOSS | 作为公共野外阶段目标 | 3 个 | 2-3 个技能，轻阶段或低血量狂暴 |
| 副本/团本真 BOSS | 承担装备、法宝、宠物和篇章终局 | 龙王、牛魔 | 多阶段、掉落核心道具 |

简单说：精简真 BOSS，弱化部分 BOSS 为大精英；鹏魔王不作为公共野外最终 BOSS，蛟魔王、鲨魔王保留在花果山篇，后续东海篇再做二阶段。

| 猕猴王 | 野外区域 BOSS | 形象适合花果山，能作为水帘洞外缘阶段目标 |

| 龟丞相 | 龙宫门将精英 | 放进龙宫副本内部，不作为公共野外 BOSS |

| 鲨魔王 | 鲨之涡流区域 BOSS，一阶段 | 保留在花果山篇，作为公共野外后段压轴；后续东海篇引入二阶段 |
| 龙王 | 龙宫隐藏单人本最终 BOSS | 已确定为一阶段/二阶段分流挑战 |
| 牛魔王 | 火焰山团队本最终 BOSS | 已确定为人形态/披甲白牛两阶段 |

## 野外区域划分

花果山公共野外建议做成 5 个连续区域，每个区域都有普通怪、精英怪和一个阶段目标。东海前缘加入后，怪物数量会增加，因此水域怪物应尽量和龙宫副本共用素材、动作和技能变体，控制首发制作量。

```text
花果山山道
-> 水帘溪谷
-> 桃林与蝙蝠窟
-> 七星洞与迦楼罗崖
-> 东海前缘与鲨之涡流
-> 火焰山团本入口
```

### 区域 1：花果山山道

定位：

- 新手公共野外。
- 让玩家熟悉普通怪、精英怪、公共资源、掉落和收集。
- 战斗空间应宽，怪物威胁低，死亡惩罚轻。

怪物：

| 怪物 | 类型 | 行为 | 用途 |
|---|---|---|---|
| 山猴 | 普通近战 | 小范围追击，成群出现 | 基础战斗教学 |
| 石皮山怪 | 普通坦克 | 移速慢，生命较高，短前摇拍击 | 教玩家绕背和躲前摇 |
| 藤叶小妖 | 普通远程 | 发射藤刺，偶尔减速 | 教玩家优先处理远程怪 |
| 猴群头目 | 精英 | 召唤 2-3 只山猴，短距离跳击 | 第一个精英怪 |
| 大猩猩 | 野外大精英 | 拍地震荡、投石、低血量狂怒 | 第一个大精英，绑定收集项 |

大猩猩不做成完整 BOSS。它应该是玩家第一次看到“血条明显更厚、技能有前摇、击杀有播报或收集进度”的目标。

### 区域 2：水帘溪谷

定位：

- 花果山与龙宫隐藏入口的连接区域。
- 怪物加入水系、跳跃、位移和隐藏探索。
- 这里应放置龙宫隐藏入口线索。

怪物：

| 怪物 | 类型 | 行为 | 用途 |
|---|---|---|---|
| 水帘小妖 | 普通近战 | 从水边刷新，短距离突进 | 增加临水区域活性 |
| 泉灵 | 普通辅助 | 给附近怪物小额恢复或护盾 | 教玩家打辅助怪 |
| 鱼妖哨兵 | 普通远程 | 水弹直线攻击，命中减速 | 为龙宫水系怪物预热 |
| 水帘妖卫 | 精英 | 水盾、扇形水波 | 龙宫入口守卫前置 |
| 水帘妖卫·潮痕载体 | 特殊精英变体 | 潮痕外溢、短暂护潮，靠近潮痕石时进入可收束状态 | 巡猎 Lv8 残响收束与无职业门槛机制教学 |
| 猕猴王 | 野外区域 BOSS | 分身突袭、旋风棍、召唤猴群 | 水帘溪谷阶段目标 |

`水帘妖卫·潮痕载体` 在首次经过水帘溪谷时固定出现一只，后续按精英刷新规则出现。它是明确的 `trace_bearing=true` 遭遇：靠近潮痕石后，所有职业都可完成 `encounter_action_key=stabilize_tide_trace`，不要求巡猎技能或任何特定职业。成功时潮痕收束、该单位转为普通水帘妖卫并后撤；超时、离场或选择直接击败时，它退回常规精英战斗路线。固定可见范围为 `resolution_text_scope=initiator_team_same_map`，即仅发起者同地图队伍看成功/失败文字；`world_state_scope=encounter_local_18`，即 18 cell 内所有玩家只看水脉环境变化和中性提示，不看结果文字。两种结果都不发放稀有奖励，巡猎猎印仍始终只对本人可见。该公共残响遭遇不写入、阻断或撤销任何职业教学路线键；巡猎 Lv8 龙宫通行只由其私有的 `C04_ROUTE_LV8_hunt/wind/bind` 决定。该遭遇的 `trace_resolution=stabilize_tide_trace`、成功/失败结果与可见范围必须由地图侧显式配置。

水帘妖卫属于水帘溪谷周边的失序水族与雇佣守卫，不代表花果山妖盟或四海龙庭整体立场；潮痕只是附着在其中一名个体上的外来残响。环境态在本次遭遇收束、失败或常规击败后仅保留 `30` 秒，之后由下一名载体重新开始，不能把一次公共结果写成永久改变整个水族阵营。

猕猴王建议作为第一个野外区域 BOSS。它需要比大猩猩更像 BOSS，但不要做成复杂多阶段。可以有低血量狂暴：

- 100%-30% 血：分身突袭、旋风棍、召唤猴群。
- 30% 以下：攻击速度提高，分身数量增加。

掉落以花果山材料、低阶装备、龙宫入口线索、收集进度为主，不掉落核心毕业装备。

### 区域 3：桃林与蝙蝠窟

定位：

- 中段公共野外。
- 让玩家从明亮山林进入阴暗洞窟，形成视觉变化。
- 怪物开始出现控制、召唤和机关。

怪物：

| 怪物 | 类型 | 行为 | 用途 |
|---|---|---|---|
| 桃花妖 | 普通远程 | 花粉弹，短暂降低命中或移速 | 桃林主题控制怪 |
| 迷踪猴 | 普通近战 | 短距离闪避，攻击后后跳 | 教玩家处理灵活怪 |
| 洞窟蝙蝠 | 普通飞行 | 俯冲攻击，生命低 | 群怪压力 |
| 洞窟小妖 | 普通近战 | 成群出现，配合蝙蝠 | 洞窟基础怪 |
| 禺狨王 | 野外大精英 | 幻影跳跃、迷雾圈、分身诱导 | 桃林阶段大精英 |
| 蝙蝠石像 | 野外机关大精英 | 召唤蝙蝠、扇形音波、石化短停顿 | 蝙蝠窟阶段大精英 |

禺狨王和蝙蝠石像都不建议做成完整野外 BOSS。它们更适合做中段大精英，让玩家觉得原作 BOSS 被保留了，但不会抢走龙宫和火焰山的核心地位。

### 区域 4：七星洞与迦楼罗崖

定位：

- 花果山公共野外的山洞高阶区域。
- 玩家在这里完成进入东海前缘前的战力检查。
- 怪物开始出现高伤害、高机动和火焰山前置元素。

怪物：

| 怪物 | 类型 | 行为 | 用途 |
|---|---|---|---|
| 七星洞妖 | 普通近战 | 普攻附带轻微破甲 | 高阶普通怪 |
| 山魈术士 | 普通远程 | 小范围地刺，提示圈明显 | 地面预警教学 |
| 飞翼妖 | 普通飞行 | 直线俯冲，落地短暂停顿 | 为鹏魔王预热 |
| 牛魔斥候 | 精英 | 冲锋、火焰挥砍 | 火焰山团本前置怪 |
| 狮驼王 | 高阶野外大精英 | 撕裂冲锋、压制吼、护甲强化 | 火焰山前置强敌 |
| 鹏魔王 | 高阶野外大精英（可选高崖侧袋） | 俯冲、风刃、风眼、短暂升空 | 东海前缘前的可选高机动挑战 |

鹏魔王不作为花果山公共野外最终 BOSS，也不是区域守门 BOSS。它位于迦楼罗崖的可选高崖侧袋，东海前缘始终有南侧绕行主路可通，不因其存活、刷新、击杀归属或队伍状态关闭。击杀后可以提供：

- 可选的个人大精英收集进度与首通展示。
- 非关键经验、材料和外观/称号类候选奖励。
- 对俯冲、风眼和高机动走位的战斗预演。

它**不**解锁东海前缘、不推进花果山主线、不充当火焰山或龙宫入口前置。若将来把它的可选收集写入角色记录，仍按个人有效参与写入，不能被最高 DPS、同队 10% 同步击杀或他人先击杀阻断。

### 区域 5：东海前缘与鲨之涡流

定位：

- 花果山篇后段公共野外。
- 承接原作东海龙宫、鲨之涡流段落。
- 让花果山篇在进入火焰山前有一次明显的水域主题变化。
- 蛟魔王、鲨魔王在首发只做一阶段；后续东海篇再引入二阶段。

怪物：

| 怪物 | 类型 | 行为 | 用途 |
|---|---|---|---|
| 鱼妖巡兵 | 普通近战 | 水边巡逻，短距离冲刺 | 水域基础怪 |
| 龟甲守卫 | 普通坦克 | 护盾、慢速撞击 | 教玩家破盾或绕开正面 |
| 水灵术士 | 普通远程 | 水弹、减速水洼 | 控场压力 |
| 漩涡妖兵 | 精英 | 在脚下生成小漩涡，短暂牵引 | 为鲨魔王机制预热 |
| 漩涡妖兵·裂潮节点 | 特殊精英变体 | 生成可交互的裂潮锚点，未处理时扩散为小漩涡 | 巡猎进阶收网与公共机制的后段预演 |
| 蛟魔王 | 野外区域 BOSS，一阶段 | 水柱、甩尾、召唤水兵、短暂潜入 | 东海前缘阶段目标 |
| 鲨魔王 | 野外区域 BOSS，一阶段 | 直线撕咬、涡流牵引、低血量狂暴 | 花果山公共野外后段压轴 |

`漩涡妖兵·裂潮节点` 是 `trace_bearing=true` 的后段变体。所有职业均可在裂潮锚点完成 `encounter_action_key=seal_vortex`；成功时裂潮收束、该单位降为普通漩涡妖兵，失败时保留常规精英战斗与小漩涡压力。固定可见范围同样为 `resolution_text_scope=initiator_team_same_map` 与 `world_state_scope=encounter_local_18`：发起者同地图队伍看结果文字，18 cell 内所有玩家只看裂潮环境变化与中性提示。它的 `trace_resolution=seal_vortex`、结果和可见范围同样必须由地图侧配置；不得把收束行为绑定为巡猎专属奖励或主线门票。

漩涡妖兵是被裂潮雇用或裹挟的无阵营水族，不等于四海龙庭的集体敌对；裂潮节点是外来残响，普通漩涡妖兵不默认带该标签。收束、失败或常规击败后的局部水环只保留 `30` 秒，下一节点显形时重新以未处理状态叙述。

蛟魔王与鲨魔王的首发定位：

- 它们保留在花果山篇，但不做二阶段。
- 不掉落东海篇毕业材料。
- 主要承担公共野外后段目标、首通奖励、收集进度、火焰山前置。
- 后续东海篇开放时，二阶段可以解释为“真身复苏”“深海形态”或“海渊强化”。

鲨魔王作为公共野外后段压轴，比鹏魔王更合适。原因是它的场景记忆点更强，和鲨之涡流绑定后，可以给玩家一种“花果山篇野外已经打穿到东海边界”的感觉。

### 命名首领的世界形态

| 首领 | 首发世界形态 | 重复出现解释 | 真身/后续剧情归属 |
|---|---|---|---|
| 猕猴王 | 裂隙劫力凝成的**化身** | 公共刷新是同一瀑布台劫力再次凝形；副本复刷改由梦墟劫痕承接 | 真身去向留给东胜妖盟后续线，不在花果山首发主线重复击杀 |
| 禺狨王 | 桃林惑雾凝成的**化身** | 桃林雾脉重新汇聚时形成同类战斗形体，不把大精英重刷写成真身复活 | 真身归属东胜妖盟的幻形支线；首发只保留其扰乱桃林的前哨形态 |
| 蝙蝠石像 | 蝙蝠窟古阵投下的**劫痕** | 洞阵复位后重新投射石像与蝙蝠潮；击破的是本次阵痕，不是可反复死亡的实体真身 | 古阵与其最初建造者留给梦墟/东胜遗迹线，首发不定义为活体首领 |
| 狮驼王 | 通行门前的**化身** | 公共大精英重聚不改变东海通行资格；南侧绕行主路始终可走 | 真身归属东胜高阶妖王线，首发只展示其前哨压力 |
| 鹏魔王 | 高崖风眼的**化身** | 高崖口袋重复的是风眼投下的战斗形体；其存在不关闭南侧东海绕行主路 | 真身与后续风域/东胜支线关联，不作为花果山终局或主线门槛 |
| 龟丞相 | 龙宫海眼守望职能的**化身** | 单人副本复入由梦墟劫痕重演门将考验；不把龙庭长者写成被玩家反复杀死 | 真身属于四海层龙庭秩序线，花果山只接触受海眼约束的门将形态 |
| 蛟魔王一阶段 | 海眼受限的**化身** | 潮汐口袋重刷为海眼再次投出的受限形体 | 二阶段明确属于东海篇的深海真身复苏 |
| 鲨魔王一阶段 | 涡流拘束的**化身** | 涡流重聚后再次形成一阶段形体 | 二阶段明确属于东海篇的海渊强化真身 |
| 龙王一/二阶段 | 龙宫海眼中的**化身 / 极化体** | 单人副本重复进入梦墟劫痕，不把龙王本体反复杀死 | 真身剧情归四海层龙庭主线处理 |
| 牛魔人形 / 披甲白牛 | 熔脉旧战场的**劫痕** | 团本复刷是同一旧战场重演 | 牛魔真身只在后续妖王主线承担一次关键剧情 |

上述表是世界观硬规则的唯一花果山落点；“一阶段”不再作为无解释的占位称谓。

## 野外 BOSS 与副本 BOSS 的边界

为了让玩家有可玩性，同时保留三篇章内容空间，花果山篇首发应遵守以下边界：

| 类型 | 示例 | 是否锁副本 | 是否多阶段 | 是否掉核心法宝/宠物 |
|---|---|---|---|---|
| 野外大精英 | 大猩猩、禺狨王、蝙蝠石像、狮驼王、鹏魔王 | 否 | 否或轻阶段 | 否 |
| 野外区域 BOSS | 猕猴王、蛟魔王一阶段、鲨魔王一阶段 | 否 | 轻阶段 | 否 |
| 单人本 BOSS | 龙王一阶段、龙王二阶段 | 是 | 是 | 是 |
| 团队本 BOSS | 牛魔人形态、披甲白牛形态 | 是 | 是 | 是 |

野外大精英和野外区域 BOSS 的奖励重点：

- 经验。
- 金币。

## 刷新与参与规则建议

普通怪：

- 刷新快。
- 成群分布。
- 掉落基础材料。
- 用于日常刷怪、收集、任务。

精英怪：

- 小范围固定点刷新。
- 战斗时长略长。
- 有 1 个明显技能。
- 掉落强化材料、收集材料。

野外大精英：

- 刷新间隔中等，建议 3-6 分钟。
- 所有玩家可见。
- 击杀后有小范围播报或 UI 提示。
- 掉落以个人参与奖励为主，避免 4 人抢怪造成负反馈。

野外区域 BOSS：

- 刷新间隔更长，建议 8-12 分钟。
- 有明显出生点和活动范围。
- 击杀归属不按尾刀，按本次战斗有效伤害贡献计算。
- 有效伤害贡献最高的玩家获得主要击杀归属；其同队成员有效伤害占比严格大于 10% 时同步计入击杀。该记录只用于荣誉、公告、队伍战绩和可选的非关键首通展示。
- **篇章入口、主线、保证性收集和角色首通**采用个人有效参与完成：玩家在同一 BOSS 实例、当前生命周期与有效战斗范围内，满足至少 `3%` 有效伤害**或**完成一次遭遇明确开放给所有职业的 `encounter_action_key`、指定破韧、有效护守或机制目标，即写入个人推进；不要求成为最高 DPS 或同队大于 10%。场地互动、站位、搬运等 `encounter_action_key` 必须无职业专属门槛；同一玩家对同一 BOSS 实例、阶段和行为键最多计入一次，事件 ID 不得重复。
- 个人掉落、队伍掉落、稀有装备资格和保底奖励另行制定；有效参与可给非稀有参与箱，但绝不替代稀有资格。花果山“首次击杀”默认指**角色首次有效参与完成**，全服播报与队伍荣誉不占用或阻断该个人进度。

| 首领 | `guardable_direct` | `periodic_or_area` | 对镇界的教学 |
|---|---|---|---|
| 猕猴王 | 旋风棍终段、分身突袭落点 | 猴群投石、场地残风 | Lv8-Lv14 预判架界格 |
| 蛟魔王 | 水柱重击、甩尾 | 潜入水洼、持续水流 | 区分直击与地面持续伤害 |
| 鲨魔王 | 直线撕咬 | 漩涡牵引、低血量涡流 | 破韧与走位并行 |

### 公共 BOSS 追迹与参与行为标签

| 猕猴王 | 分身持续 `2.5` 秒；真身全程保持可攻击，分身均为独立 Unit ID，不继承真身猎印 | 不发 `trace_pause`；不需要 `trace_transition` | `stabilize_wind_eye`：分身结束后 `1.5` 秒内处理残风眼 | 成功一次可作为非稀有参与行为；不改变击杀、稀有掉落或巡猎私有猎印 |

每个公共行为必须由遭遇侧上报带 `kind/event_id/actor_id/lifecycle_id/boss_instance_id/phase_id/boss_target_id/boss_target_lifecycle_id/interaction_unit_id/interaction_unit_lifecycle_id/encounter_action_key` 的事件；公共事件强制 `combat_scope=public` 且 `session_instance_id/session_epoch=nil`。职业只能消费结果，不能自行推断、补记或越权发奖。

### 公共行为执行矩阵

以下数值是花果山首发白盒值，交互半径以 terrain cell 计；真实 Y3 距离只允许等比换算，不能缩短窗口、改变并发或把动作移到主路。三个行为均使用通用交互，不读取职业、技能、装备、法宝或宠物状态；每个 BOSS 口袋提供最多 4 个按 `actor_id` 绑定的并发交互位，不采用“先点先占”的独占锁。

| 首领 / 行为键 | 开放窗口与位置 | 交互、并发与中断 | 成功、协同确认与个人计数 |
|---|---|---|---|
| 猕猴王 `stabilize_wind_eye` | 分身结束时在 `pt_hg_wind_eye_slot + area_hg_wind_eye_interact` 开启，`close_tick = clone_end + 1.5s`；交互半径 `3 cell` | 通用读条 `0.4s`，四名玩家可并发；离开范围、死亡、失去操作权、生命周期失效或窗口结束立即取消，可在窗口内重试 | 首个完成者只触发一次本次 occurrence 的全局“残风收束”；其余未计数玩家仍可在原窗口完成“协同确认”，取得本 occurrence 个人行为记录但不重复改变场地 |
| 蛟魔王 `drain_tide_eye` | 潜入开始即在 `pt_hg_tide_eye_slot + area_hg_tide_eye_interact` 开启，`close_tick = dive_start + 3.0s`；交互半径 `3 cell` | 通用读条 `0.8s`，最晚在 `close_tick - 0.8s` 前开始；四名玩家可并发。中断、失败与重试规则同上，不得缩短或延长潜入 | 首个完成者只把本次 occurrence 的潮眼标为稳定，潜入仍按原时间结束；其余未计数玩家可在剩余窗口完成“协同排潮”取得个人行为记录，不重复修改场地 |
| 鲨魔王 `stabilize_vortex_anchor` | 每次涡流预警开始时在 `pt_hg_vortex_anchor_slot + area_hg_vortex_anchor_interact` 开启，固定 `3.0s` 窗口；交互半径 `3 cell`，必须在 `area_hg_shark_anchor_safe_line` 内、`area_hg_shark_vortex_core` 外 | 通用读条 `0.8s`，Boss 本体继续可攻击；四名玩家可并发。锚点关闭、Boss 死亡、阶段切换、离开范围或生命周期失效时取消，窗口内可重试 | 首个完成者只稳定本次 occurrence 的涡流场地，不改变 BOSS 血量、击杀、稀有资格或火焰山入口；其余未计数玩家在原窗口可完成“协同确认”取得个人行为记录 |

所有成功事件固定为：

```text
kind = encounter_action_success
window_id = <boss_instance_id>:<phase_id>:<mechanic_occurrence_id>:<encounter_action_key>
event_id = <window_id>:<actor_id>
actor_id / lifecycle_id / boss_instance_id / phase_id
boss_target_id / boss_target_lifecycle_id = 窗口开启时冻结的 Boss 本体
interaction_unit_id / interaction_unit_lifecycle_id = 本次场地交互物
encounter_action_key / mechanic_occurrence_id / completed_tick
completion_mode = primary | assist
combat_scope = public
session_instance_id / session_epoch = nil
```

窗口开启时，遭遇权威端建立 `encounter_event_origin_index[window_id]={boss_instance_id,phase_id,boss_target_id,boss_target_lifecycle_id,interaction_unit_id,interaction_unit_lifecycle_id,open_tick,close_tick}`。同一公共窗口的 `primary/assist` 只能由该权威端原子仲裁：它先校验完成事件仍匹配原窗口、Boss 本体生命周期、当前阶段与交互物生命周期，再按 `(boss_instance_id, phase_id, mechanic_occurrence_id, encounter_action_key, completed_tick)` 聚合同 tick 完成者，以 `completed_tick -> actor_id` 稳定排序。首个成功写入唯一 `resolved_primary_actor_id` 并得到 `primary`，其余合法完成者一律得到 `assist`。该写入和场地改变必须是同一权威事务；客户端、本地读条结束顺序或 UI 回调均不得自行决定 primary。跨 tick 的后来完成者只能为 assist，已解析窗口不会因断线重放改变 primary。Boss 死亡、换相、本体/交互物重建或 origin 不匹配时，窗口不写任何成功记录。

遭遇侧按 `event_id` 去重，并按 `(actor_id, boss_instance_id, phase_id, mechanic_occurrence_id, encounter_action_key)` 限制**每个机制 occurrence 一次**成功。`assist` 只写个人参与记录，不重复改变公共场地；每名玩家在同一 phase 的首个合格行为事件才可写入项目级“行为已参与”资格，之后 occurrence 的记录只用于本次行为与反馈，不重复增加参与箱、首通、保底或奖励进度。未完成读条、超时、旧生命周期、Boss 死亡或阶段失效都不写入贡献账本。有效遭遇参与箱仍额外校验该玩家对该 BOSS 的有效伤害占比 `>=3%`，行为本身不能替代伤害、同步击杀或稀有掉落资格。

| 时点 | 权威可见信息 | 固定提示 | 奖励边界 |
|---|---|---|---|
| 窗口开启 | 行为名、剩余时间、交互半径与当前已响应人数 `0-4`；`world_state_scope=encounter_local_18` | `残风眼/潮眼/涡流锚点：剩余 X.X 秒，已响应 N/4` | 18 cell 内只看中性场地预警；只告知公共行为，不承诺击杀、掉落或稀有资格 |

## 首发制作优先级

### 必做

- 5 个野外区域。
- 12-14 种普通怪，允许同模型换技能或换色变体。
- 6-8 种精英/大精英。
- 3 个野外区域 BOSS：猕猴王、蛟魔王一阶段、鲨魔王一阶段。
- 野外怪物基础掉落和收集联动。
- 龙宫隐藏入口线索。
- 火焰山团本前置解锁。

### 应做

- 大猩猩、禺狨王、蝙蝠石像、狮驼王、鹏魔王各有独立小技能。
- 野外区域 BOSS 有出生提示和击杀提示。
- 野外 BOSS 参与奖励按个人结算。
- 首次击杀和重复击杀奖励分开。

### 后续可加

- 蛟魔王二阶段、鲨魔王二阶段、东海水域主城支线。
- 更复杂的公共事件，例如猴群突袭、蝙蝠潮、飞翼妖巡逻。
- 野外 BOSS 稀有外观或称号。
- 花果山篇噩梦公共野外或精英刷新变体。

## 风险与约束

- 野外 BOSS 过多会让第一篇章显得臃肿，并削弱龙宫和火焰山的存在感。
- 蛟魔王、鲨魔王留在花果山篇后，必须控制为一阶段轻机制，不能提前消耗后续东海篇的二阶段空间。
- 稀有掉落不能全部塞到野外，否则玩家会长期蹲点抢怪。
- 大精英技能不能太复杂，否则制作成本接近真 BOSS。
- 花果山篇必须保留“新手友好”的手感，不能因为原作 BOSS 多就把普通玩家第一小时打崩。
