## 一、职业定位

| 项目 | 设计口径 |
|---|---|
| 职业代码 | `C01` |
| 法门 | 破妄 |
| 武器 | 长兵，首发动作骨架兼容长棍、长枪、长戟类外观 |
| 战斗距离 | 近战，以 `1-5` 个角色身位为主要作用范围 |
| 核心体验 | 普攻与生势技能连续压迫，主动储存战势，在高战势时用耗势技能兑现爆发 |
| 战斗优势 | 连击顺滑、主动位移、单体爆发、范围破韧、可提供轻量团队减防 |
| 明确短板 | 需要贴身输出；高收益依赖有效命中与战势管理；远离目标后战势会衰减 |
| 单人能力 | 依靠位移、短时减伤、少量自我恢复完成主线、单人本和通天塔 |
| 团队职责 | 持续近战输出、破韧、显妄减防；不是强制坦克，也不是团队唯一控制来源 |

破妄不复刻任何原作角色的专有技能。其动作语言以长兵的横扫、突刺、回身和压阵为主，法术表现采用清晰的白金裂纹、短促风压和实体兵器残影，不使用角色化猴形分身或原作标志性动作。

## 二、设计标尺与伤害口径

### 2.1 设计身位

- `1 身位`：破妄角色默认碰撞直径，仅用于策划白盒描述。
- 正式施工前，必须在 Y3 实机中校准角色碰撞、移动速度、普攻距离和技能指示器，再转换为引擎单位。
- 本稿中的距离不直接写入物编，避免在未接入真实地图时伪造场景尺度。

### 2.2 伤害系数

本稿所有百分比伤害均表示物理攻击系数：

```text
技能基础伤害
= 角色最终物理攻击
× 技能攻击系数
× 目标防御结算
× 暴击、增伤、减伤与其他最终修正
```

- 直接命中可以独立暴击。
- 标记为“回响”或“裂痕”的追加伤害默认不能独立暴击，但会继承施法者的通用增伤。
- 固定数值、属性成长、目标防御公式和暴击公式不在本职业稿中锁定。
- 所有系数均为白盒初值，不能直接视为最终上线数值。

### 2.3 破韧系数

- 以一次普通攻击单击的破韧量为 `1.0` 个标准破韧系数。
- 普通怪可正常承受击退、减速和定身。
- 精英对硬控制使用缩短时长。
- BOSS 不承受常规定身或击退，相关效果转换为破韧系数。
- BOSS 破韧阈值、倒地时长和短期控制递减由全局战斗数值稿统一确定。

## 三、固定职业被动与资源循环

### 3.1 固定被动：破妄真意

| 字段 | 规格 |
|---|---|
| 稳定记录键 | `C01_F01` |
| 获得方式 | 创建角色时自动拥有，不消耗技能点，不占主动槽 |
| 主资源 | 战势，范围 `0-100` |
| 次级能量 | 绝技值，范围 `0-100` |
| 一般循环 | 普攻/生势技能命中 -> 储存战势 -> 达到洞明阈值 -> 耗势技能兑现 -> 继续生势 |
| 断循环 | 连续 4 秒没有直接有效攻击后，战势以每秒 12 点衰减至 0 |

破妄不额外使用蓝条。物编中的普通法力消耗保持为 `0`，战势和绝技值由同步 Lua 逻辑结算。

### 3.2 有效攻击

以下条件同时满足才算有效攻击：

- 由本人普通攻击或破妄主动技能直接造成。
- 对可参与战斗结算的敌对单位造成大于 0 的伤害。
- 目标不是无敌、剧情假人、环境装饰、友军或无奖励刷势物件。
- 周期伤害、法宝、宠物、召唤物和队友伤害不会刷新破妄本人的战势衰减计时。

### 3.3 普通攻击生势

长兵普通攻击采用三段循环：

| 段数 | 战势 | 主要动作 |
|---:|---:|---|
| 第一段 | `+4` | 短横扫 |
| 第二段 | `+4` | 反向回扫 |
| 第三段 | `+7` | 前踏重击 |

- 完整三段总计 `15` 点战势。
- 连段中断窗口暂定 `1.4` 秒，从上一段攻击完成时开始计算。
- 攻速只改变动作间隔，不改变每段战势值。
- 同一普通攻击即使命中多个目标，也只产生一次对应段数的战势。

### 3.4 生势来源

| 来源 | 单体战势 | 多目标上限 | 备注 |
|---|---:|---:|---|
| 普攻三段 | `4/4/7` | 每段固定 | 不按目标数增加 |
| `C01_A01` 开锋式 | `10`，3级后 `12` | 每个额外目标 `+2`，最多额外 3 个 | 单次最多 `18` |
| `C01_A03` 叠锋三破 | 每段 `+5` | 固定 | 三段同中一个目标后额外 `+3`，单次最多 `18` |
| `C01_A04` 踏虚行 | `12` | 固定 | 每次释放只结算一次 |
| `C01_A05` 照妄横扫 | `10`，3级后 `12` | 每个额外目标 `+2`，最多额外 3 个 | 单次最多 `18` |
| `C01_U01` 万妄俱破 | 固定 `+35` | 固定 | 不产生绝技值 |

任何一次生势都不能使战势超过 `100`，溢出部分直接损失。溢出损失是破妄需要主动管理的效率成本，不自动转化为伤害、护盾或绝技值。

战势始终使用整数，单次结算顺序固定为：基础生势与多目标加成 -> 真境生势倍率并向下取整 -> 势行不滞固定加值 -> `0-100` 截断。后续装备资源词条也必须插入统一结算层，不能由各技能自行取整。

### 3.5 耗势与洞明

| 耗势技能 | 消耗 | 绝技值收益 |
|---|---:|---:|
| `C01_A02` 贯心式 | `30` | `+6` |
| `C01_A06` 断岳裁 | `50` | `+10` |
| `C01_A07` 回锋照影 | `25` | `+5` |
| `C01_A08` 定真贯阵 | `40` | `+8` |

统一结算规则：

- 释放前战势达到 `80` 时，角色进入可视状态“洞明”。
- 耗势技能在提交释放时先记录是否满足洞明，再扣除该技能的固定战势。
- 洞明不额外扣除战势，只启用该耗势技能自己的洞明强化。
- 技能在释放提交前被打断，不扣战势；提交后被打断或落空，战势不返还。
- 只有技能在本次释放窗口内命中有效敌人，实际消耗的战势才按 `1 战势 = 0.2 绝技值` 结算绝技值。
- 退款、被动补回和绝技赠送的战势不会反向产生绝技值。
- 空放防御技能、攻击无敌目标或脱战倾倒战势都不能预充绝技。

### 3.6 战斗状态清理

| 场景 | 战势 | 绝技值 | 临时标记 |
|---|---:|---:|---|
| 公共野外自然脱战 | 按衰减规则归零 | 保留 | 到期清理 |
| 角色死亡 | 清零 | 清零 | 全部清理 |
| 进入主城或跨层传送 | 清零 | 清零 | 全部清理 |
| 单人本/团本正式加锁 | 清零 | 清零 | 全部清理后开始挑战 |
| BOSS 正常转阶段 | 保留并继续衰减 | 保留 | 按各自持续时间处理 |
| 挑战失败并传送重生点 | 清零 | 清零 | 全部清理 |

挑战开始清零的目的，是防止玩家在公共野外预充资源后进入单人本或团队本。公共野外区域 BOSS 允许玩家携带当前绝技值参战，但死亡会清零。

## 四、60-90 秒标准资源循环

### 4.1 标准测试构筑

```text
开锋式 + 贯心式 + 叠锋三破 + 踏虚行 + 断岳裁
```

该构筑用于单体 BOSS 木桩测试，不代表唯一最优装配。以技能 5 级、无装备资源词条、目标持续可攻击为前提。

### 4.2 15 秒循环模块

| 时间窗 | 主要行为 | 预计战势变化 | 设计目的 |
|---|---|---:|---|
| `0-5 秒` | 开锋、叠锋、普攻穿插 | `0 -> 40-55` | 建立基础战势，不急于消费 |
| `5-9 秒` | 踏虚贴身、第二次开锋、补普攻 | `40-55 -> 80-95` | 进入洞明并避免溢出 |
| `9-11 秒` | 洞明断岳裁 | `80-95 -> 30-45` | 兑现大额爆发，获得 10 绝技值 |
| `11-15 秒` | 叠锋/开锋回填，使用贯心式 | 生成约 `35-50`，再消耗 `30` | 将资源拉回中段并获得 6 绝技值 |

稳定循环后，每 15 秒通常消耗 `80-110` 战势并获得 `16-22` 绝技值。考虑走位、BOSS 无敌段和技能落空，首个绝技的实战目标为 `60-90` 秒；纯木桩熟练循环目标为约 `65-75` 秒。

### 4.3 循环验收指标

- 单体熟练循环中，战势达到 100 后连续停留不应超过 2 秒。
- 90 秒木桩中，因溢出损失的战势应低于总生成量的 `15%`。
- 无资源装备时，绝技首次可用时间不得早于 55 秒，也不得晚于 95 秒。
- 任意合法五槽构筑至少需要 2 个生势来源和 1 个耗势来源；UI 在保存预设时给予弱提示，但不禁止特殊构筑。
- 玩家犯错落空会损失资源效率，但不能因此进入超过 8 秒完全无技能可用的死循环。

## 六、完整主动技能组

## 七、完整学习型被动技能组

所有被动最高 5 级，每级消耗 1 点自由技能点，不占主动槽。

### 7.1 共同被动

`势行不滞`同一时间只保留一次待触发加值。新的耗势命中会刷新 4 秒窗口，不会叠加多次奖励；第一个有效生势技能完成结算后立即消耗该状态。

`守意归元`使用一个 `0-50` 的隐藏计量槽。内置冷却期间最多保留 50 点，不排队储存多个治疗；冷却结束后的下一次有效耗势会触发并清空该槽。它只提供维持单人玩法的低额续航，不替代药品、法宝、队友保护或正确躲避。累计消耗按角色实例记录，死亡、跨层和挑战清理时归零。

## 九、推荐五槽构筑与技能点分配

### 9.1 公共野外与清怪

```text
开锋式 + 踏虚行 + 照妄横扫 + 回锋照影 + 定真贯阵
```

- 重点：范围生势、穿行聚怪、显妄联动和主动减伤。
- 60 点示例：五个装配主动升满；`P01/P05/P03/P07/P04/P08` 升满；贯心式额外升至 3 级。
- 点数核算：全部主动 1 级 8 点 + 五个装配主动追加 20 点 + 六个被动 30 点 + 贯心式追加 2 点 = `60`。

### 9.2 BOSS 与通天塔

```text
开锋式 + 贯心式 + 叠锋三破 + 踏虚行 + 断岳裁
```

- 重点：单体生势、洞明断岳、踏虚调整站位。
- 60 点示例：五个装配主动升满；回锋照影升至 3 级；`P01/P05/P02/P06/P03/P07` 升满。
- 点数核算：全部主动 1 级 8 点 + 五个装配主动追加 20 点 + 回锋照影追加 2 点 + 六个被动 30 点 = `60`。

### 9.3 团队破韧协作

```text
开锋式 + 叠锋三破 + 照妄横扫 + 断岳裁 + 定真贯阵
```

- 重点：维持显妄、输出破韧、在团队破防窗口兑现断岳。
- 60 点示例：五个装配主动升满；踏虚行升至 3 级；`P01/P05/P02/P06/P04/P08` 升满。
- 点数核算：全部主动 1 级 8 点 + 五个装配主动追加 20 点 + 踏虚行追加 2 点 + 六个被动 30 点 = `60`。

三套构筑都包含至少三个生势入口和两个耗势入口。它们改变的是循环节奏、站位和团队价值，不应形成“只有一个预设能玩”的假选择。

## 十、同职业并存与团队叠加

- 每名破妄独立保存战势、绝技值、技能冷却、普攻段数、破隙和被动触发计时。
- 不允许使用职业级全局变量保存任何玩家战斗状态。
- 显妄、明识和同名团队减防只呈现一个最高来源，最高来源到期后回退；团队范围不包括施法者本人。
- 回锋照影护盾按施法者来源刷新，不与自身同名护盾叠加；不同来源护盾遵循全局护盾上限。
- BOSS 控制全部转换为破韧并遵循全局短期递减，四名破妄不能通过连续定身永久控制 BOSS。
- 个人破隙、势行不滞和守意归元只由本人触发，队友不能代为消费。
