## 二、`C03-BAL-001` 统一测试口径

### 2.1 前提

所有职业对照必须在同一地图、同一版本、同一装备白名单和同一 BOSS 数据下完成。C04 巡猎尚无职业基线，本轮只比较 C01、C02、C03，禁止为了凑四职业表虚构 C04 数据。

```text
角色：Lv60，技能与被动按指定构筑满级，零法宝主动、零宠物主动
目标：固定防御、固定破韧阈值、全程可攻击、无治疗和外部增益
日志：记录最终伤害、最终有效破韧、实际吸收、实际减伤、实际净化
次数：每个样本至少重放 3 次；取中位数，不取单次最优手法
```

| 指标 | 计算方式 | C03 目标 |
|---|---|---|
| `D90` | 90 秒内所有实际造成的最终伤害之和 | 破妄 `D90` 的 `88%-92%` |
| `B10` | 指定 10 秒爆发窗内的最终伤害 | 破妄 `B10` 的 `<=92%` |
| `R90` | 90 秒内实际施加到 BOSS 的最终破韧 | 破妄 `R90` 的 `70%-78%` |
| `S_self` | 实际吸收 + 实际减伤所避免的伤害 + 合格净化收益 | 镇界同条件 `55%-70%` |
| `S_team` | 对其他队友的实际吸收、实际减伤和净化后成功脱离次数 | 镇界同条件 `35%-45%` |

### 2.2 持明标准样本

| 样本 | 构筑 / 场景 | 强制记录 | 通过条件 |
|---|---|---|---|
| `C03-S01` | 折光裁断，单体 BOSS | 每枚法印来源、每次消费、A06/A03 序列、首绝技时间、D90/B10/R90 | 第 20 枚合格 `earned` 消费约在 `84 秒`；开启绝技后 3 枚合格消费留下 `15` 点；满足 C03 预算 |
| `C03-S02` | 净域巡照，普通怪与精英群 | A05/A08 命中目标品级、控制转化、律印来源、团队净化与移动脱离 | 控制不串目标；BOSS 只转破韧；团队不获得持明团队减伤 |
| `C03-S03` | 返照协持，高压波次 | A04/A07 实际保护、空放次数、A07 队友护幕、净化替代解 | 本人能维持推进；队友保护不超过镇界预算；无持明仍可通关 |

### 2.3 法印吞吐基线

- A01 与 A02 在明界外共享 `4.0 秒` 生成窗口。A01 可作为单目标主要产印手段；A02 是路径/多目标工具，去程与回程任一首次有效命中最多共生成一枚。
- P01 只能缩短触发它的基础技能自身冷却，不能缩短共享生成窗口、不能增加单次法印、不能让同一命中多出一印。
- `earned` 法印每枚有效消费贡献 `5` 绝技；`refunded/external` 仅可支付技能，绝不充能。标准样本的第 `20` 枚合格 `earned` 消费约在第 `84 秒` 完成，立即开绝技后再消费 3 枚，应为 `15` 点绝技。
- A04/A07 替换 A03 时，法印仍被消耗，但没有实际保护或实际净化就不产生绝技值。不得用空放防护把首绝技提前。
- 绝技一阶后的 `2.8 秒` 生成窗口只影响首绝技之后的窗口，不能改变首绝技门禁。

## 三、净化标签与替代解契约

每个可由持明交互的负面效果必须有一个稳定效果键，并附以下元数据。缺任一字段时，职业逻辑必须拒绝净化，不得根据名称、图标或描述猜测。

| 字段 | 类型 / 约束 | 说明 |
|---|---|---|
| `purge_class` | `self_purge` / `team_purge` / `none` | 决定可由哪类技能清除 |
| `purge_priority` | 整数 `1-5`，5 为最高 | 同一目标仅清一项时的排序依据 |
| `effect_key` | 全局稳定键 | 同优先级的最终稳定裁决 |
| `applied_at` | 同步施加时间 | 同优先级时较早效果优先 |
| `alternative_resolution` | 非空枚举 | `dodge`、`interact`、`consumable`、`timer`、`other_profession` 之一 |
| `encounter_required` | 布尔值 | 为真时必须在遭遇表列出无持明解决路径 |

| 标签 | A04 澄心障 | A07 返照护持 | A08 净律昭域 | 首发关卡规则 |
|---|---|---|---|---|
| `self_purge` | 仅施法者本人可清一项 | 仅施法者本人可清一项 | 不清除 | 必须有替代解 |
| `team_purge` | 不清除 | 不清除 | 提交帧在领域内的每名其他队友各清一项 | 必须有替代解，禁止唯一通关 |
| `none` | 不清除 | 不清除 | 不清除 | 用于剧情、硬机制或明确不可净化状态 |

排序规则固定为：`purge_priority` 降序 -> `applied_at` 升序 -> `effect_key` 升序。A08 对每名队友独立执行一次，不能因为一名队友负面较多而吞掉其他队友的净化额度。

## 四、确定性目标、快照与多人隔离

| 场景 | 快照时机 | 筛选与稳定裁决 | 生命周期规则 |
|---|---|---|---|
| A02 澄波回环 | 去程/回程各自命中帧 | 首次命中时间 -> 到路径距离 -> `Unit:get_id()`；同目标每程一次 | 回程和命中回调带 actor 生命周期令牌 |
| A03 照影三折 | 主击命中帧 | 锁定施法时主目标；候选按本人 M02、距离、`Unit:get_id()`；无候选才以 `70%` 回击主目标 | 保存 `primary_target_id` 与 `target_refs_by_id` |
| A05 律令缚界 | 施法提交帧与初击命中帧 | 施法点缺失则拒绝；控制逐目标读取 `target_meta_by_id` | unknown 品级只执行通用伤害与减速 |
| A07 返照护持 | 施法提交帧 | 范围内所有其他队友，不设“首名”或随机选取 | 队友快照与护盾来源按 actor 隔离 |
| A08 净律昭域 | 施法提交帧 | 范围内其他队友逐人净化；P08 只判断是否至少一人成功 | 旧角色的领域/净化回调必须静默 |

所有快照同时保存稳定 ID、当前 Unit 引用、施法者 ID、actor 生命周期令牌和必要的逐目标元数据。清理命令优先使用当前对象引用；对象已不存在时只清理内部状态，不能命中新注册的同 ID 角色。

## 五、职业边界修订

| 维度 | 破妄 | 镇界 | 持明 |
