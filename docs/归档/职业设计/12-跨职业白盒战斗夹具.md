# 跨职业白盒战斗夹具

## 文档状态

- 状态：`reviewed / fixture v4 / design-only`。
- 用途：为首发职业的离线 D90、D10、首绝技与高压样本提供同一套**可执行白盒夹具**。当前先冻结 C01 破妄与 C04 巡猎的单体 BOSS 对照，并加入 C04 单人高压夹具。
- 边界：这不是 Y3 地图、物编或实机数值；真实碰撞、投射物、动画、装备和 BOSS 行为仍须在后续 Gate 单独验证。

### 1.1 固定结算与随机

```text
equipment_set = REF_EQUIP_NONE
法宝主动 / 宠物主动 / 消耗品 / 外部增益 = disabled
暴击 / 随机伤害 / 随机闪避 / 随机命中 = disabled
物理最终伤害 = floor(原始物理伤害 × 100 / (100 + 180))
原始物理伤害 = 最终物攻 × 技能系数 × 职业明示的同源倍率
```

所有倍率先完整计算，只有上述最终物理伤害式一次向下取整。周期伤害、回响、回弦、追加段和绝技派生段均遵循同一公式；没有明示的破韧、易伤、护盾、治疗或团队修正。该夹具不以随机种子取中位数：同一版本连续运行三次必须得到逐 tick 相同的动作、命中与伤害日志；任一差异都视为同步或状态机回归失败。

### 1.2 命中与行动白盒

- 每个角色每个 sync tick 最多提交一个动作，前后摇、冷却和资源仍按职业规格执行。
- 用于本夹具的直接命中在其职业 `begin_cast` 成立的同步 tick 确认；不以未冻结的投射物速度、碰撞半径或动画资源推迟命中。
- 规格明示的延迟段、脉冲、回响和回弦仍按各自 `close_tick`、独立命中和事件 ID 结算。
- 若技能有缺失目标、点位、方向、安全落点、来源或生命周期输入，按职业规格拒绝，不以此夹具替代运行时 Hook。
- C01 普攻按三段循环，固定伤害系数 `0.80 / 0.90 / 1.20`，每段 `windup=0`、`back=0`、`begin_cast_tick=close_tick=start_tick`，下一普攻候选至少相隔 `63` tick；仅战势仍按 C01 的 `4/4/7` 生成。C04 普攻固定系数 `1.00`、`windup=0`、`back=0`、`begin_cast_tick=close_tick=start_tick`，下一候选至少相隔 `60` tick。两者的零前后摇仅是离线夹具接受时钟；真实动画不得在不提升 fixture 版本的前提下改写命中和资源结算 tick。
- 周期效果的首跳、末跳、刷新 revision、到期边界与每个动作的 `start/begin/close/cooldown/action_lock` 均以职业规格为准；日志必须逐项写入，禁止用“每秒”或“攻击间隔”文本推断实际事件。
- C04 在边界桶命中结算后若绝技值首次成为 `100`，且该 tick 尚未提交新动作，允许只重检一次 `post_resolution_U01` 并在同 tick 起手；它只能覆盖本次已接受定猎回收来源动作的剩余后摇，必须写入 `action_lock_override_source_cast_id`。来源动作仍须保持已 `finalize`，不得取消、回滚或重开；该 tick 不允许第三个动作、普通攻击或任何其他主动并发，并必须完整写入动作日志。

## 五、`COMBAT_REF_L60_PRESSURE_01`

`C04-BAL-002` 只使用此夹具，版本字段为 `pressure-fixture-v2`。它是单人、零付费、无外部帮助的 20 秒确定性压力样本，不是地图的真实碰撞参数。

```text
timebase = 60Hz sync_tick
duration = [0, 20.0s)
actor = C04-BAL-002-S01 逐风长巡
actor_start = (0.0, 0.0), facing = +X, combat_scope = public, session_instance_id = nil, session_epoch = nil
skills = A01-A08 rank 5; P01/P02/P05/P06 rank 5; P03/P04/P07/P08 unlearned; U01 tier 3
slots = A01 / A02 / A04 / A05 / A07
actor_t0 = full_hp, marks 0, ultimate 0, recovery_window closed, no M01-M12, no reservations or callbacks, all cooldowns ready
target = static elite, id = COMBAT_REF_L60_PRESSURE_01, target_rank = elite, target_rank_epoch = 1
target_position = (2.0, 0.0), target_physical_defense = 120
target_lifecycle = pressure-target-life-1, target_move/attack/transition = disabled
arena = x[-7.0, 7.0], z[-5.0, 5.0], no collision, no outside targets
safe_line_north = segment x[-5.0, 5.0], z=+3.0
safe_line_south = segment x[-5.0, 5.0], z=-3.0
```

四次直击在 tick `240/480/720/960`（`4/8/12/16 秒`）结算；每次在前 `72` tick 开启唯一的 `90°` 朝 -X 扇形预警，原点为 `(2.0,0.0)`、半径 `4.5`、伤害 `25%` actor 最大生命。tick `60` 至 `1140` 每 `60` tick 结算一次轻压：以 arena 中央 `x[-1.2,1.2], z[-1.2,1.2]` 为地面区，造成 `1.5%` actor 最大生命；直击与地面区使用不同形状、音效类别和命中原因。任一 actor 在直击 tick 落在扇形内即判直击命中；在轻压 tick 位于该矩形内即判轻压命中。

输入脚本固定为：除强制走位 tick 外，每个可行动 tick 依次尝试 U01（绝技 100 且主目标有效）-> A07（主目标至少 1 印）-> A01（冷却就绪）-> A02（冷却就绪）-> 普攻；A05 不在此单目标脚本施放。四个预警的 `(warning_start, hit_tick, safe_coordinate)` 固定为 `(168,240,(0,+3))`、`(408,480,(0,-3))`、`(648,720,(0,+3))`、`(888,960,(0,-3))`。每个受击掩码 `H` 只可取六组两次命中 `4+8 / 4+12 / 4+16 / 8+12 / 8+16 / 12+16` 或四组三次反证 `4+8+12 / 4+8+16 / 4+12+16 / 8+12+16`：在 `H` 内的预警，actor 从 `warning_start` 至 `hit_tick` 固定停在 `(0,0)`；其余预警必须规避。规避第 1/4 次预警时，在 `warning_start+27` 强制尝试一次朝固定安全坐标的 A04，landing tick 为该起手后 `12` tick；规避第 2/3 次预警时，自 `warning_start` 起沿直线以移速 `3.85` 移向固定安全坐标，抵达后保持至 `hit_tick`。每次规避结算后于 `hit_tick+1` 沿直线以同一移速回到 `(0,0)`；所有坐标、起止 tick、A04 合法性与冷却结果均写入日志，不能用“向安全线移动”代替。每个 `H` 另建 `direct_off_control(H)`：动作、移动、停留、A04 成功/冷却结果与 `H` 完全一致，仅将该四次直击伤害关闭；它是该路线唯一 D20 对照，不再用不同走位的“无直击”样本横比。`H=none` 的四次全规避样本只用于阅读性与脚本回归。P02 治疗只允许由脚本中真实完成的定猎回收触发，写入生命日志但不计入 D20。

每次重放必须输出：`route_id=H|direct_off_control(H)`、`impact_damage_enabled=true|false`、每 tick 坐标、移动目标、动作 `start/begin/close`、公开 `session_instance_id=nil/session_epoch=nil`、目标 `target_rank/target_rank_epoch`、预警状态、直击/轻压命中或 `would_hit`、生命、M01 层数、定猎/回收、P02 实际治疗和 `final_damage`。`H=none`、每个两次组合、对应的 `direct_off_control(H)` 和每个三次反证各连续运行三次，三份日志必须逐 tick 完全相同。

## 六、日志与通过口径

- 每次日志必须保存：fixture 版本、职业快照、输入脚本版本、动作 `start/begin/close`、已接受命中、`final_damage` 事件 ID、每 tick 资源、目标实例/阶段、`combat_scope/session`、坐标/生命（高压样本）与总伤害。
- `D90` 为 `[0, 90s)` 所有合法 `final_damage` 之和；`D10_peak=max(s=0..4800) Σ(final_damage with tick in [s,s+600))`，`s` 以整数 sync tick 枚举，并列取最小 `s`。
- `D20` 仅用于 `COMBAT_REF_L60_PRESSURE_01`：为 `[0,20s)` 对 `COMBAT_REF_L60_PRESSURE_01` 的全部合法 `final_damage` 之和；受击样本 `H` 只能与同职业、同公开空会话、同 `route_id` 动作/移动且仅关闭直击伤害的 `direct_off_control(H)` 比较，固定 `D20_retention(H)=D20(H)/D20(direct_off_control(H))`。治疗、目标外伤害、死亡后的事件与任何私有会话事件均不计入；角色死亡使该压力样本直接失败。
- C04 对 C01 的 `D90=93%-96%`、`D10_peak<=88%` 与首绝技 `68.87-80s` 仍是**待执行验收**；本文件只冻结输入，不能替代任何通过记录。
- 夹具字段、英雄快照、目标数值、固定结算、行动优先级或时基任何一项变更，必须提升 fixture 版本并重跑全部参与职业；不同版本日志不得横向比较。
