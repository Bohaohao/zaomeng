## 二、Lv1-20 前期闭环

“解锁”只表示可以投入技能点学习，不自动送满技能。玩家仍受自由技能点和五槽装配限制。

| 等级段 | 可学习内容 | 教学目标 | 花果山承接内容 |
|---|---|---|---|
| Lv1-2 | A01 定关横扫 | 命中后获得守势 | 山猴、石皮山怪 |
| Lv3-7 | A02 拦潮刺 | 直线命中、减速、精英/BOSS 破韧 | 藤叶小妖、猴群头目 |
| Lv8-14 | A03/A04/A05 的首级 | 二段命中、短格挡、圆形选点 | 水帘溪谷、猕猴王、龙宫旧潮可尝试 |
| Lv15-17 | A06/A07/A08 的首级 | 消耗守势、界势、护盾和区域控制 | 七星洞、狮驼王、鹏魔王前置战 |
| Lv18-20 | 分支二级与首个构筑替换 | 在五槽中选择单体、护守或封域路线 | 东海前缘、蛟魔王、鲨魔王 |

- Lv1-Lv14 的守势条照常显示 `0-100`，但不显示 80 点“界势可耗”提示，避免出现无法消费的假阈值。
- 到 Lv15 后，守势达到 80 才显示界势，并高亮已学习的 A06/A07/A08。
- 龙宫旧潮维持 Lv8 开放；它是可提前尝试的隐藏本，不承担第一次界势教学。推荐挑战等级为 Lv10 以后。
- 首次真正的格挡教学安排在 Lv8-Lv14 的猕猴王或龙宫首段，首次有效护守教学安排在 Lv15 后的七星洞高压怪与鹏魔王前置战。

## 三、目标、标记与施法点契约

### 3.1 目标范围

| 范围 | 唯一含义 |
|---|---|
| `self` | 当前施法者单位 |
| `primary` | 本次技能的主目标 |
| `selected` | 本次技能几何筛选出的目标集合 |
| `team` | 施法者附近的其他队友，不包含施法者本人 |
| `explicit` | 指令明确给出的稳定单位 ID 或对象引用 |

所有效果、额外伤害和破韧指令必须显式带目标范围。清理命令必须使用 `explicit`，并优先携带对象引用与稳定单位 ID。

### 3.2 A05 钉界

1. A05 必须取得权威同步施法点。项目未提供施法点时，返回 `cast-point-required` 并不结算技能。
2. 初击只在该施法点半径 3.5 身位内筛选一次目标。命中有效敌人时，才获得守势、施加 M06 迟滞和本人 M07 界钉。
3. 三次脉冲固定在原施法点重新筛选敌人，只造成伤害与破韧；脉冲不产生守势、不刷新迟滞、不追加界钉、不施加控制。
4. 初击为空不取消领域脉冲，但不会把空放变成资源或标记来源。

### 3.3 A08 封域镇压

1. A08 同样必须取得权威同步施法点；初击与三次脉冲都固定在该点，不追踪施法者当前位置。
2. 初击对筛选目标造成基础伤害与破韧。仅被当前施法者 M07 标记的目标，再收到独立的额外伤害和 P08 额外破韧指令。
3. M11 镇压只施加给普通和精英目标；BOSS 不获得 M11，也不定身，而是按每个目标自己的品级转为破韧。
4. P08 五级的同守触发条件是“界势 A08 命中本人界钉目标”，不能因其他镇界的界钉而触发。
5. A08 提交后初击没有命中有效敌人时，按耗势落空处理：守势不返还，不生成脉冲、M11 或 P08 团队收益。

### 3.4 A03 横戈震阵

两击同中判定绑定主目标。范围内出现额外敌人不再使主目标的双击奖励失效。

## 四、伤害资格、减伤与生命周期

### 4.1 A04/A07 的权威伤害资格

控制器不根据普通“受到伤害后”事件自行猜测可格挡性。地图遭遇必须注入 `classify_guardable_damage`，返回下列布尔结果：

| 字段 | 为 true 的必要条件 |
|---|---|
| `guardable_hit` | 敌对单位造成、非周期、非自伤、命中 A04 窗口，且该攻击在遭遇表标记为可格挡直击 |
| `effective_protection` | 敌对非周期伤害实际被 A07 的护盾吸收或减伤减少，且本次伤害未被无敌、剧情免疫或已死亡状态吞掉 |

- 未注入该分类器时，两项都默认为 false，镇界不会凭普通受伤事件刷守势、反震或绝技值。
- A04、A07 每次施放都只能成功一次；多段伤害、延迟伤害和周期伤害不得重复结算。

### 4.2 减伤计算

先在类别内取最高，再跨类别乘算：

```text
R = min(75%, 1 - (1 - R_parry) * (1 - R_personal) * (1 - R_team))
```

| 类别 | 来源 |
|---|---|
| `R_parry` | M02 格挡架势 |
| `R_personal` | M03 护守、M09 不动镇守，二者只取高值 |
| `R_team` | M10 同守，多个镇界只呈现最高来源 |

装备、法宝、时装和付费便利不得直接提供守势、界势、绝技值、格挡窗口、有效护守次数或硬控制时长。首发允许的成长维度仅为基础属性、受限冷却缩减和可替代的生存词条；全局冷却缩减上限暂定 20%，职业减伤仍受上述 75% 总上限约束。

### 4.3 生命周期

- 每次 `Controller:register` 生成递增生命周期令牌。
- 延迟伤害、效果清理定时器和外部“命中确认/落空”回调都必须携带原令牌。
- 角色销毁时先注销 Trigger、停止循环与职业定时器，再清除运行时和单位映射。
- 外部 `confirm_skill_hit`、`finish_skill_miss` 必须传回原令牌；缺失令牌或令牌过期都不能影响同 `actor_id` 的新角色。

## 五、首领遭遇与公共参与

### 5.1 花果山首领攻击标签

以下是首发遭遇必须提供的最小标签，不是最终动画或伤害数值表。

| 首领 | 可格挡直击 | 不可用于格挡/护守刷取 | 设计目的 |
|---|---|---|---|
| 猕猴王 | 旋风棍终段、分身突袭落点 | 猴群持续投石、场地残风 | Lv8-Lv14 的 A04 预判教学 |
| 龙王一阶段 | 潮枪直刺、龙尾横扫 | 水压涌流、潮汐地面 | 单人本内强化直击与水域走位区分 |
| 狮驼王/鹏魔王 | 撕裂冲锋、俯冲落地 | 压制怒吼、风眼持续伤害 | Lv15 后的 A07 有效护守教学 |
| 蛟魔王/鲨魔王 | 水柱重击、直线撕咬 | 漩涡牵引、涡流持续伤害 | 把 A08 的 BOSS 破韧与走位同时教清楚 |
| 牛魔王 | 裂地重砸、人形重斩、白牛冲撞命中 | 熔火地面、持续余烬 | 团队中验证格挡、护守和破韧窗口 |

每个“可格挡直击”还需在遭遇数据中标记敌对来源、预警开始、命中结算、是否可被护盾吸收和对应破韧窗口。此表不能由职业 Lua 自行推断。

### 5.2 公共 BOSS 的双轨参与

保留原有 DPS 规则：主要击杀归属取最高有效伤害；同队成员有效伤害占比严格大于 10% 才同步计入“击杀 BOSS”记录与首杀类进度。

新增但不替代击杀记录的“有效遭遇参与”：

- 玩家必须先达到至少 3% 的有效 BOSS 伤害，防止纯挂机或只蹭队友状态。
- 再完成至少一项遭遇贡献：命中本阶段的破韧阈值、在标记直击中产生有效护守，或完成首领明确指定的机制目标。
- 有效遭遇参与可给个人参与箱、日常进度和非稀有收集计数；不改变最高 DPS 主归属，不替代大于 10% 的同步击杀，也不获得稀有装备的伤害门槛豁免。
- 每种非 DPS 贡献在单次战斗中都有遭遇级上限，具体数值放入后续资源吞吐表，不能由职业自行累计。

这样镇界的 85% 输出不会被当作无贡献职业，同时保留公共 BOSS 不被纯辅助或挂机角色稀释核心掉落的规则。

## 六、数值预算与职业身份

### 6.1 白盒预算口径

镇界的“约 85%”不是泛泛描述，后续数值测试统一使用：Lv60、裸装、五级技能、无外部增益、单一 BOSS、90 秒持续可攻击、BOSS 无无敌段、普通攻击按两职业各自基础攻频计入、最多一次职业绝技的条件。

| 指标 | 破妄基准 | 镇界目标区间 | 失败线 |
|---|---:|---:|---:|
| 90 秒单体总输出 | 100% | 80%-87% | 低于 78% 或高于 90% |
| 10 秒准备完成后的单体爆发 | 100% | 不高于 90% | 高于 90% |
| 首次绝技 | 60-90 秒 | 60-90 秒 | 早于 55 秒或晚于 95 秒 |
| 单人高压窗口 | 无强制格挡也可存活 | 护守/格挡成功时明显更稳 | 只能靠 A04 成功才可通关 |

数值通过前，镇界的“85%”只能称为离线预算，不称为实机平衡结论。`C02-BAL-001` 需在破妄、镇界同一地图木桩和同一装备白名单下输出实际日志，再决定是否调整 A06、反震、界势震波或绝技回响系数。

### 6.2 世界观边界

镇界的“镇”指守住裂口、延缓灾变、护送同伴和稳定战场，不等于永久封存有意识生命。对妖族、龙族、亡魂和失控神将，职业表现优先使用隔离、击退、破韧、暂时压制和修复界枢；主线是否宽恕、谈判或封印由剧情选择决定，不由职业机制替玩家做道德裁决。

## 七、验收与未验证项

离线已覆盖：

1. 自身、选中、团队和显式目标不串位；团队目标自动排除施法者。
2. A02 三级额外破韧只命中精英/BOSS；A03 主目标双击不被附近小怪破坏。
3. A08 额外伤害只命中本人界钉，M11 只进入普通/精英，BOSS 按目标品级转破韧。
4. 共享最高来源到期后正确回退；多个定身直到最后一层租约结束才解除。
5. 双重注册、旧 Trigger、旧延迟效果定时器和旧命中确认不能影响新生命周期角色。

仍需真实地图验证：施法点同步来源、首领攻击标签的实际事件字段、护盾吸收读数、遭遇参与积分、距离尺度、四人延迟与上述 `C02-BAL-001` 木桩日志。
