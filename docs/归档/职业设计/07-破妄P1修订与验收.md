## 二、生命周期契约

1. Controller 注册时先建立 registration、单位映射和生命周期 ID，再调用 runtime.register，因此英雄初始属性同步可以找到真实单位。
2. 适配器按 actor 加 lifecycle ID 跟踪延迟伤害、效果到期和控制租约的同步计时器。
3. remove 先撤销注册可见性，再取消职业计时器和控制租约、移除循环计时器与 Trigger，最后清理运行时和单位映射。
4. 旧的延迟伤害、效果到期、移动结束和外部命中/落空确认都不能改变同 actor_id 的新角色。
5. 挑战清理和死亡会清理该生命周期尚未结束的职业计时器、临时位移减伤和来源效果。

## 三、回锋伤害资格

回锋照影的被动反击只读取项目注入的 classify_guardable_damage 结果：

| 字段 | 允许为 true 的条件 |
|---|---|
| guardable_hit | 敌对来源、非周期、非自伤、命中回锋窗口，且遭遇表明确标为可反击直击 |
| effective_protection | 预留给需要读取护盾吸收或实际减伤的后续机制；当前回锋反击不以它单独产出资源 |

未绑定分类器时，普通单位受伤事件不再触发反击、退款或护盾。花果山首领的实际攻击标签仍待地图遭遇侧绑定。

## 四、减伤合成

破妄维持短窗自保而非镇界式常驻防护。当前离线合成规则为：

1. mobility：踏虚移动窗口和进退有据后置减伤，同类别只取高值。
2. guard：回锋照影护守。
3. recovery：守意触发的短时减伤。
4. external：未来由其他职业、机制或装备提供的减伤，必须显式声明类别。

最终计算为：先逐类取最高，再将各类剩余伤害相乘，最后限制在 70%。该上限是破妄离线桥接的安全门槛，后续真实数值日志可提出修订，但不得恢复为直接相加。

## 五、A08 逐目标规则

1. 目标桥接为每个 selected 目标写入 target_meta_by_id。
2. A08 控制命令显式带 selected、requires_target_rank 和该元数据。
3. normal 使用普通定身时长，elite 使用精英时长，boss 只获得对应破韧。
4. 某个目标没有权威品级时，A08 仍可按技能通用部分造成伤害，但不施加定身、不臆造 BOSS 转破韧。
