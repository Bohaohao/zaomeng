## 一、采纳结论

巡猎 `C04` 已采纳为第四个正式职业**设计**子基线。当前冻结的不是 Y3 编辑器对象或 Lua 实现，而是职业的战斗语法、资源真值、技能数值、效果归属、教学门禁、遭遇接口与设计级验收口径。

采纳状态固定为：

`reviewed / official-subbaseline / P1-revision-round6-complete`

它不等于 `offline-stage-accepted`、`construction-ready` 或 `verified`。

## 二、已冻结口径

| 范围 | 当前有效结论 |
|---|---|
| 职业身位 | 中远程持续输出与追踪职业；以转火、站位和区域收网换取略低于破妄的单体爆发，不提供团队必带保护、BOSS 硬控或主破韧 |
| 固定骨架 | `C04_F01`、`C04_A01-A08`、`C04_P01-P08`、`C04_M01-M12`、`C04_U01`；五主动槽与三阶绝技规则固定 |
| 资源循环 | 猎印 `0-5`、定猎回收、角色级绝对资格时钟与绝技值 `0-100`；首个资格 tick 为 `267`，首个真实回收 tick 为 `292`，首绝技目标为 `68.87-80` 秒 |
| 前期闭环 | Lv1/Lv3/Lv8/Lv15/Lv20 的技能、路线选择、公开回照、私有试炼、失败回传与五槽替换均已定义 |
| 多人和遭遇 | `actor_id=character_profile_id`；公共/私有会话隔离、冻结 Boss 快照、贡献去重、残响、品级、形态与生命周期输入均只由权威遭遇层提供 |
| 公平边界 | 零付费 Lv60 基线受 `C04-BAL-001/002/003` 约束；价格、概率、SKU、便利倍率和战力售卖字段仍禁止进入设计 |
