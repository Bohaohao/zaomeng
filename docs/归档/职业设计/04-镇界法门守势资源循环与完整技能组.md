## 一、职业定位

| 维度 | 镇界 |
|---|---|
| 职业代码 | `C02` |
| 法门使命 | 守住界门、阵地与同伴，优先隔离裂隙与灾变而非永久封存有意识生命 |
| 武器 | 重型长柄武器 |
| 战斗定位 | 承伤、反击、空间控制 |
| 单人定位 | 以格挡、护盾和反震维持稳定推进，不依赖队友触发技能 |
| 团队定位 | 提供可替代的减伤、聚怪和破韧窗口，不拥有唯一通关权限 |
| 输出预算 | 同条件 90 秒单体输出离线预算为破妄的 `80%-87%`，10 秒爆发不超过破妄的 `90%` |

镇界的动作语言是压步、横戈、架势、落钉与震地。表现使用玄岩、金色界纹和短促冲击波，不复刻任何原作角色的专有技能、形象或动作。

三条分支：

```text
镇锋：反击输出与耗势兑现
守阙：格挡、护盾与自我恢复
封域：区域限制、标记与可替代团队保护
```

## 二、固定被动与资源循环

### 2.1 固定被动：镇界真诀 `C02_F01`

| 项目 | 规格 |
|---|---|
| 主资源 | 守势，`0-100` |
| 阈值状态 | Lv15 后守势达到 `80` 获得 `C02_M01_JIESHI` 界势；下一次耗势技能提交后消失 |
| 次级资源 | 绝技值，`0-100` |
| 普通法力 | `0`；物编蓝耗、血耗均为零，守势由同步 Lua 结算 |
| 脱战 | 连续 `6` 秒没有有效职业行为时清空守势；绝技值不因短暂脱战自动清空 |
| 强制清理 | 死亡、挑战开始、挑战失败、跨层、角色销毁和重连清空守势、绝技值与全部短时状态 |

守势来源：

| 来源 | 守势 | 限制 |
|---|---:|---|
| A01 定关横扫命中 | `10/10/12/12/14`，额外目标各 `+2`，最多 3 个 | 敌对、存活、可战斗单位 |
| A02 拦潮刺命中 | `12/12/14/14/16` | 每次释放只结算一次 |
| A03 横戈震阵 | 每击 `+5`，两击同中一个目标额外 `+3` | 两段各自独立命中集 |
| A05 钉界首次命中 | `8/8/10/10/12` | 每次释放只结算一次 |
| A04 成功格挡 | `14/15/16/17/18` | 每次架界格最多一次；仅项目标记为可格挡的敌方非周期直击 |
| A07 有效护守 | `12` | 每次不动壁最多一次；必须实际减免或吸收一次敌方非周期伤害 |

不得从自伤、无敌剧情单位、周期伤害、法宝、宠物、召唤物、队友伤害或已离场单位获得守势。守势超过 100 的部分丢弃，不转化为护盾、伤害或绝技值。

### 2.2 耗势、界势与绝技值

| 技能 | 守势消耗 | 有效结算 | 界势强化 |
|---|---:|---|---|
| A06 崩关反震 | `45` | 主击命中有效敌人 | 追加主击 `45%` 的震波与 `+1.0` 破韧 |
| A07 不动壁 | `35` | 产生护盾；有效护守才获得额外绝技值 | 对附近队友施加 `C02_M10_TONGSHOU`，自身仍保留完整护盾 |
| A08 封域镇压 | `50` | 初击命中至少一名有效敌人 | 普通/精英镇压延长；BOSS 额外 `+0.5` 破韧 |

- 耗势在提交后立即扣除；提交前打断不扣；提交后落空不返还。
- A06 与 A08 成功命中时，按实际消耗守势 `× 0.16` 获得绝技值；A07 只有有效护守时按 `35 × 0.16` 获得绝技值。
- 每次成功 A04 格挡额外获得 `8` 绝技值。退款、被动补回、绝技赠送的守势不产生绝技值。
- 无装备熟练循环的首次绝技目标为 `60-90` 秒；少于 55 秒或超过 95 秒均视为白盒失败。

### 2.3 60 秒示例循环

```text
0-8 秒：A01/A02/A03/A05 生成 45-55 守势并布置界钉
8-16 秒：预判 A04 成功格挡，进入 60-75 守势，获得反震待发
16-24 秒：继续生成至 80，获得界势
24-32 秒：界势 A06 消耗 45 守势，兑现反震与破韧
32-44 秒：用 A01/A03/A05 回填，A07 处理真实高压窗口
44-60 秒：再次获得界势并以 A08 控制/破韧；根据命中与格挡进入绝技充能中段
```

## 六、效果与多人规则

| 键 | 名称 | 策略 | 目标范围 |
|---|---|---|---|
| M01 | 界势 | `derived` | self |
| M02 | 格挡架势 | `source_refresh` | self |
| M03 | 护守 | `source_refresh` | self |
| M04 | 反震待发 | `source_refresh` | self |
| M05 | 反震护盾 | `same_source_shield_refresh` | self |
| M06 | 界钉迟滞 | `shared_highest` | selected |
| M07 | 界钉 | `source_bound` | selected |
| M08 | 不动壁垒 | `same_source_shield_refresh` | self |
| M09 | 不动镇守 | `source_refresh` | self |
| M10 | 同守 | `shared_highest` | team |
| M11 | 镇压 | `source_refresh` | selected |

- 四名镇界同时存在时，守势、绝技、格挡实例、反震待发、护盾和计时器各自独立。
- 同名迟滞、同守等团队收益只呈现一个最高来源；最高来源到期时回退到仍有效的下一来源。界钉按“目标 ID + 施法者 ID”私有保存，不能互相消费。
- `team` 永远只表示队友，不包括施法者；A07 自身护盾与减伤不依赖 M10 同守。
- 减伤按格挡、个人、团队三类分别取高值后乘算，最终受 75% 上限约束，详细公式见 [P1 修订与验收](05-镇界P1修订与验收.md)。
- A07/A08 的团队收益不能替代角色自身护盾和控制；无镇界队伍必须仍能用走位、装备或其他职业完成副本。

## 八、白盒验收

- Lv1/Lv20/Lv40/Lv60 属性与成长公式完全一致，重复初始化不叠加成长。
- 成功格挡和有效护守每次释放最多生成一次守势；周期伤害、自伤和无效目标不生成资源。可格挡性与有效护守必须由项目遭遇标签确认。
- 守势 80 获得界势，下一次耗势提交后清除；提交前打断不扣，提交后落空不返还。
- A08 对普通/精英执行控制，对 BOSS仅转破韧；重叠控制不提前解除。A05/A08 缺少权威施法点时必须拒绝结算。
- 界钉私有、同守最高值、同源护盾刷新、死亡与挑战清理均按角色正确隔离。
- 首绝技处于 60-90 秒目标，且镇界 90 秒单体输出保持在破妄同条件的 80%-87% 区间；实机日志门禁见 [P1 修订与验收](05-镇界P1修订与验收.md)。
- 存档、技能树 UI、五槽和多人会话遵循项目级延期接入契约，不直接写入职业核心。
