# 地图与多主城结构

## 总体结构

地图采用同一张大地图多区域布局。

```text
同一张 Y3 地图
-> 中心传送区
-> 三个首发主城
-> 每个主城配公共野外
-> 每个主城配独立副本区域
-> 全局长期挑战区：通天塔
-> 预留后续主城空间
```

主城之间可以通过传送阵、传送 NPC 或 UI 选择跳转。跳转只是移动玩家到地图中的不同区域，不是加载另一张地图文件。

## 首发三主城

| 主城 | 主题定位 | 公共野外 | 副本区定位 | 主要成长产出 |
|---|---|---|---|---|
| 花果山主城 | 山林、洞窟、新手西游、水域边界 | 山林、洞窟、瀑布、水帘入口、东海前缘、鲨之涡流 | 龙宫、火焰山/牛魔王 | 初阶装备、强化石、基础法宝碎片 |
| 地府主城 | 鬼城、奈何、冥河 | 鬼城街巷、奈何桥、冥河岸 | 白骨秘境、阎罗殿 | 魂石、法宝合成材料、抗性装备 |
| 天庭主城 | 云海、天门、神将 | 天宫道、南天门、天王殿外缘 | 蟠桃园、凌霄宝殿、玲珑塔支线 | 高阶装备、神将材料、塔层挑战资源 |

## 每个主城的固定构成

每个主城都必须包含以下结构：

- 主城安全区。
- NPC 功能区。
- 公共野外入口。
- 单人本入口。
- 团队本入口。
- 本城材料商人或强化 NPC。
- 本城装备阶级或材料主题。
- 通往中心传送区或其他主城的传送点。

每个主城的副本必须独立，不允许多个主城复用同一个副本区域。

## 每篇章三点传送闭环

每个主城对应的篇章固定设置 3 个篇章内传送点：

| 传送点 | 位置原则 | 主要用途 |
|---|---|---|
| 主城传送点 | 主城安全区或核心功能区 | 返回主城，进行强化、法宝、仓库、商店等养成操作 |
| 副本枢纽传送点 | 本篇章所有副本入口之间的中央转折位置 | 承担中段回程、路线转折、副本选择和玩家重新集结 |
| 团本入口传送点 | 本篇章团队本入口的安全集结区 | 支持团队本重复挑战、失败后重新集结和快速返回 |

通用约束：

- 3 个传送点只承担本篇章内部的回程闭环，不替代主城之间的跨城传送。
- 传送落点必须处于安全区域，不得落入普通怪仇恨范围、公共 BOSS 战斗圈或团队本正式战场。
- 副本枢纽传送点必须同时服务本篇章的单人本、团队本和后续新增副本，地形施工时需要预留扩展接口。
- 各篇章传送点的具体坐标、激活条件和表现形式，在对应篇章地图分布定稿时分别确定。

花果山篇对应关系：

- 主城传送点：花果山主城安全区。
- 副本枢纽传送点：龙宫与火焰山等副本入口之间的中央转折区，具体位置随花果山最终路线确定。
- 团本入口传送点：火焰山团队本安全集结区。

可以复用：

- 副本状态机规则。
- 倒计时规则。
- 死亡失败规则。
- 奖励结算框架。
- UI 交互框架。

不能复用：

- 副本地形。
- 怪物主题。
- BOSS 技能节奏。
- 掉落材料命名与用途。
- 主城视觉主题。

## 地图空间预留

v1.0 需要预留后续主城地形空间。早期九宫格方案已被统一世界观替代，现采用“一个 Y3 地图文件、多个世界层板、层内连续、层间传送”的结构：

```text
外天层：[十洲三岛/星宫/洪荒遗迹预留]

天界层：[天庭主城+副本区] -> [瑶池/雷府/北极天宫预留]

人界层：[东胜神州花果山] -> [东海岸接口]
        [南瞻/北俱/西牛等后续部洲板块]

幽冥层：[地府主城+副本区] -> [十殿/幽都/黄泉预留]

梦墟层：[通天塔] [牛魔旧战场等劫痕副本]
```

同层相邻区域可以连续步行，不同层或跨洲区域通过界门、天门、鬼门、海眼等传送。各层在同一个 Y3 地图文件中用不可达空白区隔离。

v1.0 开放：

- 花果山主城。
- 地府主城。
- 天庭主城。
- 中心传送广场。
- 通天塔首发层数。

后续开放：

- 东海龙庭。
- 南瞻长安、北俱妖城等四洲主城或前线城。
- 瑶池/善见仙城、星宫等上层天界主城。
- 幽都等地府高阶扩展区。

火焰山保留为西行火域和牛魔旧战场，不再作为默认主城预留。完整规则见 `../../10-项目统一世界观总纲.md` 与本目录的 `11-世界篇章与地图扩展蓝图.md`。

未开放区域可用以下方式封闭：

- 封印门。
- 迷雾边界。
- 断桥。
- 未激活传送阵。
- NPC 提示后续版本开放。
