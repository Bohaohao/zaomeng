# 阶段归档索引

阶段归档用于保存已经确认的设计基线和方案演变记录。归档不等于失效；每个归档目录的 `README.md` 会说明哪些文件仍是当前有效基线，哪些只用于历史追溯。

## 归档目录

- [地图设计阶段归档](地图设计/README.md)
- [职业设计阶段归档](职业设计/README.md)

## 使用规则

- 开始新阶段前先读取 [全局设计基线](../全局设计基线.md)。
- 全局设计基线只引用当前有效版本，不让下游文档自行判断历史稿优先级。
- 用户明确采纳新方案后，先更新对应归档基线，再更新全局设计基线和所有直接引用。
- 历史方案保留原文和状态标记，不覆盖成当前方案。
