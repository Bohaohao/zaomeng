## 本轮冻结的设计契约

- 首发等级上限为 `Lv60`，花果山/地府/天庭分别承担 `Lv1-20`、`Lv21-40`、`Lv41-60`；Lv60 技能总预算为 60，Lv1 自动技能与 Lv2-Lv60 的 59 点均纳入守恒。
- 四职业裸装属性统一采用完整定点计算、最终四舍五入的重算规则；装备、法宝、宠物、收集和临时战斗态必须在后续按确定顺序叠加。
- Lv8 龙宫完整交互有角色私有的 60 秒核心路线门槛：C01/C02/C03 使用 `C01_ROUTE_LV8_core`、`C02_ROUTE_LV8_core`、`C03_ROUTE_LV8_core`，C04 使用所选的 `C04_ROUTE_LV8_hunt|wind|bind`。通过键只能由同 `actor_id`、同职业、同生命周期的权威 attempt 以 `event_id` 幂等写入；失败和断线只清理会话态 attempt。
- C04 Lv15 一阶绝技试炼同时校验 `C04_U01_TRIAL_ELIGIBLE`、`C04_REAL_RECOVERY_INTRO` 和 `u01_tier=0`，成功后才持久化永久阶级。
- 公共 BOSS 的 `kill_honor_credit`、`progression_participation`、参与箱、稀有资格、保底与 roll 彼此独立；资格证据要求完整 encounter origin/window 载荷和双层去重。
- 装备、法宝、材料、龙蛋属于 `item` 资产；宠物属于 `unit + ability` 资产；货币账本与掉落 profile 是权威系统数据，不得伪造为物编对象。
