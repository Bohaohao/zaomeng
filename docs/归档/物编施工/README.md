# 物编与离线施工归档

本目录保存已经形成明确施工事实、但仍需区分“离线验证完成”和“后续验证待办”的物编与运行时归档。

## 当前条目

- [花果山离线复审修订归档](01-花果山离线复审修订归档.md)：记录花果山遭遇运行时、物编命令门禁与离线总入口的 P1 修复、全量回归与终审结论；生产施工和实机验证门禁仍保持关闭。
- [成长系统规格整包归档](02-成长系统规格整包归档.md)：记录成长规格的冻结契约、规格验证和待决数值政策；当前详细来源仍位于 `docs/物编/18-20` 与成长系统规格包，离线施工和真实 Y3 接入尚未开始。
- [成长标定候选与地府前置接口闭环归档](03-成长标定候选与地府前置接口闭环归档.md)：记录非生产标定候选的来源续封、阎罗殿/转轮殿跨篇接口、龙宫逆潮稳定门槛和团队死亡回初始出生点的离线闭环；地府资产、数值与真实 Y3 门禁仍保持关闭。
- [地府篇主线、遭遇与副本规格整包归档](04-地府篇主线遭遇与副本规格整包归档.md)：记录地府主线与副本职责的 `review-ready` 纯离线规格、白骨秘境独立单人本角色、转轮殿固定团队终点、跨篇防漂移校验与终审结论；所有地府生产施工门禁仍保持关闭。

## 归档规则

- 归档保留已落地修改、测试证据和未关闭风险，不用历史通过结果覆盖当前未复验状态。
- 生产 ID、编辑器回读、地图脚本根、真实 Y3 API 和四人实机验证仍由各施工状态文档单独管理。
