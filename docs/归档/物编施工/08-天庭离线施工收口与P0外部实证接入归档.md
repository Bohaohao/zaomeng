- 天庭主线“入章 → 南天门 → 断虹 → 四门 → 周天观台 → 凌霄外庭”及其逐人进度、私有会话、失败清理、重放与常规完成边界已形成纯离线权威合同；它不创建实际进度、存档、奖励或 Lua/Y3 对象。
- 七星、二十八星宿与四圣的会话、上海时区轮换快照、逐人资格、断线 `left`、死亡回当前篇章初始出生点及 cleanup 幂等边界均已冻结。材料、掉落、称号数值、法宝配方与经济收据仍未授权落表。
- 地图口径、公共白盒、镜头/碰撞、HUD、双通道预警、失败复盘、Boss 可读性、敌人生态与物编/美术/特效需求均已完成施工前规格；没有创建地图、资源 ID、模型、特效、UI 或物编实例。
- P0 绝对标定仍是七门 `0/7`。相对战斗标尺与四职业构筑/回放格式已冻结，但 HP、攻击、双防、攻速、移速、技能秒数、对象键和经济值全部维持 `null/deferred`。
- 外部实机采集接入包明确：真实 map-local 结构预检只是必要条件，必须再由外部来源—预检证明绑定预检合同/runner 摘要、不可变报告摘要、只读授权、权威时间和不泄露路径的工程/地图指纹；采集方、操作者、独立审阅者与采纳机关两两隔离。
- 外部 manifest 只能绑定一个冻结的环境族，并单向交给独立审阅；它不能预先或反向引用采纳决定。Node/Fengari 仅是离线测试或未来物化边界，不能成为实机采集信任根。
