- `ability`、`modifier`、`projectile` 的 defaults 与每条生产记录都必须显式提供数组类型 `unresolved_fields`。
- 缺失、`null` 或标量不能再在合并时被折叠为空数组并绕过生产数据完整性门禁。

### 离线入口信任链

涉及：`implementation/run-all-preconstruction.ps1`、`implementation/run-all-professions.ps1`、`implementation/test-run-all-preconstruction-integrity.ps1`。

- 顶层与职业入口均要求 Windows PowerShell `Desktop` 版，不能只依赖可执行文件名。
