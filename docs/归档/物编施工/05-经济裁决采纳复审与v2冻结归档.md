## 本轮修复

1. XP 收据绑定冻结来源行、等级差倍率、首次/重复结算类型和公式输出。
2. 奖励计划只能由冻结 bundle、首通/重复转化、稀有 roll 或塔 `tower_award_class` 精确投影；拒绝部分 bundle、表外额度和未绑定 grant。
3. 公共首通/稀有必须绑定已提交 P1 参与箱；牛魔团队基础包、首通与稀有均绑定团队资格快照、完成事件和团本实例。
4. 收据统一冻结权威 `actor_id + lifecycle_id + authority_proof_ref -> stable owner_id` 解析、遭遇实例、证明、终态状态/结果矩阵和禁止持久化 `prepared`。
5. 保底补齐计数初值、判定顺序、普通/强制成功、重复转化、零奖励和显式迁移记录。
6. 天庭的资源表 canonical 状态改为 `accepted-design-baseline-runtime-not-integrated`，并与设计引用角色分离；成长、花果山、地府与天庭包均切换为当前 `economy-v2` 引用。
7. 生成 handoff JSON 统一为 UTF-8 无 BOM，确保严格 Node `JSON.parse` 可直接消费。
8. 修正地府篇 source、报告与五份 handoff 的陈旧措辞：经济裁决已冻结为 `economy-v2` 设计基线；未完成的是权威运行时接入、持久化收据与生产裁决。
