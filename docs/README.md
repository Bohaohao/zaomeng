# 造梦 ORPG 策划案索引

本文档目录用于沉淀当前关于“造梦式西游 ORPG”的策划沟通结果。

当前口径：

- 项目类型：最多 4 人同游的存档制 MMORPG 风格 ORPG。
- 表现形态：Y3 2.5D 俯视角自定义地图。
- 首发版本：不是简单 Demo，而是可上架提供玩家游玩的 v1.0。
- 首发主城：花果山篇、地府篇、天庭篇，分别吸收《造梦西游 1-3》的关卡推进结构。
- 核心结构：多主城、公共野外、单人本、团队本、长期爬塔、角色存档、装备与法宝养成。
- 参考方式：吸收《造梦西游》系列的关卡进阶、装备成长、法宝养成、精英/噩梦/爬塔等结构，不复刻具体 IP 资产、角色形象和专有技能。

## 已明确结论

- v1.0 必须有可持续游玩的内容量，不能按技术验证版理解 MVP。
- 每个主城都必须拥有独立副本区域，不能多个主城复用同一副本。
- 公共野外的小怪、精英和 BOSS 是所有玩家可见的公共资源。
- 单人本和团队本需要状态锁、倒计时、失败清理和参与者边界。
- v1.0 必须包含类似通天塔的长期挑战系统，给玩家持续上升目标。
- 地图需要预留后续新主城的地形空间。
- 花果山篇隐藏单人本称谓统一为“龙宫”，不再使用“水晶宫”作为项目内名称。
- 花果山属于东胜神州并与东海相邻；地府、天界、四海和外天采用分层世界结构，不再采用平面九宫格解释全部区域。
- 火焰山当前保留为西行火域与牛魔旧战场，不作为默认主城；花果山团本通过熔脉劫痕进入，不代表花果山与真实火焰山相邻。
- 当前实施口径为“六层锚点先确定、中心内容先施工、外围按需扩容”；首发画布以 `384x320 terrain cell` 为推理基线，旧 `640x512` 方案只作为远期容量参考。
- 东胜神州通过世界地图拓扑和内容节点表达，不再分配固定地理 tile 比例；花果山以 `96x72` 可玩场景计算，只表达玩法空间并通过东岸接口邻接东海。
- v1.0 固定 4 个职业，首发等级上限 Lv60；主动与被动技能共享每级获得的自由技能点，主动技能最多装备 5 个。
- 通天塔 Lv55 解锁并逐人检查等级，低等级玩家不能通过组队进入挑战。
- 地府篇常规最终副本固定为阎罗殿，首发团队本固定为转轮殿；只有阎罗殿的权威成功回执可写入角色级 `DF_PROGRESS_YANLUO_HALL_CLEARED`，作为 Lv38 龙宫逆潮的受信任跨篇门槛。
- 团队本成员死亡后先回当前篇章初始出生点，但在同一团队会话中保持 `dead` 和重入锁；匹配清理确认前不得重入，`left` 不触发复活或回传，全灭和超时按成员状态去重回传。
