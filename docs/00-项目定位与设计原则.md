# 项目定位与设计原则

## 项目定位

本项目定位为一个最多 4 人同游的存档制 MMORPG 风格 ORPG。

严格意义上，4 人上限不属于传统 MMORPG 的“大量玩家同时在线”，但本项目追求的是 MMORPG 的核心体验语言：

- 角色存档与长期成长。
- 多主城、多区域推进。
- 公共野外刷怪与公共 BOSS。
- 单人副本、团队副本与长期挑战副本。
- 装备掉落、强化、进阶、套装追求。
- 法宝合成与养成。
- 时装、称号、图鉴等粘性收集。

更准确的项目描述是：

> 一个支持最多 4 人同游的西游题材存档制 ORPG。玩家选择角色存档进入世界，在多个主城之间推进主线，刷公共野外、挑战副本、培养装备和法宝，并通过长期爬塔验证战力与追求更高奖励。

## 设计参考

参考《造梦西游》系列的结构经验，而不是复刻具体内容。

可吸收的结构：

- 关卡由浅入深的主题进阶。
- 每个阶段有明确风格、怪物生态和 BOSS 记忆点。
- 装备掉落、装备强化、装备进阶。
- 法宝合成、法宝升级、材料刷取。
- 精英副本、噩梦副本、隐藏副本。
- 爬塔/长期挑战提供毕业后目标。
- 时装、称号、饰品、图鉴等收集目标。

需要避免：

- 直接使用原作专有角色、专有 BOSS 形象、专有技能表现。
- 只做关卡复刻，缺少自己的世界规则和成长循环。
- 首发内容只像技术样片，没有长期追求。

## v1.0 口径

本文档中的 v1.0 或首发版本不是最小技术验证版，而是可上架、可提供玩家游玩的版本。

v1.0 需要满足：

- 玩家第一次进入后有明确目标。
- 玩家能完成主线推进、刷怪、打本、强化、继续挑战的完整循环。
- 单人玩家有可玩内容。
- 2-4 人组队有明确收益。
- 通关首发主线后仍有长期上升目标。
- 后续扩展主城和新系统时不需要重构世界结构。

## 核心循环

短循环，10-60 秒：

- 找怪、走位、释放技能、击杀小怪或精英、获得金币/材料/经验。

中循环，2-8 分钟：

- 完成一片野外区域、挑战一个单人本或团队本、获得装备/材料、回城强化。

长循环，多次游玩：

- 推进主城进度、提升装备阶级、合成法宝、挑战更高通天塔层数、收集外观和称号。

## Y3 适配原则

- 使用同一张大地图承载多个主城、公共野外、副本区域和通天塔区域。
- 主城和副本可以通过传送阵或 UI 选择跳转，但本质上仍在同一张地图中。
- 公共野外用于营造世界感和多人同游感。
- 副本通过区域隔离和状态锁实现挑战边界。
- UI 可以作为玩家输入入口，真正改变玩法状态的传送、刷怪、奖励和锁定必须走同步玩法逻辑。
