# 镇界延期系统接入契约

镇界沿用项目级角色存档、技能树 UI、五槽预设和四人同步边界；这些系统是职业控制器的调用方，不能直接修改 `Runtime.actors`。

| TODO | 接入位置 | 镇界约束 |
|---|---|---|
| `ZJ-INT-001` 存档与重连 | 角色载入后 `Controller:register` 前 | 保存等级、技能等级、绝技阶级、三套预设；不保存守势、界势、绝技值、格挡、护守、界钉和待定施法 |
| `ZJ-INT-002` 技能树/HUD | 同步学习/洗点服务 | UI 只能提交意图；批准后调用 `Controller:set_ability_level`，HUD 只读取守势与状态 |
| `ZJ-INT-003` 五槽预设 | 真实技能 ID 分配后 | 五槽仅允许 A01-A08 的已学习主动；固定被动、绝技、闪避和法宝不占槽 |
| `ZJ-INT-004` 四人同步 | 会话初始化与所有外部状态变化 | 守势、格挡实例、有效护守、界钉私有标记、冷却、控制租约和 Trigger 必须按 actor 隔离 |
| `ZJ-INT-005` 选点施法记录 | 同步施法输入与 `单位-施放技能` 桥接之间 | 为 A05/A08 保存权威施法点；事件读取不到该点时拒绝结算，不能回退到角色当前位置 |
| `ZJ-INT-006` 首领伤害分类 | 遭遇伤害结算后、职业受伤事件前 | 为每段伤害提供可格挡直击、周期/持续伤害、护盾吸收与实际减伤结果；未分类不得触发 A04/A07 |
| `ZJ-INT-007` 延迟命中回调 | 投射物、命中框或项目技能命中服务 | 将施法时的 `lifecycle_id` 原样回传；过期角色或重连后的同 ID 新角色不得接受旧命中确认 |
