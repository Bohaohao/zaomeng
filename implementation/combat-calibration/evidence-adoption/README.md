# P0 跨职业绝对标定：实证采集与采纳包

## 结论

`CAL_SPEC_P0_EVIDENCE_COLLECTION_AND_ADOPTION_V1` 把既有 P0 的七道绝对字段门禁，拆成可执行的**只读采集 → 规范化 → 独立复核 → 外部采纳**链路。

它不是实机证据本身，不连接 Y3 编辑器，不读取玩家客户端，不创建对象、地图、Lua、UI、存档、会话、奖励或经济收据，也不能把任一门禁改为通过。

当前状态固定为：

```text
external_evidence_not_collected
current_satisfied_gate_ids = []
production_gate = closed
absolute projection = null
```

## 为什么现在要有这个包

此前 P0 已定义“需要哪些证据”，但缺少将未来真实 Y3 观测安全送入复审的统一入口。本包补的是采集与治理层：

1. 任何采集先绑定引擎构建、真实工程/地图或夹具版本、对象库存快照、模板读回依据和工具链摘要。
2. 采集只能只读；原始文件不进入本仓库，不得被本包修改。
3. 提交只携带不可变外部工件引用及其摘要，不携带对象绝对属性或投影结果。
4. 采集者与复核者必须不同；测试样例、客户端声明、图解坐标、猜测的对象键均会被拒绝。
5. 七门全部获得外部授权采纳后，仍只允许进入**单独的绝对字段投影复审**，不自动填入任何天庭单位字段。

提交 envelope、`gate_scope`、主合同、源快照、采集模板和采纳模板均使用精确字段白名单：不能附带任意 `metadata`、`copyFrom`、对象/模板绑定、未来投影容器或隐藏嵌套字段。在普通 JSON 数据对象输入下，公共引用入口还拒绝原型链、不可枚举属性、getter/setter 与 symbol 隐藏字段。每条提交还必须带一个只分类、不含实际对象键或数值的 `gate_scope`。它使 G01 可核对 12 份构筑 × 3 次 run，G06 可核对 1/2/3/4 人覆盖；即使结构覆盖完整，结果仍只是 `structurally_complete_preview_not_adoptable`，不会成为证据或采纳。

引用校验器也只接受这份关闭态的静态 envelope、拒绝词表、采集链和 `0/7` 采纳状态；调用者传入“已采集”“已开启”或自行扩展字段的伪造合同会在预览前被拒绝。

## 七道证据门

| 门禁 | 采集重点 | 不可接受的替代品 |
|---|---|---|
| G01 固定构筑与回放 | 12 份完整构筑，每份 3 条确定性规范日志 | 局部 Lv60 木桩、缺失技能等级、少于三条日志 |
| G02 伤害/双防公式 | 物理、魔法、减伤/穿透顺序和反例 | 旧物理夹具泛化、相对压强推导 |
| G03 命中/暴击/控制 | 目标等级/生命周期、命中、暴击、控制抗性依据 | UI/客户端结果、借用目标信息 |
| G04 动作帧与移速 | 模板读回、帧分段、攻速/移速字段、换算复核 | 把设计空间移速写进引擎字段、描述文本推帧 |
| G05 碰撞与镜头 | 实地图白盒、寻路、射程、安全落点、镜头记录 | 设计图、候选布局或无输入追踪的截图 |
| G06 1–4 人回放 | 权威成员/遭遇快照、动作/伤害日志、left/cleanup 观察 | 客户端人数、可重连旧生命周期、改写已接受日志 |
| G07 对象键与模板 | 实际对象表、稳定键、模板、字段与资源库存读回 | 猜测键、图解 ID、未盘点资源名 |

## 外部采纳边界

真实证据和采纳决定必须在受授权的外部采集/复审系统中产生。本包当前没有可信采集提供方、真实工程引用或采纳账本，因此任何“看起来完整”的提交都会停在 `blocked_provider_unavailable`；离线测试只能证明拒绝逻辑正确，不能证明外部引用、摘要或时间戳所声称的事实真实。

同一 Node 进程中的恶意可执行 JavaScript（例如可伪造反射结果的 `Proxy`）不是该对象校验器的信任边界；未来受信任采集方必须通过进程隔离与 JSON/IPC 序列化输入，而不能把任意 JavaScript 对象直接交给本包。

`capture_run_id`、会话、项目/地图版本和外部引用中出现 `synthetic`、`schema-test`、`test-only`、`preflight`、`deferred` 或客户端路径会被拒绝；时间必须是有效的 UTC RFC3339 秒级时刻。这些格式与关键词拒绝只是防御性筛查，不是信任根：未来采集方仍须验证提供方证明、权威时钟证明和不可变工件。一个预览 bundle 只能覆盖一个 gate 和一个冻结的引擎/工程/地图/模板/采集依据族，不能用跨版本或重复 run 拼接。

采纳顺序为：

```text
真实 Y3 只读采集
  → 外部工件规范化/摘要
  → 独立复核
  → 七道门逐项外部采纳
  → 单独绝对字段投影复审
  → 获授权后才可进入天庭物编/主线施工
```
